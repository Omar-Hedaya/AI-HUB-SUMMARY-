GitHub Pages & Setup Guide

1. Folder Structure on GitHub:

Create subdirectories inside a content/ directory. Subfolders become your tabs automatically!

my-study-repo/
├── index.html            (this single file!)
└── content/
    ├── lectures/
    │   └── lecture-01.html
    ├── sheets/
    │   └── thermo-sheet-1.html
    └── summaries/
        └── fluid-mechanics.html

2. Change Repo Config in index.html:

Open index.html and edit the two constants at top of the script:

const GITHUB_USERNAME = "mo2men2162007";
const GITHUB_REPO = "study-hub";

3. Enable GitHub Pages:

  1. Go to your GitHub repository -> Settings.
  2. In the left sidebar, click Pages.
  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Select main branch and /(root) folder. Click Save.
