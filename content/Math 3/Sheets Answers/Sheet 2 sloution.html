⚡ Vectors Analysis Cheat Sheet & Operators
1. Gradient of Scalar Field ($\nabla F$)
$$\nabla F = \frac{\partial F}{\partial x}i + \frac{\partial F}{\partial y}j + \frac{\partial F}{\partial z}k$$
• ينتج عنه متجه عمودي على سطح المستوى $F(x,y,z) = c$.
2. Divergence of Vector Field ($\nabla\cdot\bar{U}$)
$$\nabla\cdot\bar{U} = \frac{\partial u_1}{\partial x} + \frac{\partial u_2}{\partial y} + \frac{\partial u_3}{\partial z}$$
• ينتج عنه دالة قياسية (Scalar). إذا كان $\nabla\cdot\bar{U} = 0$ يسمى المجال Solenoidal.
3. Curl of Vector Field ($\nabla\times\bar{U}$)
$$\nabla\times\bar{U} = \begin{vmatrix} i & j & k \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ u_1 & u_2 & u_3 \end{vmatrix}$$
• ينتج عنه متجه (Vector). إذا كان $\nabla\times\bar{U} = \bar{0}$ يسمى المجال Irrotational.
4. Laplacian and Null Identities
$$\nabla^2 F = \nabla\cdot\nabla F = \frac{\partial^2 F}{\partial x^2} + \frac{\partial^2 F}{\partial y^2} + \frac{\partial^2 F}{\partial z^2}$$
$$\nabla\times(\nabla F) = \bar{0} \quad (\operatorname{curl}\operatorname{grad} F = \bar{0}), \quad \nabla\cdot(\nabla\times\bar{U}) = 0 \quad (\operatorname{div}\operatorname{curl}\bar{U} = 0)$$
5. Scale Factors in Curvilinear Coordinates
$$h_1 = \left|\frac{\partial\bar{r}}{\partial u_1}\right|, \quad h_2 = \left|\frac{\partial\bar{r}}{\partial u_2}\right|, \quad h_3 = \left|\frac{\partial\bar{r}}{\partial u_3}\right|$$
• الأسطواني $(\rho, \theta, z)$: $h_1 = 1, h_2 = \rho, h_3 = 1$ | الكروي $(\rho, \theta, \varphi)$: $h_1 = 1, h_2 = \rho\sin\varphi, h_3 = \rho$.
📌 Question 1: Derivatives of Vector Function
If $\bar{U} = (t^2 + 2t)i + (t\sin t)j + (2 + \cos t)k$, find $\frac{d\bar{U}}{dt}$ and $\frac{d^2\bar{U}}{dt^2}$.
Step 1: First Derivative $\frac{d\bar{U}}{dt}$
Differentiate each component with respect to $t$:
$$\frac{d}{dt}(t^2 + 2t) = 2t + 2$$ $$\frac{d}{dt}(t\sin t) = (1)\sin t + t\cos t = \sin t + t\cos t$$ $$\frac{d}{dt}(2 + \cos t) = -\sin t$$
$$\frac{d\bar{U}}{dt} = (2t + 2)i + (\sin t + t\cos t)j - (\sin t)k$$
Step 2: Second Derivative $\frac{d^2\bar{U}}{dt^2}$
Differentiate the first derivative components with respect to $t$:
$$\frac{d}{dt}(2t + 2) = 2$$ $$\frac{d}{dt}(\sin t + t\cos t) = \cos t + [1 \cdot \cos t + t(-\sin t)] = 2\cos t - t\sin t$$ $$\frac{d}{dt}(-\sin t) = -\cos t$$
$$\frac{d^2\bar{U}}{dt^2} = 2i + (2\cos t - t\sin t)j - (\cos t)k$$
Derivatives Computed Successfully
📌 Question 2: Vector Derivatives at $t = 0$
If $\bar{U} = (t + e^t)i + (t + \sinh t)j + (3t + \cos t)k$, find $\left|\frac{d\bar{U}}{dt}\right|$ and $\left|\frac{d^2\bar{U}}{dt^2}\right|$ at $t = 0$.
Step 1: Compute $\frac{d\bar{U}}{dt}$ and evaluate at $t = 0$
$$\frac{d\bar{U}}{dt} = (1 + e^t)i + (1 + \cosh t)j + (3 - \sin t)k$$
Substitute $t = 0$ (noting $e^0 = 1$, $\cosh 0 = 1$, $\sin 0 = 0$):
$$\left.\frac{d\bar{U}}{dt}\right|_{t=0} = (1 + 1)i + (1 + 1)j + (3 - 0)k = 2i + 2j + 3k$$
Magnitude:
$$\left|\frac{d\bar{U}}{dt}\right|_{t=0} = \sqrt{2^2 + 2^2 + 3^2} = \sqrt{4 + 4 + 9} = \sqrt{17}$$
Step 2: Compute $\frac{d^2\bar{U}}{dt^2}$ and evaluate at $t = 0$
$$\frac{d^2\bar{U}}{dt^2} = (e^t)i + (\sinh t)j - (\cos t)k$$
Substitute $t = 0$ (noting $\sinh 0 = 0$, $\cos 0 = 1$):
$$\left.\frac{d^2\bar{U}}{dt^2}\right|_{t=0} = (1)i + (0)j - (1)k = i - k$$
Magnitude:
$$\left|\frac{d^2\bar{U}}{dt^2}\right|_{t=0} = \sqrt{1^2 + 0^2 + (-1)^2} = \sqrt{1 + 1} = \sqrt{2}$$
Magnitudes: $\sqrt{17}$ and $\sqrt{2}$
📌 Question 3: First and Second Partial Derivatives of $\bar{U}(x,y,z)$
If $\bar{U} = (x^2 + yz)i + (y\sin x)j + (2^y + \cos z)k$, find $\frac{\partial\bar{U}}{\partial x}, \frac{\partial\bar{U}}{\partial y}, \frac{\partial\bar{U}}{\partial z}, \bar{U}_{xx}, \bar{U}_{yy}, \bar{U}_{zz}, \bar{U}_{xy}, \bar{U}_{xz}$.
Step 1: First Partial Derivatives
$$\frac{\partial\bar{U}}{\partial x} = 2x\,i + (y\cos x)j + 0\,k = 2x\,i + (y\cos x)j$$
$$\frac{\partial\bar{U}}{\partial y} = z\,i + (\sin x)j + (2^y \ln 2)k$$
$$\frac{\partial\bar{U}}{\partial z} = y\,i + 0\,j - (\sin z)k = y\,i - (\sin z)k$$
Step 2: Pure Second Partials ($\bar{U}_{xx}, \bar{U}_{yy}, \bar{U}_{zz}$)
$$\bar{U}_{xx} = \frac{\partial}{\partial x}(2x\,i + y\cos x\,j) = 2\,i - (y\sin x)j$$
$$\bar{U}_{yy} = \frac{\partial}{\partial y}(z\,i + \sin x\,j + 2^y \ln 2\,k) = 0\,i + 0\,j + [2^y (\ln 2)^2]k = 2^y (\ln 2)^2 k$$
$$\bar{U}_{zz} = \frac{\partial}{\partial z}(y\,i - \sin z\,k) = 0\,i - (\cos z)k = -(\cos z)k$$
Step 3: Mixed Second Partials ($\bar{U}_{xy}, \bar{U}_{xz}$)
$$\bar{U}_{xy} = \frac{\partial}{\partial y}\left(\frac{\partial\bar{U}}{\partial x}\right) = \frac{\partial}{\partial y}(2x\,i + y\cos x\,j) = (\cos x)j$$
$$\bar{U}_{xz} = \frac{\partial}{\partial z}\left(\frac{\partial\bar{U}}{\partial x}\right) = \frac{\partial}{\partial z}(2x\,i + y\cos x\,j) = \bar{0}$$
All 8 Derivatives Computed
📌 Question 4: Gradient Vector ($\nabla F$)
Find $\nabla F = \frac{\partial F}{\partial x}i + \frac{\partial F}{\partial y}j + \frac{\partial F}{\partial z}k$ for:
(a) $F = x^4 + yz + 2^y \ln z$
(b) $F = y\sin x + z\cos y + e^z$
(c) $F = 3x^2 + \sqrt{y} + \sinh(3y)$
(d) $F = y\cosh x + y e^z + 12$
Solution for (a): $F = x^4 + yz + 2^y \ln z$
$$F_x = 4x^3, \quad F_y = z + 2^y \ln 2 \ln z, \quad F_z = y + \frac{2^y}{z}$$
$$\nabla F = (4x^3)i + (z + 2^y \ln 2 \ln z)j + \left(y + \frac{2^y}{z}\right)k$$
Solution for (b): $F = y\sin x + z\cos y + e^z$
$$F_x = y\cos x, \quad F_y = \sin x - z\sin y, \quad F_z = \cos y + e^z$$
$$\nabla F = (y\cos x)i + (\sin x - z\sin y)j + (\cos y + e^z)k$$
Solution for (c): $F = 3x^2 + \sqrt{y} + \sinh(3y)$
$$F_x = 6x, \quad F_y = \frac{1}{2\sqrt{y}} + 3\cosh(3y), \quad F_z = 0$$
$$\nabla F = (6x)i + \left(\frac{1}{2\sqrt{y}} + 3\cosh(3y)\right)j$$
Solution for (d): $F = y\cosh x + y e^z + 12$
$$F_x = y\sinh x, \quad F_y = \cosh x + e^z, \quad F_z = y e^z$$
$$\nabla F = (y\sinh x)i + (\cosh x + e^z)j + (y e^z)k$$
Gradients Fully Determined
📌 Question 5: (a) & (b) Divergence ($\nabla\cdot\bar{U}$) and Curl ($\nabla\times\bar{U}$)
(a) $\bar{U} = (x^2 + yz)i + (y\sin x)j + (2^y + \cos z)k$
(b) $\bar{U} = (x^3 \sinh z)i + (y^4 - 2\sin x)j + (y\ln z)k$
Solution for (a)
Divergence:
$$\nabla\cdot\bar{U} = \frac{\partial}{\partial x}(x^2+yz) + \frac{\partial}{\partial y}(y\sin x) + \frac{\partial}{\partial z}(2^y+\cos z) = 2x + \sin x - \sin z$$
Curl via Determinant:
$$\nabla\times\bar{U} = \begin{vmatrix} i & j & k \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ x^2+yz & y\sin x & 2^y+\cos z \end{vmatrix}$$
$$= i\left[\frac{\partial}{\partial y}(2^y+\cos z) - \frac{\partial}{\partial z}(y\sin x)\right] - j\left[\frac{\partial}{\partial x}(2^y+\cos z) - \frac{\partial}{\partial z}(x^2+yz)\right] + k\left[\frac{\partial}{\partial x}(y\sin x) - \frac{\partial}{\partial y}(x^2+yz)\right]$$
$$= i(2^y \ln 2 - 0) - j(0 - y) + k(y\cos x - z) = (2^y \ln 2)i + y\,j + (y\cos x - z)k$$
Solution for (b)
Divergence:
$$\nabla\cdot\bar{U} = \frac{\partial}{\partial x}(x^3 \sinh z) + \frac{\partial}{\partial y}(y^4 - 2\sin x) + \frac{\partial}{\partial z}(y\ln z) = 3x^2 \sinh z + 4y^3 + \frac{y}{z}$$
Curl:
$$\nabla\times\bar{U} = \begin{vmatrix} i & j & k \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ x^3 \sinh z & y^4 - 2\sin x & y\ln z \end{vmatrix}$$ $$= i(\ln z - 0) - j(0 - x^3 \cosh z) + k(-2\cos x - 0) = (\ln z)i + (x^3 \cosh z)j - (2\cos x)k$$
📌 Question 5: (c) & (d) Divergence and Curl
(c) $\bar{U} = (yz + \ln x)i + (e^z \cos x)j + (xy + \cosh z)k$
(d) $\bar{U} = (x y^2 z^3)i + (x^3 y^3 + 2z)j + [x - 3\log(y+2z)]k$
Solution for (c)
$$\nabla\cdot\bar{U} = \frac{1}{x} + 0 + \sinh z = \frac{1}{x} + \sinh z$$
$$\nabla\times\bar{U} = \begin{vmatrix} i & j & k \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ yz+\ln x & e^z \cos x & xy+\cosh z \end{vmatrix}$$ $$= i(x - e^z \cos x) - j(y - y) + k(-e^z \sin x - z) = (x - e^z \cos x)i - (e^z \sin x + z)k$$
Solution for (d)
Recall that $\log u \equiv \log_{10} u = \frac{\ln u}{\ln 10}$:
$$\nabla\cdot\bar{U} = y^2 z^3 + 3x^3 y^2 - \frac{3 \cdot 2}{(y+2z)\ln 10} = y^2 z^3 + 3x^3 y^2 - \frac{6}{(y+2z)\ln 10}$$
Curl components:
$$\nabla\times\bar{U} = \begin{vmatrix} i & j & k \\ \frac{\partial}{\partial x} & \frac{\partial}{\partial y} & \frac{\partial}{\partial z} \\ x y^2 z^3 & x^3 y^3 + 2z & x - 3\log(y+2z) \end{vmatrix}$$ $$= i\left[-\frac{3}{(y+2z)\ln 10} - 2\right] - j[1 - 3x y^2 z^2] + k[3x^2 y^3 - 2xyz^3]$$
Calculations Completed
📌 Question 6: Laplacian ($\nabla\cdot\nabla F = \nabla^2 F$) and Curl of Grad ($\nabla\times\nabla F$)
Find $\nabla\cdot\nabla F = \nabla^2 F$ and $\nabla\times\nabla F$ for functions in Question 4:
(a) $F = x^4 + yz + 2^y \ln z$
(b) $F = y\sin x + z\cos y + e^z$
(c) $F = 3x^2 + \sqrt{y} + \sinh(3y)$
(d) $F = y\cosh x + y e^z + 12$
General Identity for All Parts: $\nabla\times\nabla F$
From Vector Identity Theorem (Theorem 5, viii):
$$\operatorname{curl}(\operatorname{grad} F) = \nabla\times(\nabla F) = \bar{0} \quad \text{for all scalar functions } F$$
Hence for (a), (b), (c), and (d): $\nabla\times\nabla F = \bar{0}$
(a) Laplacian for $F = x^4 + yz + 2^y \ln z$
$$F_{xx} = \frac{\partial}{\partial x}(4x^3) = 12x^2$$
$$F_{yy} = \frac{\partial}{\partial y}(z + 2^y \ln 2 \ln z) = 2^y (\ln 2)^2 \ln z$$
$$F_{zz} = \frac{\partial}{\partial z}\left(y + \frac{2^y}{z}\right) = -\frac{2^y}{z^2}$$
$$\nabla^2 F = F_{xx} + F_{yy} + F_{zz} = 12x^2 + 2^y (\ln 2)^2 \ln z - \frac{2^y}{z^2}$$
(b) Laplacian for $F = y\sin x + z\cos y + e^z$
$$F_{xx} = \frac{\partial}{\partial x}(y\cos x) = -y\sin x$$
$$F_{yy} = \frac{\partial}{\partial y}(\sin x - z\sin y) = -z\cos y$$
$$F_{zz} = \frac{\partial}{\partial z}(\cos y + e^z) = e^z$$
$$\nabla^2 F = -y\sin x - z\cos y + e^z$$
(c) Laplacian for $F = 3x^2 + \sqrt{y} + \sinh(3y)$
$$F_{xx} = 6, \quad F_{yy} = -\frac{1}{4}y^{-3/2} + 9\sinh(3y) = -\frac{1}{4y^{3/2}} + 9\sinh(3y), \quad F_{zz} = 0$$
$$\nabla^2 F = 6 - \frac{1}{4y^{3/2}} + 9\sinh(3y)$$
(d) Laplacian for $F = y\cosh x + y e^z + 12$
$$F_{xx} = y\cosh x, \quad F_{yy} = 0, \quad F_{zz} = y e^z$$
$$\nabla^2 F = y\cosh x + y e^z = y(\cosh x + e^z)$$
All Laplacians Evaluated
📌 Question 7: Vector in Cylindrical Coordinates
Express the vector $\bar{U} = (xy)i + z\,j + (yz)k$ in cylindrical coordinates $(\rho, \theta, z)$.
Step 1: Coordinate Relations and Unit Vectors
Transformation: $x = \rho\cos\theta, \,\, y = \rho\sin\theta, \,\, z = z$
The Cartesian unit vectors expressed in cylindrical basis $(\bar{e}_\rho, \bar{e}_\theta, \bar{e}_z)$:
$$i = \cos\theta \bar{e}_\rho - \sin\theta \bar{e}_\theta$$ $$j = \sin\theta \bar{e}_\rho + \cos\theta \bar{e}_\theta$$ $$k = \bar{e}_z$$
Step 2: Substitute $x, y, z$ in $\bar{U}$
$$xy = (\rho\cos\theta)(\rho\sin\theta) = \rho^2 \cos\theta\sin\theta$$ $$z = z$$ $$yz = z\rho\sin\theta$$
$$\bar{U} = (\rho^2 \cos\theta\sin\theta)i + (z)j + (z\rho\sin\theta)k$$
Step 3: Collect components along $(\bar{e}_\rho, \bar{e}_\theta, \bar{e}_z)$
$$\bar{U} = (\rho^2 \cos\theta\sin\theta)[\cos\theta \bar{e}_\rho - \sin\theta \bar{e}_\theta] + z[\sin\theta \bar{e}_\rho + \cos\theta \bar{e}_\theta] + (z\rho\sin\theta)\bar{e}_z$$
$$\bar{U} = (\rho^2 \cos^2\theta\sin\theta + z\sin\theta)\bar{e}_\rho + (-\rho^2 \cos\theta\sin^2\theta + z\cos\theta)\bar{e}_\theta + (z\rho\sin\theta)\bar{e}_z$$

📌 Question 8: Vector in Spherical Coordinates and Jacobian
Write the vector $\bar{U} = (xy)i + (yz)j - x\,k$ in spherical coordinates $(\rho, \theta, \varphi)$ and find the Jacobian of the transformation.
Part 1: Jacobian of the Spherical Transformation
Transformation: $x = \rho\cos\theta\sin\varphi, \,\, y = \rho\sin\theta\sin\varphi, \,\, z = \rho\cos\varphi$
$$J = \frac{\partial(x,y,z)}{\partial(\rho,\theta,\varphi)} = \begin{vmatrix} \cos\theta\sin\varphi & \sin\theta\sin\varphi & \cos\varphi \\ -\rho\sin\theta\sin\varphi & \rho\cos\theta\sin\varphi & 0 \\ \rho\cos\theta\cos\varphi & \rho\sin\theta\cos\varphi & -\rho\sin\varphi \end{vmatrix} = \rho^2 \sin\varphi$$
Jacobian: $J = \rho^2 \sin\varphi$
Part 2: Unit Vector Matrix Inversion
The unit vectors $(\bar{e}_\rho, \bar{e}_\theta, \bar{e}_\varphi)$ relate to $(i, j, k)$ orthogonally:
$$i = \cos\theta\sin\varphi \bar{e}_\rho - \sin\theta \bar{e}_\theta + \cos\theta\cos\varphi \bar{e}_\varphi$$ $$j = \sin\theta\sin\varphi \bar{e}_\rho + \cos\theta \bar{e}_\theta + \sin\theta\cos\varphi \bar{e}_\varphi$$ $$k = \cos\varphi \bar{e}_\rho - \sin\varphi \bar{e}_\varphi$$
Part 3: Express $\bar{U}$ in terms of $(\bar{e}_\rho, \bar{e}_\theta, \bar{e}_\varphi)$
Components in Cartesian:
$$u_1 = xy = \rho^2 \sin\theta\cos\theta\sin^2\varphi$$ $$u_2 = yz = \rho^2 \sin\theta\sin\varphi\cos\varphi$$ $$u_3 = -x = -\rho\cos\theta\sin\varphi$$
Projecting along $\bar{e}_\rho, \bar{e}_\theta, \bar{e}_\varphi$:
$$U_\rho = \bar{U}\cdot\bar{e}_\rho = u_1(\cos\theta\sin\varphi) + u_2(\sin\theta\sin\varphi) + u_3(\cos\varphi)$$ $$= \rho^2 \cos^2\theta\sin\theta\sin^3\varphi + \rho^2 \sin^2\theta\sin^2\varphi\cos\varphi - \rho\cos\theta\sin\varphi\cos\varphi$$
$$U_\theta = \bar{U}\cdot\bar{e}_\theta = u_1(-\sin\theta) + u_2(\cos\theta) + u_3(0) = -\rho^2 \sin^2\theta\cos\theta\sin^2\varphi + \rho^2 \sin\theta\cos\theta\sin\varphi\cos\varphi$$
$$U_\varphi = \bar{U}\cdot\bar{e}_\varphi = u_1(\cos\theta\cos\varphi) + u_2(\sin\theta\cos\varphi) - u_3(\sin\varphi)$$ $$= \rho^2 \cos^2\theta\sin\theta\sin^2\varphi\cos\varphi + \rho^2 \sin^2\theta\sin\varphi\cos^2\varphi + \rho\cos\theta\sin^2\varphi$$
$\bar{U} = U_\rho \bar{e}_\rho + U_\theta \bar{e}_\theta + U_\varphi \bar{e}_\varphi$
📌 Question 9: Toroidal-type Orthogonal System Proof
Show that the new system corresponding to $(r, \theta, \phi)$ where:
$x = (2 - r\cos\theta)\cos\phi, \quad y = (2 - r\cos\theta)\sin\phi, \quad z = r\sin\theta$
is orthogonal and the scale factors are $h_1 = 1$, $h_2 = r$, and $h_3 = 2 - r\cos\theta$.
Step 1: Position Vector $\bar{r}$ and Partial Derivatives
$$\bar{r} = (2 - r\cos\theta)\cos\phi\,i + (2 - r\cos\theta)\sin\phi\,j + (r\sin\theta)k$$
1. Differentiate w.r.t $r$:
$$\frac{\partial\bar{r}}{\partial r} = -\cos\theta\cos\phi\,i - \cos\theta\sin\phi\,j + \sin\theta\,k$$
2. Differentiate w.r.t $\theta$:
$$\frac{\partial\bar{r}}{\partial\theta} = r\sin\theta\cos\phi\,i + r\sin\theta\sin\phi\,j + r\cos\theta\,k$$
3. Differentiate w.r.t $\phi$:
$$\frac{\partial\bar{r}}{\partial\phi} = -(2 - r\cos\theta)\sin\phi\,i + (2 - r\cos\theta)\cos\phi\,j + 0\,k$$
Step 2: Compute Scale Factors ($h_1, h_2, h_3$)
$$h_1 = \left|\frac{\partial\bar{r}}{\partial r}\right| = \sqrt{\cos^2\theta\cos^2\phi + \cos^2\theta\sin^2\phi + \sin^2\theta} = \sqrt{\cos^2\theta(\cos^2\phi+\sin^2\phi) + \sin^2\theta} = \sqrt{\cos^2\theta + \sin^2\theta} = 1$$
$$h_2 = \left|\frac{\partial\bar{r}}{\partial\theta}\right| = \sqrt{r^2\sin^2\theta\cos^2\phi + r^2\sin^2\theta\sin^2\phi + r^2\cos^2\theta} = \sqrt{r^2\sin^2\theta + r^2\cos^2\theta} = \sqrt{r^2} = r$$
$$h_3 = \left|\frac{\partial\bar{r}}{\partial\phi}\right| = \sqrt{(2-r\cos\theta)^2\sin^2\phi + (2-r\cos\theta)^2\cos^2\phi + 0} = \sqrt{(2-r\cos\theta)^2} = 2 - r\cos\theta$$
Scale Factors Verified: $h_1 = 1, \quad h_2 = r, \quad h_3 = 2 - r\cos\theta$
Step 3: Prove Orthogonality via Dot Products
Test 1: $\frac{\partial\bar{r}}{\partial r}\cdot\frac{\partial\bar{r}}{\partial\theta}$:
$$\frac{\partial\bar{r}}{\partial r}\cdot\frac{\partial\bar{r}}{\partial\theta} = (-\cos\theta\cos\phi)(r\sin\theta\cos\phi) + (-\cos\theta\sin\phi)(r\sin\theta\sin\phi) + (\sin\theta)(r\cos\theta)$$ $$= -r\sin\theta\cos\theta(\cos^2\phi + \sin^2\phi) + r\sin\theta\cos\theta = -r\sin\theta\cos\theta + r\sin\theta\cos\theta = 0$$
Test 2: $\frac{\partial\bar{r}}{\partial r}\cdot\frac{\partial\bar{r}}{\partial\phi}$:
$$\frac{\partial\bar{r}}{\partial r}\cdot\frac{\partial\bar{r}}{\partial\phi} = (-\cos\theta\cos\phi)[-(2-r\cos\theta)\sin\phi] + (-\cos\theta\sin\phi)[(2-r\cos\theta)\cos\phi] + 0$$ $$= (2-r\cos\theta)\cos\theta\sin\phi\cos\phi - (2-r\cos\theta)\cos\theta\sin\phi\cos\phi = 0$$
Test 3: $\frac{\partial\bar{r}}{\partial\theta}\cdot\frac{\partial\bar{r}}{\partial\phi}$:
$$\frac{\partial\bar{r}}{\partial\theta}\cdot\frac{\partial\bar{r}}{\partial\phi} = (r\sin\theta\cos\phi)[-(2-r\cos\theta)\sin\phi] + (r\sin\theta\sin\phi)[(2-r\cos\theta)\cos\phi] + 0$$ $$= -r\sin\theta(2-r\cos\theta)\cos\phi\sin\phi + r\sin\theta(2-r\cos\theta)\cos\phi\sin\phi = 0$$
Q.E.D. The Coordinate System is Orthogonal!
