حل شيت 3: التكامل الثنائي (Double Integral)

حلول تفصيلية نموذجية خطوة بخطوة للتكاملات الثنائية، تبديل ترتيب التكامل، والإحداثيات القطبية وتطبيقات المساحات.

⚡ Double Integral Cheat Sheet & Formulas
1. Polar Transformation
$$x = r\cos\theta, \quad y = r\sin\theta, \quad x^2 + y^2 = r^2$$
$$dx\,dy = r\,dr\,d\theta \quad \text{(Multiply by } r \text{)}$$
• First quadrant: $\theta \in [0, \pi/2]$ | Upper semi-disc: $\theta \in [0, \pi]$ | Full disc: $\theta \in [0, 2\pi]$
2. Change of Order of Integration
$$\int_{a}^{b}\left[\int_{g_1(x)}^{g_2(x)} f(x,y)\,dy\right]dx \quad \Longleftrightarrow \quad \int_{c}^{d}\left[\int_{h_1(y)}^{h_2(y)} f(x,y)\,dx\right]dy$$
• Used when the inner integral has no elementary antiderivative: $\int e^{y/x}dx$ or $\int \frac{\sinh x}{x^2}dx$ or $\int \sin(x^3)dx$.
3. General Transformation & Jacobian
$$dx\,dy = \left|J\left(\frac{x,y}{u,v}\right)\right| du\,dv = \frac{1}{\left|J\left(\frac{u,v}{x,y}\right)\right|} du\,dv$$
$$J\left(\frac{u,v}{x,y}\right) = \begin{vmatrix} u_x & u_y \\ v_x & v_y \end{vmatrix} = u_x v_y - u_y v_x$$
4. Area by Double Integral
$$\text{Area} = \iint_{D} dx\,dy = \iint_{D} r\,dr\,d\theta$$
5. Essential Trigonometric Identities
$$\cos^2\theta = \frac{1 + \cos 2\theta}{2}, \quad \sin^2\theta = \frac{1 - \cos 2\theta}{2}, \quad \sin\theta\cos\theta = \frac{\sin 2\theta}{2}$$
📌 Question 1: (i) to (iii) Direct Iterated Integrals
(i) $\int_{0}^{1}\int_{0}^{2} (12xy)\,dx\,dy$
(ii) $\int_{0}^{1}\int_{0}^{2} (12x^3 y)\,dy\,dx$
(iii) $\int_{0}^{1}\int_{0}^{x} (x + e^y)\,dy\,dx$
(i) Evaluate $\int_{0}^{1}\int_{0}^{2} (12xy)\,dx\,dy$
Step 1: Inner integral with respect to $x$:
$$\int_{0}^{2} 12xy\,dx = 12y \left[\frac{x^2}{2}\right]_{0}^{2} = 12y \cdot \frac{4}{2} = 24y$$
Step 2: Outer integral with respect to $y$:
$$\int_{0}^{1} 24y\,dy = 24\left[\frac{y^2}{2}\right]_{0}^{1} = 24 \cdot \frac{1}{2} = 12$$
Answer = 12
(ii) Evaluate $\int_{0}^{1}\int_{0}^{2} (12x^3 y)\,dy\,dx$
Step 1: Inner integral with respect to $y$:
$$\int_{0}^{2} 12x^3 y\,dy = 12x^3 \left[\frac{y^2}{2}\right]_{0}^{2} = 12x^3 \cdot \frac{4}{2} = 24x^3$$
Step 2: Outer integral with respect to $x$:
$$\int_{0}^{1} 24x^3\,dx = 24\left[\frac{x^4}{4}\right]_{0}^{1} = 24 \cdot \frac{1}{4} = 6$$
Answer = 6
(iii) Evaluate $\int_{0}^{1}\int_{0}^{x} (x + e^y)\,dy\,dx$
Step 1: Inner integral with respect to $y$:
$$\int_{0}^{x} (x + e^y)\,dy = \left[xy + e^y\right]_{0}^{x} = (x^2 + e^x) - (0 + e^0) = x^2 + e^x - 1$$
Step 2: Outer integral with respect to $x$:
$$\int_{0}^{1} (x^2 + e^x - 1)\,dx = \left[\frac{x^3}{3} + e^x - x\right]_{0}^{1} = \left(\frac{1}{3} + e - 1\right) - (0 + 1 - 0) = e - \frac{5}{3}$$
Answer = $e - \frac{5}{3}$
📌 Question 1: (iv) to (vi) Direct Iterated Integrals
(iv) $\int_{0}^{1}\int_{0}^{2y} (2xy)\,dx\,dy$
(v) $\int_{1}^{2}\int_{0}^{x} (x^3 - y)\,dy\,dx$
(vi) $\int_{1}^{2}\int_{1}^{x} \frac{x}{y}\,dy\,dx$
(iv) Evaluate $\int_{0}^{1}\int_{0}^{2y} (2xy)\,dx\,dy$
$$\int_{0}^{2y} 2xy\,dx = 2y \left[\frac{x^2}{2}\right]_{0}^{2y} = y(2y)^2 = 4y^3$$
$$\int_{0}^{1} 4y^3\,dy = \left[y^4\right]_{0}^{1} = 1$$
Answer = 1
(v) Evaluate $\int_{1}^{2}\int_{0}^{x} (x^3 - y)\,dy\,dx$
$$\int_{0}^{x} (x^3 - y)\,dy = \left[x^3 y - \frac{y^2}{2}\right]_{0}^{x} = x^4 - \frac{x^2}{2}$$
$$\int_{1}^{2} \left(x^4 - \frac{x^2}{2}\right)dx = \left[\frac{x^5}{5} - \frac{x^3}{6}\right]_{1}^{2} = \left(\frac{32}{5} - \frac{8}{6}\right) - \left(\frac{1}{5} - \frac{1}{6}\right) = \frac{31}{5} - \frac{7}{6} = \frac{151}{30}$$
Answer = $\frac{151}{30}$
(vi) Evaluate $\int_{1}^{2}\int_{1}^{x} \frac{x}{y}\,dy\,dx$
$$\int_{1}^{x} \frac{x}{y}\,dy = x \left[\ln y\right]_{1}^{x} = x(\ln x - \ln 1) = x\ln x$$
Integration by parts for $x\ln x$: $u=\ln x, dv=x\,dx \implies du=\frac{1}{x}dx, v=\frac{x^2}{2}$:
$$\int x\ln x\,dx = \frac{x^2}{2}\ln x - \int \frac{x}{2}\,dx = \frac{x^2}{2}\ln x - \frac{x^2}{4}$$
$$\left[\frac{x^2}{2}\ln x - \frac{x^2}{4}\right]_{1}^{2} = (2\ln 2 - 1) - \left(0 - \frac{1}{4}\right) = 2\ln 2 - \frac{3}{4}$$
Answer = $2\ln 2 - \frac{3}{4}$
📌 Question 1: (vii) to (ix) Direct Iterated Integrals
(vii) $\int_{1}^{2}\int_{1-x}^{\sqrt{x}} x^2 y\,dy\,dx$
(viii) $\int_{0}^{1}\int_{0}^{y^2} \frac{3}{4+y^3}\,dx\,dy$
(ix) $\int_{1}^{2}\int_{1}^{y} \frac{y}{x+1}\,dx\,dy$
(vii) Evaluate $\int_{1}^{2}\int_{1-x}^{\sqrt{x}} x^2 y\,dy\,dx$
$$\int_{1-x}^{\sqrt{x}} x^2 y\,dy = x^2 \left[\frac{y^2}{2}\right]_{1-x}^{\sqrt{x}} = \frac{x^2}{2}\left(x - (1-x)^2\right) = \frac{x^2}{2}(-x^2 + 3x - 1) = -\frac{x^4}{2} + \frac{3x^3}{2} - \frac{x^2}{2}$$
$$\int_{1}^{2} \left(-\frac{x^4}{2} + \frac{3x^3}{2} - \frac{x^2}{2}\right)dx = \left[-\frac{x^5}{10} + \frac{3x^4}{8} - \frac{x^3}{6}\right]_{1}^{2} = \frac{163}{120}$$
Answer = $\frac{163}{120}$
(viii) Evaluate $\int_{0}^{1}\int_{0}^{y^2} \frac{3}{4+y^3}\,dx\,dy$
$$\int_{0}^{y^2} \frac{3}{4+y^3}\,dx = \frac{3}{4+y^3} [x]_{0}^{y^2} = \frac{3y^2}{4+y^3}$$
$$\int_{0}^{1} \frac{3y^2}{4+y^3}\,dy = \left[\ln(4+y^3)\right]_{0}^{1} = \ln 5 - \ln 4 = \ln\left(\frac{5}{4}\right)$$
Answer = $\ln(5/4)$
(ix) Evaluate $\int_{1}^{2}\int_{1}^{y} \frac{y}{x+1}\,dx\,dy$
$$\int_{1}^{y} \frac{y}{x+1}\,dx = y \left[\ln(x+1)\right]_{1}^{y} = y[\ln(y+1) - \ln 2]$$
$$\int_{1}^{2} y\ln(y+1)\,dy - \ln 2\int_{1}^{2} y\,dy = \left[\frac{y^2-1}{2}\ln(y+1) - \frac{(y-1)^2}{4}\right]_{1}^{2} - \frac{3}{2}\ln 2 = \frac{3}{2}\ln\left(\frac{3}{2}\right) - \frac{1}{4}$$
Answer = $\frac{3}{2}\ln(3/2) - \frac{1}{4}$
📌 Question 2: (i) to (iv) Changing Order of Integration
(i) $\int_{0}^{\infty}\int_{x}^{\infty} \frac{x}{y}e^{-y}\,dy\,dx$
(ii) $\int_{0}^{1}\int_{0}^{\cos^{-1}y} e^{\sin x}\,dx\,dy$
(iii) $\int_{1}^{2}\int_{x^2}^{x} e^{y/x}\,dy\,dx$
(iv) $\int_{-\pi/2}^{\pi/2}\int_{2}^{2(1+\cos\theta)} r\,dr\,d\theta$
(i) Evaluate $\int_{0}^{\infty}\int_{x}^{\infty} \frac{x}{y}e^{-y}\,dy\,dx$
Region: $0 \le x \le y < \infty$. Reversing order: $0 \le y < \infty$ and $0 \le x \le y$:
$$I = \int_{0}^{\infty} \left[\int_{0}^{y} \frac{x}{y}e^{-y}\,dx\right]dy = \int_{0}^{\infty} \frac{e^{-y}}{y}\left(\frac{y^2}{2}\right)dy = \frac{1}{2}\int_{0}^{\infty} y e^{-y}\,dy = \frac{1}{2}(1!) = \frac{1}{2}$$
Answer = $1/2$
(ii) Evaluate $\int_{0}^{1}\int_{0}^{\cos^{-1}y} e^{\sin x}\,dx\,dy$
Region: $0 \le y \le 1, 0 \le x \le \cos^{-1}y \implies y = \cos x$. New bounds: $0 \le x \le \pi/2$ and $0 \le y \le \cos x$:
$$I = \int_{0}^{\pi/2} \left[\int_{0}^{cos x} e^{\sin x}\,dy\right]dx = \int_{0}^{\pi/2} \cos x \cdot e^{\sin x}\,dx = \left[e^{\sin x}\right]_{0}^{\pi/2} = e - 1$$
Answer = $e - 1$
(iii) Evaluate $\int_{1}^{2}\int_{x^2}^{x} e^{y/x}\,dy\,dx$
$$\int_{x^2}^{x} e^{y/x}\,dy = \left[x e^{y/x}\right]_{x^2}^{x} = x(e - e^x) = ex - x e^x$$
$$\int_{1}^{2} (ex - x e^x)\,dx = \left[\frac{e x^2}{2} - (x e^x - e^x)\right]_{1}^{2} = \frac{3e}{2} - e^2$$
Answer = $\frac{3e}{2} - e^2$
(iv) Evaluate $\int_{-\pi/2}^{\pi/2}\int_{2}^{2(1+\cos\theta)} r\,dr\,d\theta$
$$\int_{2}^{2(1+\cos\theta)} r\,dr = \left[\frac{r^2}{2}\right]_{2}^{2(1+\cos\theta)} = 2(1+\cos\theta)^2 - 2 = 4\cos\theta + 2\cos^2\theta$$
$$\int_{-\pi/2}^{\pi/2} (4\cos\theta + 1 + \cos 2\theta)\,d\theta = \left[4\sin\theta + \theta + \frac{\sin 2\theta}{2}\right]_{-\pi/2}^{\pi/2} = 8 + \pi$$
Answer = $8 + \pi$
📌 Question 2: (v) to (ix) Changing Order of Integration
(v) $\int_{0}^{1}\int_{0}^{(\cos^{-1}y)^2} \tan\sqrt{x}\,dx\,dy$
(vi) $\int_{0}^{4}\int_{\sqrt{y}}^{2} \frac{\sinh x}{x^2}\,dx\,dy$
(vii) $\int_{0}^{4}\int_{\sqrt{x}}^{2} \frac{x e^{y^2}}{y^3}\,dy\,dx$
(viii) $\int_{0}^{9}\int_{\sqrt{y}}^{3} \sin(x^3)\,dx\,dy$
(ix) $\int_{0}^{1}\int_{x^2}^{1} x^3 \sin(y^3)\,dy\,dx$
(v) Evaluate $\int_{0}^{1}\int_{0}^{(\cos^{-1}y)^2} \tan\sqrt{x}\,dx\,dy$
New bounds: $0 \le x \le \pi^2/4$ and $0 \le y \le \cos\sqrt{x}$:
$$I = \int_{0}^{\pi^2/4} \cos\sqrt{x}\tan\sqrt{x}\,dx = \int_{0}^{\pi^2/4} \sin\sqrt{x}\,dx = \int_{0}^{\pi/2} 2t\sin t\,dt = 2$$
Answer = 2
(vi) Evaluate $\int_{0}^{4}\int_{\sqrt{y}}^{2} \frac{\sinh x}{x^2}\,dx\,dy$
New bounds: $0 \le x \le 2$ and $0 \le y \le x^2$:
$$I = \int_{0}^{2} \left[\int_{0}^{x^2} \frac{\sinh x}{x^2}\,dy\right]dx = \int_{0}^{2} \sinh x\,dx = [\cosh x]_{0}^{2} = \cosh 2 - 1$$
Answer = $\cosh 2 - 1$
(vii) Evaluate $\int_{0}^{4}\int_{\sqrt{x}}^{2} \frac{x e^{y^2}}{y^3}\,dy\,dx$
New bounds: $0 \le y \le 2$ and $0 \le x \le y^2$:
$$I = \int_{0}^{2} \frac{e^{y^2}}{y^3}\left(\frac{y^4}{2}\right)dy = \frac{1}{2}\int_{0}^{2} y e^{y^2}\,dy = \frac{e^4 - 1}{4}$$
Answer = $\frac{e^4 - 1}{4}$
(viii) Evaluate $\int_{0}^{9}\int_{\sqrt{y}}^{3} \sin(x^3)\,dx\,dy$
New bounds: $0 \le x \le 3$ and $0 \le y \le x^2$:
$$I = \int_{0}^{3} x^2 \sin(x^3)\,dx = \left[-\frac{\cos(x^3)}{3}\right]_{0}^{3} = \frac{1 - \cos 27}{3}$$
Answer = $\frac{1 - \cos 27}{3}$
(ix) Evaluate $\int_{0}^{1}\int_{x^2}^{1} x^3 \sin(y^3)\,dy\,dx$
New bounds: $0 \le y \le 1$ and $0 \le x \le \sqrt{y}$:
$$I = \int_{0}^{1} \sin(y^3)\left(\frac{y^2}{4}\right)dy = \frac{1}{12}\left[-\cos(y^3)\right]_{0}^{1} = \frac{1 - \cos 1}{12}$$
Answer = $\frac{1 - \cos 1}{12}$
📌 Question 3: (i) to (iii) Circular Regions in Polar Form
(i) $\int_{0}^{1}\int_{0}^{\sqrt{1-x^2}} \sqrt{x^2+y^2}\,dy\,dx$
(ii) $\int_{-1}^{1}\int_{0}^{\sqrt{1-x^2}} \sqrt{x^2+y^2}\,dy\,dx$
(iii) $\int_{0}^{1}\int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}} \sqrt{x^2+y^2}\,dy\,dx$
(i) First Quadrant ($R=1$)
$$I = \int_{0}^{\pi/2} d\theta \int_{0}^{1} r^2\,dr = \frac{\pi}{2} \cdot \frac{1}{3} = \frac{\pi}{6}$$
Answer = $\pi/6$
(ii) Upper Semi-Circle ($R=1$)
$$I = \int_{0}^{\pi} d\theta \int_{0}^{1} r^2\,dr = \pi \cdot \frac{1}{3} = \frac{\pi}{3}$$
Answer = $\pi/3$
(iii) Right Semi-Circle ($R=1$)
$$I = \int_{-\pi/2}^{\pi/2} d\theta \int_{0}^{1} r^2\,dr = \pi \cdot \frac{1}{3} = \frac{\pi}{3}$$
Answer = $\pi/3$
📌 Question 3: (iv) to (vi) Rational Integrands in Polar Form
(iv) $\int_{0}^{1}\int_{0}^{\sqrt{1-y^2}} \frac{dx\,dy}{\sqrt{x^2+y^2}}$
(v) $\int_{0}^{1}\int_{0}^{\sqrt{1-y^2}} \frac{xy}{\sqrt{x^2+y^2}}\,dx\,dy$
(vi) $\int_{0}^{2}\int_{0}^{\sqrt{4-x^2}} \frac{x+y}{\sqrt{x^2+y^2}}\,dy\,dx$
(iv) First Quadrant Quarter-Disc ($R=1$)
$$I = \int_{0}^{\pi/2} d\theta \int_{0}^{1} \frac{1}{r} \cdot r\,dr = \frac{\pi}{2} \cdot 1 = \frac{\pi}{2}$$
Answer = $\pi/2$
(v) First Quadrant Quarter-Disc ($R=1$)
$$I = \int_{0}^{\pi/2} \frac{\sin 2\theta}{2}\,d\theta \int_{0}^{1} r^2\,dr = \frac{1}{2} \cdot \frac{1}{3} = \frac{1}{6}$$
Answer = $1/6$
(vi) First Quadrant Quarter-Disc ($R=2$)
$$I = \int_{0}^{\pi/2} (\cos\theta + \sin\theta)\,d\theta \int_{0}^{2} r\,dr = 2 \cdot 2 = 4$$
Answer = 4
📌 Question 4: Region bounded by Parabolas
Evaluate $\iint_{D} (2x + 3y^2)\,dx\,dy$, where $D$ is bounded by $y=x^3$ and $y=x^2$ for $x \in [0,1]$.
Limits of Integration
For $x \in [0,1]$, $x^3 \le y \le x^2$:
$$I = \int_{0}^{1} \left[\int_{x^3}^{x^2} (2x + 3y^2)\,dy\right] dx = \int_{0}^{1} (2x^3 - 2x^4 + x^6 - x^9)\,dx = \frac{1}{7}$$
Answer = $1/7$
📌 Question 5: Triangular Region
Evaluate $\iint_{D} (x^2 y)\,dx\,dy$, where $D$ is bounded by $y=0$, $y=x$, and $x+y=2$.
Integration along horizontal strips
Integrating with respect to $x$ first: $y \le x \le 2-y$, with $0 \le y \le 1$:
$$I = \int_{0}^{1} y \left[\int_{y}^{2-y} x^2\,dx\right] dy = \frac{1}{3}\int_{0}^{1} (8y - 12y^2 + 6y^3 - 2y^4)\,dy = \frac{11}{30}$$
Answer = $11/30$
📌 Questions 6 & 7: Annular Region Integrals
(6) Evaluate $\iint_{D} \sqrt{x^2+y^2}\,dx\,dy$
(7) Evaluate $\iint_{D} (x+y)\,dx\,dy$
where $D$ is bounded by $4 \le x^2+y^2 \le 9$.
Solution for Question 6
In Polar coordinates: $2 \le r \le 3$, and $0 \le \theta \le 2\pi$:
$$I = \int_{0}^{2\pi} d\theta \int_{2}^{3} r^2\,dr = 2\pi \left(\frac{27 - 8}{3}\right) = \frac{38\pi}{3}$$
Answer = $\frac{38\pi}{3}$
Solution for Question 7
$$I = \int_{0}^{2\pi} (\cos\theta + \sin\theta)\,d\theta \int_{2}^{3} r^2\,dr = 0 \cdot \left(\frac{19}{3}\right) = 0$$
Answer = 0 (by symmetry)
📌 Question 8: Area between Standard Parabolas
Find the area of the region bounded by $y=x^2$ and $x=y^2$.
Formulation and Integration
Intersection points: $(0,0)$ and $(1,1)$:
$$A = \int_{0}^{1} (\sqrt{x} - x^2)\,dx = \left[\frac{2}{3}x^{3/2} - \frac{x^3}{3}\right]_{0}^{1} = \frac{1}{3}$$
Area = $1/3$
📌 Question 9: Area via Jacobian Transformation
Find the area of the region bounded by $y=x^2$, $4y=x^2$, $x=y^2$, and $4x=y^2$.
Transformation of Variables (Jacobian Method)
Let $u = \frac{x^2}{y} \in [1,4]$ and $v = \frac{y^2}{x} \in [1,4]$:
$$J\left(\frac{u,v}{x,y}\right) = \begin{vmatrix} \frac{2x}{y} & -\frac{x^2}{y^2} \\ -\frac{y^2}{x^2} & \frac{2y}{x} \end{vmatrix} = 4 - 1 = 3 \implies J\left(\frac{x,y}{u,v}\right) = \frac{1}{3}$$
$$A = \int_{1}^{4}\int_{1}^{4} \frac{1}{3}\,du\,dv = \frac{1}{3}(3)(3) = 3$$
Area = 3
