⚡ Functions of Several Variables Cheat Sheet & Rules
1. Implicit Differentiation Formulas
$$\text{If } F(x,y) = 0 \implies \frac{dy}{dx} = -\frac{F_x}{F_y}$$
$$\text{If } F(x,y,z) = 0 \implies \frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$
• يتم اشتقاق الدالة $F$ جزئياً بالنسبة للمتغير المطلوب مع اعتبار باقي المتغيرات ثوابت.
2. Euler's Theorem for Homogeneous Functions
$$f(tx, ty) = t^k f(x,y) \implies x \frac{\partial f}{\partial x} + y \frac{\partial f}{\partial y} = k f(x,y)$$
$$\text{In 3 variables: } x f_x + y f_y + z f_z = k f(x,y,z)$$
• إذا كانت الدالة داخلية مثل $u = \tan^{-1}(S)$ أو $\ln(S)$؛ نطبق نظرية أويلر على الدالة المتجانسة $S$ أولاً.
3. Clairaut's Theorem & Laplace's Equation
$$\text{Symmetry of Second Partials: } f_{xy} = f_{yx} \quad \left(\frac{\partial^2 f}{\partial y \partial x} = \frac{\partial^2 f}{\partial x \partial y}\right)$$
$$\text{Laplace's Equation (Harmonic function): } f_{xx} + f_{yy} = 0 \quad (\nabla^2 f = 0)$$
4. Envelope of a Family of Curves
$$\text{Family: } F(x, y, c) = 0 \quad \text{and} \quad \frac{\partial F}{\partial c}(x, y, c) = 0$$
• يتم إيجاد الوسيط $c$ من المعادلة التفاضلية والتعويض به في المعادلة الأصلية لحذفه والحصول على معادلة الغلاف.
5. Extrema and Saddle Points (Second Derivative Test)
1. نجد النقط الحرجة (Critical Points) بحل: $f_x = 0$ و $f_y = 0$.
2. نحسب المميز: $\Delta = f_{xx} f_{yy} - (f_{xy})^2$.
$$\Delta > 0 \text{ and } f_{xx} > 0 \implies \mathbf{Local\,\,Minimum}$$ $$\Delta > 0 \text{ and } f_{xx} < 0 \implies \mathbf{Local\,\,Maximum}$$ $$\Delta < 0 \implies \mathbf{Saddle\,\,Point}, \qquad \Delta = 0 \implies \mathbf{Inconclusive}$$
6. Lagrange Multipliers for Constrained Extrema
$$\nabla f = \lambda \nabla g \implies f_x = \lambda g_x, \quad f_y = \lambda g_y, \quad f_z = \lambda g_z \quad \text{subject to } g = 0$$
• تستخدم لإيجاد القيم العظمى أو الصغرى المقيدة بشرط (مثل مسافة، حجم صندوق، أو مساحة).
7. Jacobian & Hessian Matrix
$$J\left(\frac{f,g}{x,y}\right) = \begin{vmatrix} f_x & f_y \\ g_x & g_y \end{vmatrix}, \qquad H(f) = \begin{bmatrix} f_{xx} & f_{xy} \\ f_{yx} & f_{yy} \end{bmatrix}$$
📌 Q1: (i) & (ii) First Partial Derivatives
(i) $f(x,y) = x^2 + y^4 + xy + 3$
(ii) $f(x,y,z) = 3^x + xy^4 + z^3 \ln y$
Solution for (i): $f(x,y) = x^2 + y^4 + xy + 3$
Differentiate w.r.t $x$ (treating $y$ as a constant):
$$f_x = \frac{\partial}{\partial x}(x^2) + \frac{\partial}{\partial x}(y^4) + \frac{\partial}{\partial x}(xy) + \frac{\partial}{\partial x}(3) = 2x + 0 + y(1) + 0 = 2x + y$$
Differentiate w.r.t $y$ (treating $x$ as a constant):
$$f_y = \frac{\partial}{\partial y}(x^2) + \frac{\partial}{\partial y}(y^4) + \frac{\partial}{\partial y}(xy) + \frac{\partial}{\partial y}(3) = 0 + 4y^3 + x(1) + 0 = 4y^3 + x$$
Answer: $f_x = 2x + y, \quad f_y = 4y^3 + x$
Solution for (ii): $f(x,y,z) = 3^x + xy^4 + z^3 \ln y$
Derivative w.r.t $x$:
$$f_x = \frac{\partial}{\partial x}(3^x) + \frac{\partial}{\partial x}(xy^4) + \frac{\partial}{\partial x}(z^3 \ln y) = 3^x \ln 3 + y^4 + 0 = 3^x \ln 3 + y^4$$
Derivative w.r.t $y$:
$$f_y = 0 + x(4y^3) + z^3\left(\frac{1}{y}\right) = 4xy^3 + \frac{z^3}{y}$$
Derivative w.r.t $z$:
$$f_z = 0 + 0 + (3z^2)\ln y = 3z^2 \ln y$$
Answer: $f_x = 3^x \ln 3 + y^4, \quad f_y = 4xy^3 + \frac{z^3}{y}, \quad f_z = 3z^2 \ln y$
📌 Q1: (iii) & (iv) First Partial Derivatives
(iii) $f(x,y) = \cos x + y \sin y$
(iv) $f(x,y,z) = x^4 \sin z + 3z \sinh(2y)$
Solution for (iii): $f(x,y) = \cos x + y \sin y$
$$f_x = -\sin x + 0 = -\sin x$$
Product rule for $y\sin y$:
$$f_y = 0 + \left[1 \cdot \sin y + y \cos y\right] = \sin y + y \cos y$$
Answer: $f_x = -\sin x, \quad f_y = \sin y + y \cos y$
Solution for (iv): $f(x,y,z) = x^4 \sin z + 3z \sinh(2y)$
$$f_x = 4x^3 \sin z + 0 = 4x^3 \sin z$$
$$f_y = 0 + 3z[\cosh(2y) \cdot 2] = 6z \cosh(2y)$$
$$f_z = x^4 \cos z + 3(1)\sinh(2y) = x^4 \cos z + 3 \sinh(2y)$$
Answer: $f_x = 4x^3 \sin z, \quad f_y = 6z \cosh(2y), \quad f_z = x^4 \cos z + 3 \sinh(2y)$
📌 Q1: (v) & (vi) First Partial Derivatives
(v) $f(x,y) = e^x + 2y^4 + x \cdot 3^y$
(vi) $f(x,y,z) = 2x^4 + \ln(3y + z^3)$
Solution for (v): $f(x,y) = e^x + 2y^4 + x \cdot 3^y$
$$f_x = e^x + 0 + (1 \cdot 3^y) = e^x + 3^y$$
$$f_y = 0 + 8y^3 + x(3^y \ln 3) = 8y^3 + x \cdot 3^y \ln 3$$
Answer: $f_x = e^x + 3^y, \quad f_y = 8y^3 + x \cdot 3^y \ln 3$
Solution for (vi): $f(x,y,z) = 2x^4 + \ln(3y + z^3)$
$$f_x = 8x^3 + 0 = 8x^3$$
$$f_y = 0 + \frac{3}{3y + z^3} = \frac{3}{3y + z^3}$$
$$f_z = 0 + \frac{3z^2}{3y + z^3} = \frac{3z^2}{3y + z^3}$$
Answer: $f_x = 8x^3, \quad f_y = \frac{3}{3y+z^3}, \quad f_z = \frac{3z^2}{3y+z^3}$
📌 Q1: (vii), (viii/x) & (ix) First Partial Derivatives

$$f_y = -3y^{-4} + 0 = -\frac{3}{y^4}$$
Answer: $f_x = \cosh x + x \sinh x, \quad f_y = -\frac{3}{y^4}$

$$f_x = [1 \cdot e^x + x e^x] + 0 - 0 = (1+x)e^x$$
$$f_y = 0 + 0 - \cosh(yz) \cdot z = -z \cosh(yz)$$
$$f_z = 0 + 3 - \cosh(yz) \cdot y = 3 - y \cosh(yz)$$
Answer: $f_x = (1+x)e^x, \quad f_y = -z\cosh(yz), \quad f_z = 3 - y\cosh(yz)$

$$f_y = x \cdot \frac{2y+1}{y^2+y} + (1)\sinh x = \frac{x(2y+1)}{y^2+y} + \sinh x$$
Answer: $f_x = \ln(y^2+y) + y\cosh x, \quad f_y = \frac{x(2y+1)}{y^2+y} + \sinh x$
📌 Q2: (a) & (b) Second Partial Derivatives ($f_{xx}, f_{yy}, f_{xy}, f_{yx}$)
Find $f_{xx}, f_{yy}, f_{xy}, f_{yx}$ for:
(a) $f(x,y) = x^3 + y^4 + xy + 3$
(b) $f(x,y) = 3^x + xy^4 + \ln y$
Full Solution for (a): $f(x,y) = x^3 + y^4 + xy + 3$
1. First order derivatives:
$$f_x = 3x^2 + y, \quad f_y = 4y^3 + x$$
2. Second order pure derivatives:
$$f_{xx} = \frac{\partial}{\partial x}(3x^2 + y) = 6x$$
$$f_{yy} = \frac{\partial}{\partial y}(4y^3 + x) = 12y^2$$
3. Second order mixed derivatives:
$$f_{xy} = \frac{\partial}{\partial y}(3x^2 + y) = 1, \quad f_{yx} = \frac{\partial}{\partial x}(4y^3 + x) = 1$$
Verified: $f_{xy} = f_{yx} = 1$
Full Solution for (b): $f(x,y) = 3^x + xy^4 + \ln y$
$$f_x = 3^x \ln 3 + y^4 \implies f_{xx} = 3^x (\ln 3)^2$$
$$f_y = 4xy^3 + \frac{1}{y} \implies f_{yy} = 12xy^2 - \frac{1}{y^2}$$
$$f_{xy} = \frac{\partial}{\partial y}(3^x \ln 3 + y^4) = 4y^3, \quad f_{yx} = \frac{\partial}{\partial x}\left(4xy^3 + \frac{1}{y}\right) = 4y^3$$
Verified: $f_{xy} = f_{yx} = 4y^3$

📌 Q3: Show that $f_{xx} + f_{yy} = 0$ (Laplace's Equation)
(a) $f(x,y) = 2x + e^y \cos x$
(b) $f(x,y) = 3x^2 - 3y^2 + x - 2y + 6$
Detailed Proof for (a): $f(x,y) = 2x + e^y \cos x$
$$f_x = 2 - e^y \sin x \implies f_{xx} = -e^y \cos x$$
$$f_y = e^y \cos x \implies f_{yy} = e^y \cos x$$
$$f_{xx} + f_{yy} = (-e^y \cos x) + (e^y \cos x) = 0$$
Q.E.D. Laplace's Equation Holds: $f_{xx} + f_{yy} = 0$
Detailed Proof for (b): $f(x,y) = 3x^2 - 3y^2 + x - 2y + 6$
$$f_x = 6x + 1 \implies f_{xx} = 6$$
$$f_y = -6y - 2 \implies f_{yy} = -6$$
$$f_{xx} + f_{yy} = 6 + (-6) = 0$$
Q.E.D. Laplace's Equation Holds: $f_{xx} + f_{yy} = 0$
📌 Q4: (a) & (b) Implicit Differentiation $\frac{dy}{dx} = -\frac{F_x}{F_y}$
(a) $x^3 + y^4 + x \tanh y = 3$
(b) $3^x \sin y + x y^4 + \ln y = 0$
Full Solution for (a): $x^3 + y^4 + x \tanh y = 3$
$$F(x,y) = x^3 + y^4 + x \tanh y - 3 = 0$$
$$F_x = 3x^2 + \tanh y, \quad F_y = 4y^3 + x \operatorname{sech}^2 y$$
$$\frac{dy}{dx} = -\frac{F_x}{F_y} = -\frac{3x^2 + \tanh y}{4y^3 + x \operatorname{sech}^2 y}$$
Final Answer: $\frac{dy}{dx} = -\frac{3x^2 + \tanh y}{4y^3 + x\operatorname{sech}^2 y}$
Full Solution for (b): $3^x \sin y + x y^4 + \ln y = 0$
$$F_x = 3^x \ln 3 \sin y + y^4, \quad F_y = 3^x \cos y + 4xy^3 + \frac{1}{y}$$
$$\frac{dy}{dx} = -\frac{F_x}{F_y} = -\frac{3^x \ln 3 \sin y + y^4}{3^x \cos y + 4xy^3 + \frac{1}{y}} = -\frac{y(3^x \ln 3 \sin y + y^4)}{y \cdot 3^x \cos y + 4xy^4 + 1}$$
Final Answer: $\frac{dy}{dx} = -\frac{y(3^x \ln 3 \sin y + y^4)}{y 3^x \cos y + 4xy^4 + 1}$
📌 Q4: (c) & (d) Implicit Differentiation $\frac{dy}{dx}$
(c) $y \cosh(x^3) + x \sin y = 8$
(d) $x \sin x + y \cos y = 0$
Full Solution for (c): $y \cosh(x^3) + x \sin y - 8 = 0$
$$F_x = 3x^2 y \sinh(x^3) + \sin y, \quad F_y = \cosh(x^3) + x \cos y$$
$$\frac{dy}{dx} = -\frac{F_x}{F_y} = -\frac{3x^2 y \sinh(x^3) + \sin y}{\cosh(x^3) + x \cos y}$$
Final Answer: $\frac{dy}{dx} = -\frac{3x^2 y \sinh(x^3) + \sin y}{\cosh(x^3) + x \cos y}$
Full Solution for (d): $x \sin x + y \cos y = 0$
$$F_x = \sin x + x \cos x, \quad F_y = \cos y - y \sin y$$
$$\frac{dy}{dx} = -\frac{F_x}{F_y} = -\frac{\sin x + x \cos x}{\cos y - y \sin y} = \frac{\sin x + x \cos x}{y \sin y - \cos y}$$
Final Answer: $\frac{dy}{dx} = \frac{\sin x + x \cos x}{y \sin y - \cos y}$
📌 Q4: (e) & (f) Implicit Differentiation $\frac{dy}{dx}$
(e) $x^2 + y^4 + x e^y + 4 = 0$
(f) $2x^4 + \ln(x + y^3) - 2y = 0$
Full Solution for (e): $x^2 + y^4 + x e^y + 4 = 0$

$$\frac{dy}{dx} = -\frac{F_x}{F_y} = -\frac{2x + e^y}{4y^3 + x e^y}$$
Final Answer: $\frac{dy}{dx} = -\frac{2x + e^y}{4y^3 + x e^y}$
Full Solution for (f): $2x^4 + \ln(x + y^3) - 2y = 0$
$$F_x = 8x^3 + \frac{1}{x+y^3}, \quad F_y = \frac{3y^2}{x+y^3} - 2$$

Final Answer: $\frac{dy}{dx} = \frac{8x^4 + 8x^3 y^3 + 1}{2x + 2y^3 - 3y^2}$

📌 Q6: (a) & (b) Verify Euler's Theorem
Verify Euler's theorem ($x f_x + y f_y = k f$) for:
(a) $f(x,y) = x^3 + y^3 + x y^2$
(b) $f(x,y) = 3x^4 + x y^3 - 2y^4$
Verification for (a): $f(x,y) = x^3 + y^3 + x y^2$
$$f(tx, ty) = (tx)^3 + (ty)^3 + (tx)(ty)^2 = t^3(x^3 + y^3 + xy^2) = t^3 f(x,y) \implies k = 3$$
$$f_x = 3x^2 + y^2, \quad f_y = 3y^2 + 2xy$$
$$x f_x + y f_y = x(3x^2 + y^2) + y(3y^2 + 2xy) = 3x^3 + 3xy^2 + 3y^3 = 3(x^3 + y^3 + xy^2) = 3f$$
Euler's Theorem Verified: $k = 3$
Verification for (b): $f(x,y) = 3x^4 + x y^3 - 2y^4$
$$f(tx, ty) = t^4(3x^4 + xy^3 - 2y^4) = t^4 f(x,y) \implies k = 4$$
$$f_x = 12x^3 + y^3, \quad f_y = 3xy^2 - 8y^3$$
$$x f_x + y f_y = x(12x^3 + y^3) + y(3xy^2 - 8y^3) = 12x^4 + 4xy^3 - 8y^4 = 4(3x^4 + xy^3 - 2y^4) = 4f$$
Euler's Theorem Verified: $k = 4$
📌 Q6: (c) & (d) Verify Euler's Theorem
(c) $f(x,y) = \ln x - \ln y = \ln\left(\frac{x}{y}\right)$
(d) $f(x,y) = 5x + \sqrt{x^2+y^2}$
Verification for (c): $f(x,y) = \ln(x/y)$
$$f(tx, ty) = \ln\left(\frac{tx}{ty}\right) = \ln\left(\frac{x}{y}\right) = t^0 f(x,y) \implies k = 0$$
$$f_x = \frac{1}{x}, \quad f_y = -\frac{1}{y} \implies x f_x + y f_y = x\left(\frac{1}{x}\right) + y\left(-\frac{1}{y}\right) = 1 - 1 = 0 = 0 \cdot f$$
Verified: $x f_x + y f_y = 0$
Verification for (d): $f(x,y) = 5x + \sqrt{x^2+y^2}$
$$f(tx, ty) = 5tx + \sqrt{t^2(x^2+y^2)} = t(5x + \sqrt{x^2+y^2}) = t^1 f(x,y) \implies k = 1$$
$$f_x = 5 + \frac{x}{\sqrt{x^2+y^2}}, \quad f_y = \frac{y}{\sqrt{x^2+y^2}}$$

📌 Questions 10, 11 & 12: Advanced Euler Proofs
(10) If $u = \tan^{-1}\left(\frac{x^3+y^3}{2x+3y}\right)$, show that $x u_x + y u_y = \sin 2u$
(11) If $u = \ln\left(\frac{x^3+y^3}{2x^2+3y^2}\right)$, show that $x u_x + y u_y = 1$
(12) If $u = \ln\left(\frac{x^2-y^2}{2x^2+3y^2}\right) + \tan^{-1}\left(\frac{y}{z}\right) - \sinh^{-1}\left(\frac{z}{x}\right)$, show that $x u_x + y u_y + z u_z = 0$
Detailed Solution for Question 10
Step 1: Transform to an explicit homogeneous function:
$$\tan u = \frac{x^3+y^3}{2x+3y} \implies \text{Let } S(x,y) = \tan u = \frac{x^3+y^3}{2x+3y}$$
Step 2: Check homogeneity of $S(x,y)$:
$$S(tx, ty) = \frac{(tx)^3+(ty)^3}{2(tx)+3(ty)} = \frac{t^3(x^3+y^3)}{t(2x+3y)} = t^2 S(x,y) \implies k = 2$$
Step 3: Apply Euler's Theorem to $S(x,y)$:
$$x S_x + y S_y = 2 S$$
Since $S = \tan u \implies S_x = \sec^2 u \cdot u_x, \quad S_y = \sec^2 u \cdot u_y$:
$$x(\sec^2 u \cdot u_x) + y(\sec^2 u \cdot u_y) = 2\tan u \implies \sec^2 u (x u_x + y u_y) = 2\tan u$$
Step 4: Simplify trigonometric relations:
$$x u_x + y u_y = \frac{2\tan u}{\sec^2 u} = 2\left(\frac{\sin u}{\cos u}\right)\cos^2 u = 2\sin u \cos u = \sin 2u$$
Q.E.D. Formula Verified: $x u_x + y u_y = \sin 2u$
Detailed Solution for Question 11
Step 1: Transform logarithmic function:
$$e^u = \frac{x^3+y^3}{2x^2+3y^2} \implies \text{Let } S(x,y) = e^u = \frac{x^3+y^3}{2x^2+3y^2}$$
Step 2: Check degree of homogeneity of $S$:
$$S(tx, ty) = \frac{t^3(x^3+y^3)}{t^2(2x^2+3y^2)} = t^1 S(x,y) \implies k = 1$$
Step 3: Apply Euler's Theorem to $S$:
$$x S_x + y S_y = 1 \cdot S \implies x(e^u u_x) + y(e^u u_y) = e^u \implies e^u (x u_x + y u_y) = e^u$$
Step 4: Divide both sides by $e^u$:
$$x u_x + y u_y = 1$$
Q.E.D. Formula Verified: $x u_x + y u_y = 1$
Detailed Solution for Question 12
Evaluate homogeneity directly for each term in $u(x,y,z)$:
$$u(tx, ty, tz) = \ln\left(\frac{t^2(x^2-y^2)}{t^2(2x^2+3y^2)}\right) + \tan^{-1}\left(\frac{ty}{tz}\right) - \sinh^{-1}\left(\frac{tz}{tx}\right)$$ $$= \ln\left(\frac{x^2-y^2}{2x^2+3y^2}\right) + \tan^{-1}\left(\frac{y}{z}\right) - \sinh^{-1}\left(\frac{z}{x}\right) = t^0 u(x,y,z)$$
The function $u(x,y,z)$ is homogeneous of degree $k = 0$. By Euler's Theorem in 3 variables:
$$x u_x + y u_y + z u_z = 0 \cdot u = 0$$
Q.E.D. Formula Verified: Sum equals 0
📌 Question 13: Envelope of Curves (Cases a to f)
Find the envelope for:
(a) $x^2 + (y-a)^2 = 2a$
(b) $(x-b)^2 + y^2 = 4b$
(c) $(x-c)^2 + (y-2c)^2 = 8$
(d) $(x-\cos\alpha)^2 + (y-\sin\alpha)^2 = 1$
(e) $x\cos\theta + y\sin\theta = 2$
(f) $x\sin\beta + y\cos\beta = 4$
(a) $F(x,y,a) = x^2 + (y-a)^2 - 2a = 0$
Differentiate w.r.t parameter $a$:
$$\frac{\partial F}{\partial a} = 2(y-a)(-1) - 2 = -2(y-a) - 2 = 0 \implies y - a = -1 \implies a = y + 1$$
Substitute $a = y + 1$ into original equation:
$$x^2 + [y - (y+1)]^2 = 2(y+1) \implies x^2 + (-1)^2 = 2y + 2 \implies x^2 + 1 = 2y + 2$$
Envelope: $x^2 = 2y + 1$ (Parabola)
(b) $F(x,y,b) = (x-b)^2 + y^2 - 4b = 0$
$$\frac{\partial F}{\partial b} = 2(x-b)(-1) - 4 = 0 \implies x - b = -2 \implies b = x + 2$$
Substitute $b = x + 2$:
$$(-2)^2 + y^2 = 4(x+2) \implies 4 + y^2 = 4x + 8$$
Envelope: $y^2 = 4x + 4 = 4(x+1)$ (Parabola)
(c) $F(x,y,c) = (x-c)^2 + (y-2c)^2 - 8 = 0$
Differentiate w.r.t $c$:
$$\frac{\partial F}{\partial c} = -2(x-c) - 4(y-2c) = 0 \implies -(x-c) - 2(y-2c) = 0 \implies -x + c - 2y + 4c = 0 \implies 5c = x + 2y \implies c = \frac{x+2y}{5}$$
Substitute $x-c = \frac{4x-2y}{5} = \frac{2(2x-y)}{5}$ and $y-2c = \frac{y-2x}{5} = -\frac{2x-y}{5}$:
$$\left[\frac{2(2x-y)}{5}\right]^2 + \left[-\frac{2x-y}{5}\right]^2 = 8 \implies \frac{4(2x-y)^2 + (2x-y)^2}{25} = 8 \implies \frac{5(2x-y)^2}{25} = 8$$
$$(2x-y)^2 = 40 \implies 2x - y = \pm\sqrt{40} = \pm 2\sqrt{10}$$
Envelope: Two parallel lines $2x - y = \pm 2\sqrt{10}$
(d) $F(x,y,\alpha) = (x-\cos\alpha)^2 + (y-\sin\alpha)^2 - 1 = 0$
Expand: $x^2 - 2x\cos\alpha + \cos^2\alpha + y^2 - 2y\sin\alpha + \sin^2\alpha - 1 = 0 \implies x^2 + y^2 - 2(x\cos\alpha + y\sin\alpha) = 0$
Differentiate w.r.t $\alpha$:
$$-2(-x\sin\alpha + y\cos\alpha) = 0 \implies x\sin\alpha = y\cos\alpha \implies \tan\alpha = \frac{y}{x}$$
Hence $\cos\alpha = \frac{x}{\sqrt{x^2+y^2}}$ and $\sin\alpha = \frac{y}{\sqrt{x^2+y^2}}$:
$$x\cos\alpha + y\sin\alpha = \frac{x^2+y^2}{\sqrt{x^2+y^2}} = \sqrt{x^2+y^2}$$
Substitute back: $x^2 + y^2 - 2\sqrt{x^2+y^2} = 0 \implies \sqrt{x^2+y^2}(\sqrt{x^2+y^2} - 2) = 0$
Envelope: Circle $x^2 + y^2 = 4$ (and origin point $x=y=0$)
(e) $x\cos\theta + y\sin\theta = 2$ & (f) $x\sin\beta + y\cos\beta = 4$
For (e): Differentiate w.r.t $\theta$: $-x\sin\theta + y\cos\theta = 0 \implies \frac{\sin\theta}{y} = \frac{\cos\theta}{x} = \frac{1}{\sqrt{x^2+y^2}}$
$$\cos\theta = \frac{x}{\sqrt{x^2+y^2}}, \,\, \sin\theta = \frac{y}{\sqrt{x^2+y^2}} \implies \frac{x^2+y^2}{\sqrt{x^2+y^2}} = 2 \implies \sqrt{x^2+y^2} = 2 \implies x^2+y^2 = 4$$
Similarly for (f):
$$\sqrt{x^2+y^2} = 4 \implies x^2 + y^2 = 16$$
Envelopes: (e) Circle $x^2+y^2=4$ | (f) Circle $x^2+y^2=16$

📌 Questions 16 & 17: Applied Optimization Problems
(16) Find the point on the plane $x+2y-z=10$ nearest to the point $(1, 2, 3)$.
(17) Find the volume of the largest rectangular box that can be inscribed in the ellipsoid $16x^2+4y^2+9z^2=144$.
Solution for Question 16
Step 1: Distance squared function from $(1,2,3)$
$$f(x,y,z) = (x-1)^2 + (y-2)^2 + (z-3)^2 \quad \text{subject to } g(x,y,z) = x+2y-z-10 = 0$$
Step 2: Lagrange Multipliers
$$2(x-1) = \lambda(1) \implies x = 1 + \frac{\lambda}{2}$$
$$2(y-2) = \lambda(2) \implies y = 2 + \lambda$$
$$2(z-3) = \lambda(-1) \implies z = 3 - \frac{\lambda}{2}$$
Step 3: Substitute into plane equation
$$\left(1+\frac{\lambda}{2}\right) + 2(2+\lambda) - \left(3-\frac{\lambda}{2}\right) = 10 \implies 1 + \frac{\lambda}{2} + 4 + 2\lambda - 3 + \frac{\lambda}{2} = 10 \implies 2 + 3\lambda = 10 \implies \lambda = \frac{8}{3}$$
Step 4: Find the coordinates
$$x = 1 + \frac{4}{3} = \frac{7}{3}, \quad y = 2 + \frac{8}{3} = \frac{14}{3}, \quad z = 3 - \frac{4}{3} = \frac{5}{3}$$
Nearest Point: $\left(\frac{7}{3}, \frac{14}{3}, \frac{5}{3}\right)$
Solution for Question 17
Step 1: Formulate Volume and Ellipsoid equation
A box with vertices $(\pm x, \pm y, \pm z)$ has volume: $V = (2x)(2y)(2z) = 8xyz$
$$\text{Maximize } f(x,y,z) = xyz \quad \text{subject to } \frac{x^2}{9} + \frac{y^2}{36} + \frac{z^2}{16} = 1$$
Step 2: Lagrange equations
$$yz = \lambda \frac{2x}{9}, \quad xz = \lambda \frac{2y}{36}, \quad xy = \lambda \frac{2z}{16}$$
Multiplying by $x, y, z$ respectively:
$$xyz = \frac{2\lambda x^2}{9} = \frac{2\lambda y^2}{36} = \frac{2\lambda z^2}{16} \implies \frac{x^2}{9} = \frac{y^2}{36} = \frac{z^2}{16}$$
Step 3: Since their sum equals 1:
$$3\left(\frac{x^2}{9}\right) = 1 \implies x^2 = 3 \implies x = \sqrt{3}$$
$$y^2 = 12 \implies y = \sqrt{12} = 2\sqrt{3}, \quad z^2 = \frac{16}{3} \implies z = \frac{4}{\sqrt{3}}$$
Step 4: Total Volume
$$V = 8xyz = 8(\sqrt{3})(2\sqrt{3})\left(\frac{4}{\sqrt{3}}\right) = 8 \cdot 6 \cdot \frac{4}{\sqrt{3}} = \frac{192}{\sqrt{3}} = 64\sqrt{3}$$
Maximum Volume: $V = 64\sqrt{3} \approx 110.85$
