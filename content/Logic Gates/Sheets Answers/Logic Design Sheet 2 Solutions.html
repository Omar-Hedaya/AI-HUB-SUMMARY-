⚡ ملخص قواعد البوابات المنطقية (Quick Reference Guide)
🔘 NOT & AND Gates
• NOT: Inverts input ($0 \leftrightarrow 1$).
• AND: Output is 1 only when BOTH inputs are 1 ($1 \cdot 1 = 1$).
NOT: X = A'  |  AND: X = A · B
➕ OR & NAND Gates
• OR: Output is 1 if ANY input is 1 ($0+0=0$).
• NAND: Output is 0 only when BOTH inputs are 1.
OR: X = A + B  |  NAND: X = (A · B)'
⭕ NOR & XOR Gates
• NOR: Output is 1 only when BOTH inputs are 0.
• XOR: Output is 1 when inputs are DIFFERENT ($A \neq B$).
NOR: X = (A + B)'  |  XOR: X = A ⊕ B
⚖️ XNOR Gate (Equivalence)
• XNOR: Inverted XOR. Output is 1 when inputs are IDENTICAL ($A = B$).
XNOR: X = (A ⊕ B)' = A ⊙ B
