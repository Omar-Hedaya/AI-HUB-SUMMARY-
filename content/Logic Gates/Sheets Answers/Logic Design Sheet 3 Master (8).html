Logic Design — Sheet 3: Boolean Algebra & Karnaugh Maps (K-Maps)

حلول هندسية منظمة وشاملة بالبراهين الجبرية الدقيقة، جداول الحقيقة التفاعلية، مسارات تدفق الإشارات المضيئة ⚡، وخرائط كارنوف (K-Maps) مزودة بمفتاح أرقام المينتيرمز ($m_0, m_1, \dots$) والربط التفاعلي بين الحدود وحلقات الخريطة (Term-to-Loop Highlight).

⚡ Quick Reference Guide: Postulates & Theorems (قوانين الجبر البوليني وخرائط كارنوف)
🔘 Postulates & Identity
• $A + 0 = A$,   $A \cdot 1 = A$
• $A + 1 = 1$,   $A \cdot 0 = 0$
• $A + A = A$,   $A \cdot A = A$
A + A' = 1  |  A · A' = 0  |  (A')' = A
➕ Absorption & Distributive
• $A + AB = A$
• $A + \overline{A}B = A + B$
• $(A + B)(A + C) = A + BC$
A(A + B) = A  |  A(A' + B) = AB
⭕ DeMorgan's Theorems
• $\overline{A \cdot B} = \overline{A} + \overline{B}$ (NAND)
• $\overline{A + B} = \overline{A} \cdot \overline{B}$ (NOR)
(A + B + ... + Z)' = A' · B' · ... · Z'
🗺️ K-Map Grouping Rules
• Groups must be powers of 2 ($1, 2, 4, 8, 16$).
• Wrap-around edges & 4 corners are adjacent.

Q1. Simplify Expressions Using Boolean Algebra (a to e)
Q1. Simplify the following expressions using Boolean algebra laws and theorems:
(a) $(A+\overline{B})(A+C)$      (b) $A(\overline{A}+AB)$      (c) $AB+\overline{AB}C+A$
(d) $A\overline{B}C+\overline{A}BC+\overline{A}\overline{B}C$      (e) $(B+BC)(B+\overline{B}C)(B+D)$
(a) Expression: $(A+\overline{B})(A+C)$ Dual Distributive: (X+Y)(X+Z) = X+YZ
Step 1 (Expand using Distributive Law): Distributive Law
$$= A \cdot A + A \cdot C + \overline{B} \cdot A + \overline{B} \cdot C$$
Step 2 (Apply Idempotence & Factor out $A$): Idempotent: A · A = A
$$= A + AC + A\overline{B} + \overline{B}C = A(1 + C + \overline{B}) + \overline{B}C$$
Step 3 (Apply Null Element / Annulment): Annulment: 1 + X = 1
$$= A(1) + \overline{B}C = \mathbf{A + \overline{B}C}$$
Result (a): $\mathbf{A + \overline{B}C}$
جدول التحقق والمطابقة العددية لجميع الاحتمالات ($2^3 = 8$) ✓ متطابق 100%

(b) Expression: $A(\overline{A}+AB)$ Absorption: X' + XY = X' + Y
Method 1 (Internal Absorption First): Complement: A · A' = 0
$$A(\overline{A} + B) = A\overline{A} + AB = 0 + AB = \mathbf{AB}$$
Method 2 (Distribute $A$ Directly): Distributive
$$= A \cdot \overline{A} + A \cdot (AB) = 0 + (A \cdot A)B = \mathbf{AB}$$
Result (b): $\mathbf{AB}$

(c) Expression: $AB+\overline{AB}C+A$ DeMorgan & Absorption
Step 1 (Combine $AB + A$): A + AB = A
$$= A + AB + \overline{AB}C = A(1 + B) + \overline{AB}C = A + \overline{AB}C$$
Step 2 (Apply DeMorgan on $\overline{AB}$): (AB)' = A' + B'
$$= A + (\overline{A} + \overline{B})C = A + \overline{A}C + \overline{B}C$$
Step 3 (Simplify $A + \overline{A}C = A + C$): X + X'Y = X + Y
$$= (A + C) + \overline{B}C = A + C(1 + \overline{B}) = \mathbf{A + C}$$
Result (c): $\mathbf{A + C}$

Step 1 (Factor common $\overline{B}C$): A + A' = 1
$$= \overline{B}C(A + \overline{A}) + \overline{A}BC = \overline{B}C(1) + \overline{A}BC = \overline{B}C + \overline{A}BC$$
Step 2 (Factor variable $C$): X' + XY = X' + Y
$$= C(\overline{B} + \overline{A}B) = C(\overline{B} + \overline{A}) = \mathbf{\overline{B}C + \overline{A}C}$$
Result (d): $\mathbf{\overline{B}C + \overline{A}C} = \mathbf{(\overline{A} + \overline{B})C}$

Q2. Expression Analysis: $Y=A\overline{B}C+\overline{A}\overline{B}C+\overline{A}BC+A\overline{B}C+ABC$
Q2. For the Boolean expression: $Y=A\overline{B}C+\overline{A}\overline{B}C+\overline{A}BC+A\overline{B}C+ABC$
(a) Obtain the truth table of Y.
(b) Draw the logic circuit using the original Boolean expression.
(c) Draw the logic circuit after simplification using Boolean algebra.
Boolean Algebraic Simplification: Idempotent: X + X = X
Notice term $A\overline{B}C$ is repeated. The 4 unique minterms are:
$$Y = \overline{A}\overline{B}C + \overline{A}BC + A\overline{B}C + ABC$$
Factor $C$ from all four minterms:
$$Y = C \left( \overline{A}\overline{B} + \overline{A}B + A\overline{B} + AB \right) = C \left[ \overline{A}(\overline{B}+B) + A(\overline{B}+B) \right] = C(\overline{A}+A) = \mathbf{C}$$
Remarkable Simplification: $\mathbf{Y = C}$ (Output identically equals input C)
المسارات مضيئة دائماً (اضغط على أي صف لتحديد مسار الإشارة) انقر خارج الجدول للعودة للإضاءة الشاملة
(c) Logic Circuit After Simplification: $Y = C$
💡 مقارنة هندسية: الدائرة الأصلية تتطلب 4 بوابات AND ثلاثية المداخل + 1 بوابة OR رباعية المداخل، بينما بعد التبسيط يتم ربط خط الدخل $C$ مباشرة بالخرج $Y$ دون الحاجة لأي بوابة!
Q3. Apply DeMorgan's Theorem (a, b, c)
Q3. Apply DeMorgan's Theorem to find the complement and simplify:
(a) $\overline{(A+\overline{B})(\overline{C}+D)}$
(b) $\overline{(A+\overline{B\overline{C}}+CD)+\overline{BC}}$
(c) $\overline{(\overline{A}+B+C+D)(A\overline{B}\overline{C}D)}$
(a) Expression: $\overline{(A+\overline{B})(\overline{C}+D)}$ DeMorgan: (X · Y)' = X' + Y'
Step 1 (Apply Product Complement):
$$= \overline{A + \overline{B}} + \overline{\overline{C} + D}$$
Step 2 (Apply Sum Complement & Double Inversion):
$$= (\overline{A} \cdot \overline{\overline{B}}) + (\overline{\overline{C}} \cdot \overline{D}) = \mathbf{\overline{A}B + C\overline{D}}$$
Result (a): $\mathbf{\overline{A}B + C\overline{D}}$
(b) Expression: $\overline{(A+\overline{B\overline{C}}+CD)+\overline{BC}}$ Tautology Complement
$\overline{B\overline{C}} = \overline{B} + C$, so $A + \overline{B} + C + CD = A + \overline{B} + C$.
Also $\overline{BC} = \overline{B} + \overline{C}$.
$$\text{Inner} = (A + \overline{B} + C) + (\overline{B} + \overline{C}) = A + \overline{B} + (C + \overline{C}) = A + \overline{B} + 1 = 1$$
Step 2 (Complement the Tautology): (1)' = 0
$$\overline{1} = \mathbf{0}$$
Result (b): $\mathbf{0}$   (Tautology complemented to 0)
(c) Expression: $\overline{(\overline{A}+B+C+D)(A\overline{B}\overline{C}D)}$ DeMorgan & Absorption
$$= \overline{(\overline{A} + B + C + D)} + \overline{(A\overline{B}\overline{C}D)} = (A\overline{B}\overline{C}\overline{D}) + (\overline{A} + B + C + \overline{D})$$
Notice $\overline{D}$ absorbs $A\overline{B}\overline{C}\overline{D}$ ($X + XY = X$ where $X = \overline{D}$):
$$= \mathbf{\overline{A} + B + C + \overline{D}}$$
Result (c): $\mathbf{\overline{A} + B + C + \overline{D}}$
Q4. Standard (SOP) & (POS) Canonical Forms for $(A+B)(C+B)$
Q4. For the given expression: $(A+B)(C+B)$
Find the Standard SOP (Canonical Sum of Minterms) and Standard POS (Canonical Product of Maxterms) by replacing the missing variable and using the truth table method.
Method 1: Algebraic Missing Variable Expansion
A) Standard POS Formulation:
Term $(A + B + C\overline{C}) = (A + B + C)(A + B + \overline{C})$ (Maxterms $M_0, M_1$)
Term $(A\overline{A} + B + C) = (A + B + C)(\overline{A} + B + C)$ (Maxterms $M_0, M_4$)
$$\text{Standard POS} = (A + B + C)(A + B + \overline{C})(\overline{A} + B + C) = \prod M(0, 1, 4)$$
B) Standard SOP Formulation:
Algebraic expansion: $(A + B)(B + C) = B + AC$
$B = B(A + \overline{A})(C + \overline{C}) \implies m_2, m_3, m_6, m_7$
$AC = AC(B + \overline{B}) \implies m_5, m_7$
$$\text{Standard SOP} = \sum m(2, 3, 5, 6, 7) = \overline{A}B\overline{C} + \overline{A}BC + A\overline{B}C + AB\overline{C} + ABC$$
Method 2: Truth Table Verification
Canonical SOP: $Y = \sum m(2, 3, 5, 6, 7)$  |  Canonical POS: $Y = \prod M(0, 1, 4)$

Q7. Simplify Given Expressions Using K-Maps (a to d)
Q7. Use Karnaugh Map (K-Map) to simplify the following expressions:
(a) $\overline{A}(BC+B\overline{C})+A(BC+B\overline{C})$
(b) $DE\overline{F}+\overline{D}E\overline{F}+\overline{D}\overline{E}\overline{F}$
(c) $\overline{A}\overline{B}\overline{C}\overline{D}+\overline{A}\overline{B}\overline{C}D+ABC\overline{D}$
(d) $(\overline{A}\overline{B}+A\overline{B})(CD+C\overline{D})$
(a) Expression: $\overline{A}(BC+B\overline{C})+A(BC+B\overline{C})$ Quad Covering: 4 Minterms
Minterm Expansion:
$$\overline{A}BC + \overline{A}B\overline{C} + ABC + AB\overline{C} = m_3 + m_2 + m_7 + m_6$$
K-Map Mapping (3 Variables $A, B, C$):
All cells where $B = 1$ are covered ($m_2, m_3, m_6, m_7$). This forms a Quad of 4 across row 01 and row 11!
Since $A$ changes ($0 \to 1$) and $C$ changes ($0 \to 1$), only $B$ remains constant:
Result (a): $\mathbf{Y = B}$
(b) Expression: $DE\overline{F}+\overline{D}E\overline{F}+\overline{D}\overline{E}\overline{F}$ Adjacent Pairs Grouping
Minterms ($D, E, F$ order):
• $DE\overline{F} = (110)_2 = m_6$  |  $\overline{D}E\overline{F} = (010)_2 = m_2$  |  $\overline{D}\overline{E}\overline{F} = (000)_2 = m_0$
K-Map Grouping:
• Group 1 (Pair $m_2, m_6$): $E\overline{F}$   |   Group 2 (Pair $m_0, m_2$): $\overline{D}\overline{F}$
Result (b): $\mathbf{Y = E\overline{F} + \overline{D}\overline{F}} = \mathbf{\overline{F}(E + \overline{D})}$
(c) Expression: $\overline{A}\overline{B}\overline{C}\overline{D}+\overline{A}\overline{B}\overline{C}D+ABC\overline{D}$ Pair & Isolated Minterm
Minterms (4 Variables $A, B, C, D$):
• $\overline{A}\overline{B}\overline{C}\overline{D} = m_0$  |  $\overline{A}\overline{B}\overline{C}D = m_1$  |  $ABC\overline{D} = m_{14}$
K-Map Grouping:
• Pair ($m_0, m_1$): Covers $\overline{A}\overline{B}\overline{C}$ ($D$ changes $0 \to 1$).
• Single Minterm ($m_{14}$): Has no adjacent 1s, remains isolated as $ABC\overline{D}$.
Result (c): $\mathbf{Y = \overline{A}\overline{B}\overline{C} + ABC\overline{D}}$
(d) Expression: $(\overline{A}\overline{B}+A\overline{B})(CD+C\overline{D})$ Complement & Factorization
Algebraic Factorization & K-Map Alignment:
$$(\overline{A}\overline{B} + A\overline{B}) = \overline{B}(\overline{A} + A) = \overline{B}$$
$$(CD + C\overline{D}) = C(D + \overline{D}) = C$$
$$Y = \overline{B} \cdot C = \mathbf{\overline{B}C}$$
In 4-variable K-map: Represents a Quad of 4 minterms ($m_2, m_3, m_{10}, m_{11}$) where $B=0$ and $C=1$.
Result (d): $\mathbf{Y = \overline{B}C}$
