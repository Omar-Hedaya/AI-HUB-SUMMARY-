المرحلة الأولى: آلية عمل بت النمط M

• عندما $M = 0$: $B_i \oplus 0 = B_i$ و $C_{\text{in}} = 0$ (جمع مباشر).
• عندما $M = 1$: $B_i \oplus 1 = \overline{B_i}$ و $C_{\text{in}} = 1$ (طرح بالمتمم الثنائي).

المرحلة الثانية: الدائرة المنطقية باستخدام بوابات XOR المتحكم بها

تتصل المدخلات $B$ بأحد طرفي بوابات XOR والطرف الآخر يتصل بالخط المشترك $M$ مع $C_{\text{in}}$.

المرحلة الثالثة: بطاقات الحساب المنظمة أفقياً للحالتين
Case (a): Addition Mode (M = 0, Cin = 0) A = 1000 (8), B = 1001 (9)
Carries: 0 0 0 0 (C₄ C₃ C₂ C₁)
Operand A: 1 0 0 0 = 8₁₀
+ Operand B: 1 0 0 1 = 9₁₀

الناتج الكلي: Cout = 1, SUM = 0001 → 10001₂ = 17₁₀

Operand A: 1 1 0 0 = 12₁₀
+ 2's Comp B: 0 1 1 1 B'=0111 + 1

الناتج الكلي: Cout = 1, SUM = 0100 → النتيجة +4₁₀

⚠️ الدليل الهندسي الشامل: أسرار المتمم الثنائي وكشف الـ Overflow في الامتحانات
  • 1. كارثة الخلط بين المتمم الأحادي (1's) والمتمم الثنائي (2's) في الـ Carry:
    في المتمم الأحادي، إذا ظهر حمل أخير ($\text{End-Around Carry}$) يجب جمعه مجدداً مع خانة الآحاد. أما في المتمم الثنائي (المستخدم في هذه الدائرة)، يُهمل ويُلغى الحمل الأخير تماماً (Discard Carry-Out)؛ لأن الواحد المطلوب تم جمعه مسبقاً في البداية عبر إدخال $C_{\text{in}} = 1$.
  • 2. خطأ نسيان ضبط $C_{\text{in}} = M = 1$ في عملية الطرح:
    بوابات الـ XOR عند ضبط $M = 1$ تقوم فقط بعملية العكس $\overline{B}$ (توليد المتمم الأحادي). ولكي يتحول إلى متمم ثنائي سليم، لا بد من إضافة $+1$ عبر خط الحمل الابتدائي $C_{\text{in}} = M = 1$.
  • 3. قاعدة كشف الفيض المنطقي للأعداد ذات الإشارة (Signed Overflow):
    يحدث الـ Overflow عندما لا تتسع خانات الخرج للرقم الحقيقي، ويُكشف عبر بوابة XOR بين حمل الخانة الأخيرة وحمل ما قبل الأخيرة: $$V = C_n \oplus C_{n-1}$$ إذا كان $V = 1$ فهناك طفح حسابي (Overflow) والناتج خاطئ. أما إذا كان $V = 0$ فالناتج سليم.
  • 4. كشف الطفح في الأعداد غير ذات الإشارة (Unsigned Overflow):
    نص الشيت حدد: "Treat both inputs as unsigned decimal numbers". في الأعداد غير ذات الإشارة:
    • في الجمع: $C_{\text{out}} = 1$ يعني أن المجموع تجاوز سعة الـ 4 بت (تجاوز الرقم 15) ويحتاج لبت خامس.
    • في الطرح: $C_{\text{out}} = 1$ يعني أن $A \ge B$ والنتيجة موجبة صحيحة. بينما $C_{\text{out}} = 0$ يعني حدوث استعارة (Borrow) وأن $A < B$.
