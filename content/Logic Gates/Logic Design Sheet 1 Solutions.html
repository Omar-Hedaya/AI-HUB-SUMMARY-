⚡ Quick Study Reference & Radix Mechanics (الملخص السريع للقواعد الهندسية)
📦 1. Binary Grouping & Padding Rule
• Octal (Base 8): Divide bits into 3-bit groups from right (LSB).
• Hexadecimal (Base 16): Divide bits into 4-bit groups from right.
• Padding 0s: Add zeros to the far left of the most significant group if it lacks bits.
Octal: 2³ = 8 (3 bits) | Hex: 2⁴ = 16 (4 bits)
🔄 2. Carry & Borrow Values by Base
When borrowing in subtraction, the borrowed digit value depends strictly on the Radix $r$:
• Binary (Base 2): Borrow 1 brings +2 to current column.
• Octal (Base 8): Borrow 1 brings +8 to current column.
• Hex (Base 16): Borrow 1 brings +16 to current column.
Borrowed Val = Current Digit + Radix (r)
📏 3. Signed-Magnitude Range & Overflow
1 Sign bit (MSB: 0=+, 1=-) + $(n-1)$ Magnitude bits:
• 4-bit Range: $-(2^3 - 1) \text{ to } +(2^3 - 1) \implies \mathbf{[-7, +7]}$
• 8-bit Range: $-(2^7 - 1) \text{ to } +(2^7 - 1) \implies \mathbf{[-127, +127]}$
• Any number outside this window results in OVERFLOW.
Range = [ -(2ⁿ⁻¹ - 1) , +(2ⁿ⁻¹ - 1) ]
⚙️ 4. 2's Complement End-Around Carry Rules
When computing $A - B$ using $A + (\text{2's comp of } B)$:
• End Carry = 1: Discard the carry bit → The result is Positive (+).
• End Carry = 0: No carry → The result is Negative (-) and stored in 2's comp form. (Re-complement to get magnitude).
End Carry = 1 → Discard | End Carry = 0 → Negative
🔢 5. BCD (Binary-Coded Decimal 8421)
Encode each decimal digit ($0 \text{ to } 9$) independently into its exact 4-bit binary equivalent.
Forbidden codes: 1010 through 1111 ($10 \text{ to } 15$).
Example: (26)₁₀ = (0010 0110)_BCD

Q5. Fractional Conversion: (17.3)₁₀ to Binary, Octal, Hexadecimal
Q5. Convert $(17.3)_{10}$ to binary, octal and hexadecimal.
1) Integer Part ($17_{10}$):
• Binary: $17 = 16 + 1 \implies (10001)_2$
• Octal: $17 / 8 = 2 \text{ rem } 1 \implies (21)_8$
• Hexadecimal: $17 / 16 = 1 \text{ rem } 1 \implies (11)_{16}$
2) Fractional Part ($0.3_{10}$) via Successive Multiplications:
• To Binary (× 2):
0.3 × 2 = 0.6 → 0 (MSB fraction)
0.6 × 2 = 1.2 → 1
0.2 × 2 = 0.4 → 0
0.4 × 2 = 0.8 → 0
0.8 × 2 = 1.6 → 1
0.6 × 2 = 1.2 → 1 (repeating pattern 0011)...
$(17.3)_{10} \approx (10001.0100110011...)_2$
• To Octal (× 8):
0.3 × 8 = 2.4 → 2
0.4 × 8 = 3.2 → 3
0.2 × 8 = 1.6 → 1
0.6 × 8 = 4.8 → 4
0.8 × 8 = 6.4 → 6...
$(17.3)_{10} \approx (21.23146...)_8$
• To Hexadecimal (× 16):
0.3 × 16 = 4.8 → 4
0.8 × 16 = 12.8 → 12 (≡ C)
0.8 × 16 = 12.8 → 12 (≡ C repeating)...
$(17.3)_{10} \approx (11.4\text{CCCC}...)_{16}$

Q11. Range of Signed Magnitude Numbers (4-bits & 8-bits)
Q11. Determine the range of numbers that can be represented in signed magnitude numbers in 4-bits and 8-bits.
Mathematical Range Formula for Signed Magnitude:
In an $n\text{-bit}$ signed magnitude number, the most significant bit (MSB) denotes sign ($0 = +, 1 = -$) leaving $(n-1)$ bits for absolute magnitude:
$$\text{Range} = -(2^{n-1} - 1) \quad \text{to} \quad +(2^{n-1} - 1)$$
1) For 4-bits ($n = 4$):
$$\text{Range} = -(2^{4-1} - 1) \text{ to } +(2^{4-1} - 1) = -(2^3 - 1) \text{ to } +(2^3 - 1) = \mathbf{[-7 , +7]}$$
4-bit Signed Range: $[-7 , +7]$
2) For 8-bits ($n = 8$):
$$\text{Range} = -(2^{8-1} - 1) \text{ to } +(2^{8-1} - 1) = -(2^7 - 1) \text{ to } +(2^7 - 1) = \mathbf{[-127 , +127]}$$
8-bit Signed Range: $[-127 , +127]$

Q13. In 4-bit size, find the value of $(5 - 3)$ and $(-4 + 7)$ using 2's complement.
