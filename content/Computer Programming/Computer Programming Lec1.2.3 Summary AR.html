1.1 الهيكل البنائي لبرنامج C++

يتألف أي برنامج قياسي مكتوب بلغة C++ من مكونات جوهرية متكاملة:

  • توجيهات ما قبل المعالجة (Preprocessor Directives): كل سطر يبدأ بعلامة #، مثل #include <iostream>، لتضمين مكتبات الإدخال والإخراج القياسية قبل البدء في مرحلة الترجمة.
  • الدالة الرئيسية main(): نقطة انطلاق وبداية تنفيذ البرنامج، ووجودها شرط أساسي في كل برنامج، وترجع قيمة رقمية صحيحة (int).
  • جملة الخروج return 0;: تُشير إلى أن البرنامج انتهى بنجاح تام وسليم دون أي مشاكل بنظام التشغيل.
  • الفاصلة المنقوطة ;: علامة إلزامية تختم كل تعبير برمجي تنفيذي (Statement).
SAMPLE CODE // FIRST PROGRAM
welcome.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to C++!\n";
    return 0;
}

1.2 التعليقات في C++ (Comments)

التعليقات أسطر توضيحية للمبرمجين يتجاهلها المترجم تماماً ولا تُترجم لأوامر قابلة للتنفيذ:

  • تعليق السطر الواحد (Single-Line): يبدأ بالعلامة // ويستمر حتى نهاية السطر الحالي.
  • تعليق متعدد الأسطر (Multi-Line / Block): يبدأ بالعلامة /* ويُغلق بالعلامة */.

1.3 المتغيرات، المعرفات، والثوابت (Variables & Constants)

المتغير (Variable): موقع مخصص في الذاكرة لتخزين قيمة يمكن تعديلها أثناء تنفيذ البرنامج، ويحدد نوع البيانات سعة وطبيعة ما يمكن تخزينه فيه.

قواعد تسمية المعرفات (Identifiers):

  1. تتكون فقط من الحروف الأبجدية (كبيرة أو صغيرة)، والأرقام، والشرطة السفلية _.
  2. يجب أن تبدأ بحرف أو بشرطة سفلية (ممنوع منعاً باتاً أن تبدأ برقم).
  3. لا تحتوي على أي مسافات فارغة أو علامات خاصة مثل (#, -, !, $, %).
  4. لا يجوز أن تكون كلمة محجوزة من كلمات اللغة (مثل int, class, cin, return).

طرق الإعلان عن الثوابت (Constants):

  • بواسطة موجه المعالجة: #define PI 3.14 (بدون فاصلة منقوطة ولا علامة إسناد).
  • بواسطة الكلمة المفتاحية: const float PI = 3.14; (إلزامية التهيئة بالقيمة عند التعريف فوراً).

1.4 أنواع البيانات الأساسية ودوال الإدخال والإخراج

تصنيف النوع الكلمة المفتاحية الوصف والاستخدام
الأعداد الصحيحة short, int, long أعداد صحيحة موجبة أو سالبة بدون أجزاء عشرية.
الأعداد الحقيقية float, double, long double أعداد تحتوي على كسور عشرية وبمستويات دقة متفاوتة.
الحروف والرموز char رمز فردي يُكتب بين علامتي تنصيص فرديتين مثل 'A'.
السلاسل النصية string سلسلة متتابعة من الأحرف والكلمات والنصوص.
القيم المنطقية bool تحمل قيمتين فقط: true (تساوي 1) أو false (تساوي 0).

إعادة تسمية الأنواع (typedef):

typedef int number;
number distance = 150; // distance هو متغير نوعه int تماماً

معاملات تدفق الإدخال والإخراج ورموز الهروب:

  • cout << : معامل الإقحام (Insertion Operator) لعرض المخرجات على الشاشة.
  • cin >> : معامل الاستخراج (Extraction Operator) لقراءة الإدخال من المستخدم وحفظه في المتغير.
  • \n : النزول لسطر جديد.
  • \t : مسافة جدولية أفقية (Tab).
  • endl : إدراج سطر جديد مع إفراغ الذاكرة المؤقتة لمجرى الإخراج (Flush Buffer).

2. المعاملات والتعبيرات البرمجية (Operators & Expressions)

الأسبقية الحسابية، معاملات التراكم، الزيادة والنقصان، العمليات المنطقية، ومفهوم Lvalues مقابل Rvalues.

# أسبقية العمليات # ++x مقابل x++ # المنطق والـ Short-Circuit # فخ == مقابل = # Lvalues مقابل Rvalues
فخاخ امتحانية شائعة (EXAM PITFALLS): 1. قسمة الأعداد الصحيحة 31 / 3 ينتج عنها 10 وليس 10.33، حيث يُبتر الجزء الكسري تماماً!
2. معامل باقي القسمة % يعمل فقط وحصرياً مع الأعداد الصحيحة (int)، وتطبيقه على أعداد كسرية ينتج عنه خطأ ترجمة فوري.

2.1 العمليات الحسابية وقواعد الأسبقية (Precedence)

تدعم C++ العمليات الحسابية: الجمع (+)، الطرح (-)، الضرب (*)، القسمة (/)، وباقي القسمة (%):

ترتيب الأسبقية والأولوية في التنفيذ:

  1. الأقواس (): الأعلى أولوية دائماً وتُنفذ من الداخل إلى الخارج.
  2. الضرب والقسمة وباقي القسمة (*, /, %): تلي الأقواس وتُقيم من اليسار لليمين.
  3. الجمع والطرح (+, -): الأدنى أسبقية وتُقيم من اليسار لليمين.

2.2 معاملات الزيادة والنقصان والتراكم (Increment / Decrement)

معاملات التراكم تختصر المعادلات: التعبير c += 3 يكافئ تماماً c = c + 3.

الفرق الجوهري بين Pre-Increment و Post-Increment:

  • الزيادة القبلية (++x): يُزاد المتغير بمقدار 1 أولاً، ثم تُستخدم قيمته الجديدة والمحدثة في التعبير الحالي.
  • الزيادة البعدية (x++): تُستخدم القيمة الحالية للمتغير في التعبير أولاً، ثم تتم زيادة المتغير بواحد بعد انتهاء التقييم.
  • إذا كُتب المتغير منفرداً في سطر مستقل (مثل ++c; أو c++;)، فلا يوجد أي فارق في النتيجة النهائية.
TRACE EXAMPLE // PRE VS POST
inc_trace.cpp 
#include <iostream>
using namespace std;

int main() {
    int c = 5;
    cout << ++c << endl; // يطبع 6 (تمت الزيادة أولاً)
    cout << c++ << endl; // يطبع 6 (يُقيم بالقيمة الحالية، ثم تصبح c = 7)
    cout << c << endl;   // يطبع 7
    return 0;
}

2.3 معاملات المقارنة والعمليات المنطقية

معاملات المقارنة ترجع قيماً منطقية: true (1) أو false (0):

  • معاملات المقارنة: >, <, >=, <=, ==, !=.
  • المعاملات المنطقية: && (AND), || (OR), ! (NOT).
A B A && B (AND) A || B (OR) !A (NOT)
true true true true false
true false false true false
false true false true true
false false false false true

خاصية الدائرة القصيرة (Short-Circuit Evaluation):

تتميز لغة C++ بالاقتصاد التقييمي؛ فإذا عُرفت النتيجة النهائية المؤكدة، تتوقف عن فحص باقي التعبير:

  • في معامل &&: إذا كان الطرف الأول false، يتم تجاهل الطرف الثاني تماماً (لأن النتيجة حتماً false).
  • في معامل ||: إذا كان الطرف الأول true، يتم تجاهل الطرف الثاني تماماً (لأن النتيجة حتماً true).

2.4 الخلط الكارثي بين المقارنة (==) والإسناد (=)

خطأ منطقي خطير (Critical Logic Bug):
كتابة if (payCode = 4) بدلاً من if (payCode == 4) تقوم بإسناد الرقم 4 للمتغير. وبما أن الرقم 4 قيمة غير صفرية، تعتبرها لغة C++ صائبة (True) دائماً، فيتحقق الشرط وينفذ الكود الداخلي دون أي اعتراض أو تنبيه من المترجم!

2.5 مفهوم Lvalues مقابل Rvalues

معرفة مواضع المعاملات بالنسبة لعلامة التساوي قاعدة أساسية لفهم قواعد الإسناد في لغة C++:

  • الـ Lvalues (قيم الطرف الأيسر): تعبيرات تمثل مواقع حقيقية محجوزة في ذاكرة الحاسوب وتملك عنواناً (Memory Address)، ولذا يمكن أن تقع على يسار علامة الإسناد وقيمتها قابلة للتعديل (مثل المتغيرات: x = 4;).
  • الـ Rvalues (قيم الطرف الأيمن): تعبيرات مؤقتة تمثل قيماً عددية أو حسابية لحظية، وتقع فقط على يمين علامة الإسناد ولا تملك مكاناً ثابتاً يمكن التعديل عليه (مثل الثوابت والأرقام المباشرة: لا يجوز كتابة 4 = x;).
  • القاعدة الذهبية: يمكن استخدام الـ Lvalue كـ Rvalue، ولكن لا يمكن استخدام الـ Rvalue كـ Lvalue أبداً.
int x = 10; // 'x' عبارة عن lvalue، والرقم 10 عبارة عن rvalue (صحيح)
int y = x; // 'y' عبارة عن lvalue، والمتغير 'x' يُعامل هنا كـ rvalue (صحيح)
10 = x; // خطأ ترجمة فادح: الثابت 10 هو rvalue ولا يمكن أن يوضع على اليسار!

3. هياكل التحكم والاختيار (Control Structures: Selection)

اتخاذ القرار: جمل if و if/else، المعامل الثلاثي، تصنيف الأخطاء البرمجية، وبنية جملة switch المتعددة.

# جمل if و if/else # المعامل الثلاثي (?:) # تصنيف الأخطاء البرمجية # بنية جملة switch
فخاخ امتحانية شائعة (EXAM PITFALLS): 1. في جملة switch، المتغير المفحوص يجب أن يكون من نوع صحيح أو رمزي (int أو char فقط)، ولا يقبل الأنواع العشرية float أو double أو النصوص string.
2. نسيان أمر break داخل case يسبب السقوط التتابعي (Fall-through)، مما يؤدي لتنفيذ الحالات التالية تلقائياً حتى مصادفة أول break!

3.1 هياكل الاختيار if و if/else

تُحدد هياكل الاختيار مسار البرنامج استناداً إلى تقييم شرط معين. في C++ يُعد أي رقم غير صفري True، وتُعتبر القيمة الصفرية فقط False.

الأقواس والجمل المركبة (Compound Statements):
إذا احتوى جسم if أو else على أكثر من أمر برمجي واحد، فيجب حصر هذه الأوامر بين قوسين معقوفين { }. بدون الأقواس، يعتبر المترجم أن الجملة الأولى فقط تابعة للشرط، بينما تُنفذ الجمل الأخرى دائماً في كل الأحوال.

3.2 المعامل الثلاثي الشرطي (Ternary Operator ?:)

طريقة بديلة ومختصرة لجملة if/else مكونة من 3 أطراف: الشرط ? قيمة_التحقق : قيمة_عدم_التحقق;

cout << (grade >= 60 ? "Passed" : "Failed");

3.3 تصنيف الأخطاء البرمجية (Types of Programming Errors)

تنقسم الأخطاء البرمجية بحسب وقت اكتشافها وأثرها على مسار تنفيذ البرنامج إلى أصناف رئيسية:

تصنيف الخطأ وقت الاكتشاف السلوك والأثر على البرنامج أمثلة شائعة
الأخطاء القواعدية (Syntax Errors) أثناء الترجمة (Compile Time) يكتشفها المترجم ويمنع تحويل الكود إلى ملف تنفيذي تماماً. نسيان الفاصلة المنقوطة ;، خطأ إملائي بالكلمات المحجوزة (cot)، عدم إغلاق الأقواس.
الأخطاء المنطقية غير القاتلة (Non-fatal Logic Errors) أثناء التشغيل (Runtime) يعمل البرنامج للنهاية ويكتمل، ولكنه يعطي مخرجات وحسابات غير صحيحة. كتابة الإسناد = بدلاً من المقارنة ==، أو حساب المتوسط a+b/2 بدل (a+b)/2.
الأخطاء المنطقية القاتلة (Fatal Logic Errors) أثناء التشغيل (Runtime) يتوقف البرنامج فجأة وينهار (Crash) ويخرج قبل إتمام باقي الأوامر. القسمة على صفر (x / 0)، أو التكرار اللانهائي المستهلك للذاكرة.

3.4 جملة الاختيار المتعدد switch

تُعد الخيار الأمثل والأنظف عند مقارنة متغير واحد بعدة احتمالات ثابتة، لتجنب التعقيد الناجم عن تكرار else if:

COMPLETE EXAMPLE // DAYS IN MONTH WITH LEAP YEAR
days_in_month.cpp 
#include <iostream>
using namespace std;

int main() {
    int month, year;
    cout << "Enter month number (1-12): ";
    cin >> month;

    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            cout << "31 days" << endl;
            break;

        case 4: case 6: case 9: case 11:
            cout << "30 days" << endl;
            break;

        case 2:
            cout << "Enter year: ";
            cin >> year;
            if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
                cout << "29 days (Leap year)" << endl;
            } else {
                cout << "28 days (Normal year)" << endl;
            }
            break;

        default:
            cout << "Invalid month number!" << endl;
    }
    return 0;
}

4. ملخص تصنيف الأخطاء البرمجية (Errors Taxonomy)

  • أخطاء قواعدية (Syntax Errors): تظهر في مرحلة الترجمة (Compile-time)، وتمنع إنشاء البرنامج وتشغيله (مثل نسيان الفاصلة المنقوطة ; أو الأخطاء الإملائية).
  • أخطاء منطقية غير قاتلة (Non-fatal Logic Errors): تظهر أثناء التشغيل (Runtime)، حيث يعمل البرنامج لنهايته بشكل طبيعي ولكنه يُخرج نتائج وحسابات خاطئة (مثل فخ if (payCode = 4)).
  • أخطاء منطقية قاتلة (Fatal Logic Errors): تظهر أثناء التشغيل (Runtime)، وتتسبب في انهيار البرنامج وتوقفه المفاجئ عن العمل (مثل القسمة على صفر x / 0).

        // statements
        break;
    case 2:
    case 3: // Multiple labels sharing one logic
        // statements
        break;
    default:
        // executes if no case matched
        break;
}

2. كبسولات المراجعة السريعة:

  • == مقابل =: المعامل الأول مقارنة منطقية يرجع true/false، والثاني إسناد يعدل قيمة المتغير وقيمته هي القيمة المسندة (إذا كانت غير صفرية تُعامل كـ True).
  • Lvalue مقابل Rvalue: الـ Lvalue يقع يسار علامة التساوي وله عنوان ثابت في الذاكرة وقيمته قابلة للتعديل (x = 10;). الـ Rvalue يقع يميناً فقط كقيمة أو ناتج حسابي (10 = x; // خطأ فادح). الـ Lvalue يمكن استخدامه كـ Rvalue ولكن ليس العكس!
  • أمر break: وظيفته الخروج الفوري من switch، وبدونه يحدث الـ Fall-through وتُنفذ الحالات التالية تلقائياً.
  • الدائرة القصيرة (Short-Circuit): التوقف عن الفحص فور وضوح النتيجة الحتمية: (true || anything = true) و (false && anything = false).
