1.1 Anatomy of a C++ Program

يتكون أي برنامج بلغة C++ من مجموعة عناصر بنائية أساسية لا غنى عنها:

  • توجيهات ما قبل المعالجة (Preprocessor Directives): كل سطر يبدأ بعلامة #، مثل #include <iostream>، يوجه المترجم لتحميل ترويسة ملفات الإدخال والإخراج القياسية.
  • الدالة الرئيسية main(): نقطة الانطلاق الأساسية للتنفيذ، ووجودها إلزامي، وترجع قيمة رقمية صحيحة (int).
  • أمر إنهاء البرنامج return 0;: إشارة لنظام التشغيل بأن البرنامج انتهى بنجاح وبدون مشاكل.
  • الفاصلة المنقوطة ;: تنهي كل جملة برمجية تنفيذية (Statement).

1.2 Comments in C++

التعليقات عبارات غير تنفيذية يتجاهلها المترجم تماماً، وتُستخدم لتوثيق الكود وزيادة قابليته للقراءة:

  • Single-Line Comment: يبدأ بالعلامة // ويتجاهل المترجم ما تبقى من السطر.
  • Multi-Line (Block) Comment: يبدأ بالعلامة /* وينتهي بالعلامة */ لعدة أسطر متتالية.

1.3 Variables, Identifiers & Constants

المتغير (Variable): موقع محجوز في الذاكرة لتخزين قيمة قابلة للتعديل أثناء التشغيل.

قواعد تسمية المعرفات (Identifier Rules):

  1. تتكون فقط من الحروف (كبيرة وصغيرة)، الأرقام، والشرطة السفلية _.
  2. يجب أن تبدأ بحرف أو بشرطة سفلية (لا تبدأ برقم).
  3. لا تحتوي على مسافات أو رموز خاصة (#, -, !, $, %).
  4. ليست كلمة من الكلمات المحجوزة للغة (int, class, cin, return).

طرق الإعلان عن الثوابت (Constants):

  • عبر التوجيه المسبق: #define PI 3.14 (بدون فاصلة منقوطة).
  • عبر الكلمة المفتاحية: const float PI = 3.14; (إلزامية القيمة عند التعريف).

2.1 Arithmetic Operators & Precedence

تدعم C++ العمليات الحسابية الخمس (+, -, *, /, %):

ترتيب الأسبقية (Order of Evaluation):

  1. الأقواس (): الأولوية القصوى، ويُقيم القوس الداخلي أولاً.
  2. الضرب والقسمة وباقي القسمة *, /, %: من اليسار لليمين.
  3. الجمع والطرح +, -: تُنفذ أخيراً من اليسار لليمين.

2.2 Increment & Decrement Operators

معاملات التراكم تختصر العمليات: c += 3 تكافئ c = c + 3.

الفرق بين Pre-Increment و Post-Increment:

  • Pre-increment (++x): يُغير المتغير فوراً بزيادته 1، ثم تُستخدم القيمة الجديدة في التعبير الحالي.
  • Post-increment (x++): تُستخدم القيمة الحالية للمتغير في التعبير أولاً، ثم تتم الزيادة بعد انتهاء السطر أو التعبير.
  • إذا كان المتغير في سطر منفصل، فإن ++c; و c++; متطابقان تماماً.
TRACE EXAMPLE // PRE VS POST
inc_trace.cpp 
#include <iostream>
using namespace std;

int main() {
    int c = 5;
    cout << ++c << endl; // يطبع 6 (تمت الزيادة أولاً)
    cout << c++ << endl; // يطبع 6 (يطبع القيمة ثم تصبح c = 7)
    cout << c << endl;   // يطبع 7
    return 0;
}

2.3 Relational & Logical Operators

معاملات المقارنة ترجع true (1) أو false (0):

  • المقارنة: >, <, >=, <=, ==, !=.
  • المنطقية: && (AND), || (OR), ! (NOT).
A B A && B (AND) A || B (OR) !A (NOT)
true true true true false
true false false true false
false true false true true
false false false false true

تقييم الدائرة القصيرة (Short-Circuit Evaluation):

تتوقف C++ عن إكمال فحص التعبير المركب بمجرد معرفة النتيجة النهائية المؤكدة:

  • في &&: إذا كان الطرف الأول false، لا يُفحص الطرف الثاني أبداً (النتيجة حتماً false).
  • في ||: إذا كان الطرف الأول true، لا يُفحص الطرف الثاني أبداً (النتيجة حتماً true).

2.4 Confusing Equality (==) and Assignment (=)

خطر كارثي (Logic Bug):
كتابة if (payCode = 4) بدلاً من if (payCode == 4) تسند القيمة 4 إلى المتغير. ولأن الرقم 4 غير صفري، تُعتبر الشريطة صائبة دائماً (True) في C++، مما ينفذ الكود الداخلي دون أي تحذير خطأ من المترجم!

Lvalues مقابل Rvalues: الـ Lvalue موقع في الذاكرة يمكن أن يظهر يسار علامة التساوي وقيمته قابلة للتعديل (مثل المتغير x = 5;)، بينما الـ Rvalue قيمة مؤقتة تظهر على اليمين فقط (مثل الأرقام: لا يمكن كتابة 5 = x;).

3.1 The if & if/else Structures

هيكل الاختيار الأحادي (Single-Selection) يحدد مسار التنفيذ. في لغة C++ أي تعبير ينتج قيمة غير صفرية يُعد True، والقيمة الصفرية فقط تُعد False.

الجمل المركبة والأقواس (Compound Statements & Braces):
إذا تضمنت جملة if أو else أكثر من أمر واحد، يجب حصرها داخل أقواس معقوفة { }. نسيان الأقواس يجعل الجملة الأولى فقط تابعة للشرط، بينما تنفذ بقية الجمل في جميع الحالات.

3.2 Ternary Conditional Operator (?:)

طريقة مختصرة لكتابة جملة if/else مكونة من 3 أطراف: Condition ? Value_If_True : Value_If_False;

cout << (grade >= 60 ? "Passed" : "Failed");

3.3 Types of Programming Errors

  • أخطاء قواعدية (Syntax Errors): يكتشفها المترجم (Compiler) أثناء الترجمة وتمنع بناء البرنامج (مثل نسيان الفاصلة المنقوطة).
  • أخطاء منطقية (Logic Errors): يعمل البرنامج ولكن يُعطي مخرجات غير متوقعة. وتنقسم إلى:
    • Non-fatal logic errors: يكمل البرنامج عمله مع إعطاء نتائج حسابية غير صحيحة.
    • Fatal logic errors: يتوقف البرنامج عن العمل فجأة وينهار أثناء التشغيل (Runtime Crash مثل القسمة على صفر).

3.4 The switch Multiple-Selection Structure

تُستخدم switch للاختيار بين عدة احتمالات لقيمة متغير واحد بدلاً من التكرار الطويل لجمل if / else if:

COMPLETE EXAMPLE // DAYS IN MONTH WITH LEAP YEAR
days_in_month.cpp 
#include <iostream>
using namespace std;

int main() {
    int month, year;
    cout << "Enter month number (1-12): ";
    cin >> month;

    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            cout << "31 days" << endl;
            break;

        case 4: case 6: case 9: case 11:
            cout << "30 days" << endl;
            break;

        case 2:
            cout << "Enter year: ";
            cin >> year;
            if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
                cout << "29 days (Leap year)" << endl;
            } else {
                cout << "28 days (Normal year)" << endl;
            }
            break;

        default:
            cout << "Invalid month number!" << endl;
    }
    return 0;
}

2. Data Types, Sizes & Memory Specs

النوع الحجم النموذجي المدى التقريبي / الدقة أهم الملاحظات
bool 1 Byte 0 (false) أو 1 (true) أي قيمة غير صفرية تُعامل كـ true.
char 1 Byte رمز واحد (-128 إلى 127) يُكتب بين علامتي اقتباس فرديتين مثل 'A'.
short 2 Bytes -32,768 إلى 32,767 صحيح قصير موفر للمساحة.
int 4 Bytes حوالي ± 2.14 مليار النوع الافتراضي للأعداد الصحيحة.
long 4 أو 8 Bytes أعداد صحيحة كبيرة جداً يستخدم عند توقع تخطي سعة int.
float 4 Bytes دقة ~7 أرقام عشرية يحتوي على جزء كسري.
double 8 Bytes دقة ~15 رقماً عشرياً النوع الافتراضي للكسور ويوفر دقة مضاعفة.
long double 8 أو 16 Bytes دقة فائقة ممتدة للحسابات الهندسية والعلمية عالية الدقة.
قاعدة قسمة الأعداد الصحيحة (Integer Division Rule):
إذا كان الطرفان أعداداً صحيحة، فالنتيجة دائماً صحيحة مع حذف الجزء الكسري تماماً:
• 7 / 2 = 3  |  لكن 7.0 / 2 = 3.5 أو (double)7 / 2 = 3.5.

4. Quick Control Flow Syntax Templates

1. نموذج جملة switch-case القياسية:

switch_template.cpp 
switch (integral_variable) { // int or char only!
    case 1:
        // statements
        break;
    case 2:
    case 3: // Multiple labels sharing one logic
        // statements
        break;
    default:
        // runs if no case matched
        break;
}

2. ملخص الفروق والمصطلحات الامتحانية:

  • == مقابل =: المعامل الأول مقارنة يرجع منطقي (bool)، والثاني إسناد يعدل قيمة المتغير وقيمته هي القيمة المسندة (إذا كانت غير صفرية تُعامل كـ True).
  • break في switch: بدونها يحدث الـ Fall-through وتُنفذ كل الحالات التالية حتى أول break.
  • Short-Circuit: التوقف فور التأكد من النتيجة (true || anything = true) و (false && anything = false).
  • Lvalue vs Rvalue: الـ Lvalue يقع يسار علامة التساوي وله عنوان في الذاكرة (x = 10;)، الـ Rvalue يقع يميناً فقط (10 = x; // خطأ فادح).
