1.1 Anatomy of a C++ Program

Every standard C++ program is built from specific foundational components:

  • Preprocessor Directives: Lines starting with #, such as #include <iostream>, instructing the preprocessor to attach headers for input/output facilities.
  • Main Function main(): The designated execution entry point where program control starts. It must return an integer (int).
  • Return Statement return 0;: Exits the function and signals normal program termination back to the operating system.
  • Semicolon ;: Required punctuation mark terminating every executable statement.
SAMPLE CODE // FIRST PROGRAM
welcome.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to C++!\n";
    return 0;
}

1.2 Comments in C++

Comments are non-executable text statements ignored by the compiler, used strictly for documentation:

  • Single-Line Comment: Begins with // and ignores the remainder of that line.
  • Multiple-Line (Block) Comment: Starts with /* and ends with */, spanning across multiple lines.

1.3 Variables, Identifiers & Constants

Variable: A named memory location dedicated to holding data that can change during runtime.

Identifier Naming Rules:

  1. Can only contain letters (uppercase and lowercase), digits, and the underscore character _.
  2. Must begin with a letter or an underscore (never a digit).
  3. Cannot contain spaces or special punctuation symbols (#, -, !, $, %).
  4. Cannot be any of the reserved language keywords (int, class, cin, return).

Defining Constants:

  • Using Preprocessor: #define PI 3.14 (no semicolon).
  • Using Keyword: const float PI = 3.14; (initialization mandatory).

2.1 Arithmetic Operators & Precedence

Standard arithmetic operators: Addition (+), Subtraction (-), Multiplication (*), Division (/), and Modulo (%):

Operator Precedence Hierarchy:

  1. Parentheses (): Evaluated first from innermost to outermost.
  2. Multiplicative (*, /, %): Evaluated next, left-to-right.
  3. Additive (+, -): Evaluated last, left-to-right.

2.2 Increment & Decrement Operators

Compound assignment abbreviations: c += 3 is equivalent to c = c + 3.

Prefix vs Postfix Evaluation:

  • Pre-increment (++x): Increments the variable first, then yields the updated value for the rest of the expression.
  • Post-increment (x++): Supplies the current value to the expression first, then increments the variable afterwards.
  • When standing alone as a single statement (e.g., ++c; vs c++;), both produce the exact same final result.
TRACE EXAMPLE // PRE VS POST
inc_trace.cpp 
#include <iostream>
using namespace std;

int main() {
    int c = 5;
    cout << ++c << endl; // Prints 6 (incremented immediately)
    cout << c++ << endl; // Prints 6 (evaluates current value, then c becomes 7)
    cout << c << endl;   // Prints 7
    return 0;
}

2.3 Relational & Logical Operators

Relational operators yield boolean results: true (1) or false (0):

  • Comparison: >, <, >=, <=, ==, !=.
  • Logical: && (AND), || (OR), ! (NOT).
A B A && B (AND) A || B (OR) !A (NOT)
true true true true false
true false false true false
false true false true true
false false false false true

Short-Circuit Evaluation:

C++ optimizes boolean evaluation by stopping early once the outcome is definitively guaranteed:

  • In &&: If the left operand is false, the right operand is never evaluated (result is false).
  • In ||: If the left operand is true, the right operand is never evaluated (result is true).

2.4 Confusing Equality (==) and Assignment (=)

CRITICAL LOGICAL BUG:
Writing if (payCode = 4) instead of if (payCode == 4) assigns 4 to payCode. Because 4 is non-zero, it evaluates as True in C++, executing the conditional branch unconditionally without any compiler warning!

2.5 Lvalues vs Rvalues

Understanding which operands can be assigned to is fundamental to C++ syntax and assignment semantics:

  • Lvalues (Left Values): Expressions that can appear on the left-hand side of an assignment equation. They identify actual, persistent storage locations in computer memory whose contents can be modified (for example, variable names like x = 4;).
  • Rvalues (Right Values): Expressions that can only appear on the right-hand side of an assignment equation. They represent temporary values, calculations, or literal constants (such as numbers: you cannot write 4 = x;).
  • Cardinal Rule: Lvalues can be used as Rvalues, but Rvalues cannot be used as Lvalues.
int x = 10; // 'x' is an lvalue, 10 is an rvalue (Valid)
int y = x; // 'y' is an lvalue, 'x' is evaluated as an rvalue (Valid)
10 = x; // COMPILE ERROR: constant '10' is an rvalue and cannot be assigned to

3.1 The if & if/else Structures

The single-selection structure routes control based on boolean conditions. In C++, any non-zero value is treated as True, and zero alone is treated as False.

Compound Statements & Braces:
When an if or else clause controls multiple statements, they must be wrapped inside curly braces { }. Without braces, only the very first statement is conditioned; the subsequent statements will execute unconditionally.

3.2 Ternary Conditional Operator (?:)

Shorthand for simple if/else branching: Condition ? Value_If_True : Value_If_False;

cout << (grade >= 60 ? "Passed" : "Failed");

3.3 Complete Classification of Programming Errors

Programming errors are divided based on when they manifest and their severity:

Error Category Detection Timing Consequence / Behavior Examples
Syntax Errors Compilation Time Caught by compiler; program fails to compile into an executable binary. Missing semicolons ;, misspelled keywords (cot), unmatched braces {.
Non-fatal Logic Errors Runtime (Execution) The program runs and completes normally, but produces incorrect or unintended output. Using = instead of ==, wrong precedence in averages a+b/2 instead of (a+b)/2.
Fatal Logic Errors Runtime (Execution) The program crashes or terminates prematurely before executing subsequent instructions. Division by zero (x / 0), infinite recursion overflowing stack memory.

3.4 The switch Multiple-Selection Structure

Replaces lengthy chained else if statements when comparing one integral expression against distinct constant values:

COMPLETE EXAMPLE // DAYS IN MONTH WITH LEAP YEAR
days_in_month.cpp 
#include <iostream>
using namespace std;

int main() {
    int month, year;
    cout << "Enter month number (1-12): ";
    cin >> month;

    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            cout << "31 days" << endl;
            break;

        case 4: case 6: case 9: case 11:
            cout << "30 days" << endl;
            break;

        case 2:
            cout << "Enter year: ";
            cin >> year;
            if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)) {
                cout << "29 days (Leap year)" << endl;
            } else {
                cout << "28 days (Normal year)" << endl;
            }
            break;

        default:
            cout << "Invalid month number!" << endl;
    }
    return 0;
}

4. Programming Errors Taxonomy

  • Syntax Errors: Detected at compile-time by the compiler. Prevents binary creation (e.g., missing semicolon ;, misspelled keywords).
  • Non-Fatal Logic Errors: Occurs at runtime. Program runs to completion, but yields incorrect results (e.g., assignment payCode = 4 inside if, incorrect formula).
  • Fatal Logic Errors: Occurs at runtime. Program crashes or exits prematurely (e.g., division by zero x / 0).

2. Key Exam Terminology Review:

  • == vs =: == is an equality test returning a boolean. = performs assignment and evaluates to the assigned value (non-zero is True).
  • Lvalue vs Rvalue: Lvalues appear on the left of an assignment, have addressable memory, and can be modified. Rvalues appear on the right, representing values or constants. Lvalues can be used as Rvalues, but not vice-versa!
  • break in switch: Prevents fall-through execution into consecutive case branches.
  • Short-Circuiting: Early evaluation exit: (true || expr = true) and (false && expr = false).
