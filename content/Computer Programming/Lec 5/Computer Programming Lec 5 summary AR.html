Part 1: What is a Nested Loop? — Execution Order & Fundamentals

ملخص هندسي وتطبيقي شامل لمحاضرة Nested Loops مع تتبع الشفرات البرمجية، كبسولة المراجعة، وأسئلة الاختبار التفاعلي.

Part 1: Introduction, Objectives & Single vs Nested Loops

🎯 Learning Objectives (أهداف المحاضرة الأساسية)

  • Explain the idea: فهم آلية عمل الحلقة الخارجية (Outer Loop) والحلقة الداخلية (Inner Loop).
  • Trace execution: التتبع الدقيق لترتيب التنفيذ وعدد مرات تكرار كل حلقة.
  • Predict output: قراءة الشفرة واستنتاج المخرجات بدقة.
  • Build patterns: بناء الشبكات (Grids)، الجداول، والأشكال الهندسية.

Part 3: Calculating Iterations — Independent vs Dependent Loops

🔢 القواعد الحسابية لعدد مرات تنفيذ جسم الحلقة (Inner Body Executions)

  • الحلقات المستقلة (Independent Loops): نضرب عدد دورات الخارجية في عدد دورات الداخلية:
    $$\text{Total} = \text{Outer} \times \text{Inner}$$
  • الحلقات التابعة (Dependent Loops): نجمع مرات التكرار سطراً بسطر (Row-by-Row Summation):
    $$\text{Total} = 1 + 2 + \dots + N = \frac{N(N+1)}{2}$$
حساب عداد الحلقات التابعة: for (int j = 1; j <= i; j++) 
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++) {
        cout << j << " ";
    }
    cout << endl;
}
• السطر 1: يطبع 1 (1 مرة)
• السطر 2: يطبع 1 2 (2 مرات)
• السطر 3: يطبع 1 2 3 (3 مرات)
• السطر 4: يطبع 1 2 3 4 (4 مرات)
$$\text{Total} = 1 + 2 + 3 + 4 = 10 \text{ Prints}$$

Part 4: Common Mistakes & Debugging Guide

الخطأ الشائعالكود الخاطئ أو السلوكالنتيجة والتصحيح النموذجي
Wrong Variable
تعديل العداد الخاطئ		 for(int col=1; col<=4; row++) كارثة برمجية: يؤدي إلى حلقة لا نهائية (Infinite Loop) لأن col لا يزيد أبداً.
التصحيح: استخدام col++.
Missing Braces
نسيان الأقواس المعقوفة		 for(...) cout << "*"; cout << endl; تعتبر لغة C++ جملة واحدة فقط تابعة للحلقة، وتسقط جملة السطر الجديد خارجها.
No Newline
نسيان سطر جديد		 بدون cout << endl; تتكدس كافة النجوم في سطر واحد طويل جداً وتفقد التنسيق الشبكي.
Off-by-one limit
خطأ حدود الزيادة		 i < 5 مقابل i <= 5 الأولى تدور 4 مرات فقط بينما الثانية تدور 5 مرات كاملة.
Debug It: لماذا لا يطبع هذا الكود شبكة 3 × 4؟ (Slide 15)
اكتشف الخطأ البرمجي في الكود التالي: 
for (int row = 1; row <= 3; row++) {
    for (int col = 1; col <= 4; row++) { // <-- لاحظ هنا!
        cout << "* ";
    }
    cout << endl;
}
التحليل والتصحيح:
• المشكلة: تم كتابة row++ داخل الحلقة الداخلية بدلاً من col++. هذا يعني أن متغير العمود يظل ثابتاً عند 1 مما يمنع الحلقة من التوقف.
• التصحيح السليم: استبدالها بـ col++.

• السطر 2 (i=2): j=1, 2 → ينطبع 3 4 ثم سطر جديد.
• السطر 3 (i=3): j=1, 2, 3 → ينطبع 4 5 6.

Exit Ticket: أسئلة التقييم الختامي للمحاضرة (Slide 20)
1. متى يُعاد ضبط وبدء الحلقة الداخلية من جديد؟
2. كم مرة يُنفذ جسم الحلقة إذا دارت الخارجية 4 مرات والداخلية 3 مرات في كل دورة؟
3. ما الذي يتغير عند استبدال شرط الداخلية بـ j <= i؟
1. إجابة السؤال الأول:
يُعاد ضبط الحلقة الداخلية من قيمتها الابتدائية في كل مرة تنتقل فيها الحلقة الخارجية إلى الدورة التالية.
2. إجابة السؤال الثاني:
الحلقتان مستقلتان، إذن: $$\text{Total} = 4 \times 3 = 12 \text{ times}$$
3. إجابة السؤال الثالث:
يتغير الشكل من مستطيل ثابت الأعمدة إلى نمط مثلثي متزايد، وتُحسب التكرارات بمجموع المتوالية الحسابية (1 + 2 + ... + n).

هذه الكبسولة تلخص أهم النقاط الشائعة التي تركز عليها أسئلة التتبع (Tracing) والاختيار من متعدد (MCQ) الخاصة بـ Nested Loops.

القاعدة 1: عدد مرات تكرار الحلقات المستقلة (Independent Loops Formula)

عندما يكون شرط الدوران للحلقة الداخلية ثابتاً ولا يعتمد على عداد الحلقة الخارجية، فإن إجمالي مرات تنفيذ جسم اللوب الداخلي يُحسب مباشرة بعملية الضرب:

$$\text{Total Executions} = \text{Outer} \times \text{Inner} = N \times M$$
مثال سريع وتطبيق فوري:
for (int i = 0; i < 4; i++) { // Outer runs 4 times (0, 1, 2, 3)
  for (int j = 1; j <= 5; j++) { // Inner runs 5 times (1, 2, 3, 4, 5)
    cout << "*";
  }
}
الناتج: 4 × 5 = 20 مرة
القاعدة 2: متسلسلة المثلث التزايدي التابع (Triangular Loop Formula)

إذا كان شرط الحلقة الداخلية معتمداً على عداد الخارجية بالشكل j <= i حيث تبدأ i من 1 إلى n، فإن عدد التكرارات يتبع متسلسلة غاوس الحسابية:

$$\text{Total} = 1 + 2 + 3 + \dots + n = \frac{n(n + 1)}{2}$$
مثال سريع (n = 5):
for (int i = 1; i <= 5; i++) {
  for (int j = 1; j <= i; j++) cout << "*";
  cout << endl;
}
إجمالي النجوم المطبوعة: 5 × (5 + 1) / 2 = 15 نجمة
القاعدة 3: فخ الامتحان الأشهر — تأثير break و continue داخل Nested Loops

⚠️ قاعدة ذهبية لا تنساها: جملة break; تنهي أضيق حلقة تحيط بها مباشرة فقط (Innermost Loop)، ولا توقف الحلقة الخارجية أبداً!

تتبع هذا السؤال الخادع:
for (int i = 1; i <= 3; i++) {
  for (int j = 1; j <= 4; j++) {
    if (j == 2) break; // يوقف اللوب الداخلي فقط!
    cout << i << j << " ";
  }
}
المخرجات ستكون: 11 21 31 (لأن الحلقة الداخلية تطبع عند j=1 ثم يحصل break، وتنتقل الخارجية للدورة التالية).
القاعدة 4: الموضع الصحيح لنزول سطر جديد (cout << endl)

لكي يظهر الشكل كشبكة منتظمة أو مثلث سليم:

  • مكان cout << endl; الصحيح هو نهاية اللوب الخارجي (بعد اكتمال طباعة أعمدة السطر بالكامل).
  • إذا وُضع أمر endl بالخطأ داخل اللوب الداخلي، فسيتم النزول لسطر جديد بعد كل رمز أو نجمة منفردة ويتحول الشكل إلى عمود طولي أحادي!
التوزيع الهيكلي الصحيح:
for (int row = 1; row <= 3; row++) {
  for (int col = 1; col <= 3; col++) {
    cout << "* ";
  } // نهاية السطر الحالي
  cout << endl; // ✅ المكان الصحيح هنا بعد انتهاء جميع الأعمدة
}

القاعدة 6: فخ الحلقة اللانهائية (Accidental Infinite Loop in Inner Loop)

من أكثر الأخطاء شيوعاً في الامتحانات كتابة اسم العداد الخارجي في جملة تحديث العداد الداخلي سهواً:

⚠️ الكود القاتل (Deadly Bug):
for (int row = 1; row <= 3; row++) {
  for (int col = 1; col <= 4; row++) { // ❌ خطأ فادح!
    cout << "* ";
  }
  cout << endl;
}
النتيجة: المتغير col يظل ثابتاً عند 1 والشرط col <= 4 يظل متحققاً للأبد، مما ينتج عنه تكرار لا نهائي (Infinite Loop) وانهيار البرنامج.
التصحيح السريع: كتابة col++ داخل تحديث اللوب الداخلي.
