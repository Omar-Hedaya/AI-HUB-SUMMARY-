الجزء 1: تشريح الحلقة الفردية مقابل المتداخلة ونموذج التنفيذ الذهبي

🎯 أهداف المحاضرة الأساسية (Lecture Learning Objectives)

  • شرح الفكرة: استيعاب ووصف وظيفة الحلقة الخارجية (Outer Loop) كمنظم عام للصفوف، والداخلية (Inner Loop) كمعالج لعناصر السطر.
  • تتبع التنفيذ: عد وحساب مرات تكرار كل حلقة وتتبع قيم المتغيرات بدقة في الذاكرة (RAM).
  • توقع المخرجات: قراءة أكواد C++ المتداخلة واستنتاج ناتجها المطبوع خطوة بخطوة قبل تشغيل البرنامج.
  • بناء الأنماط: توظيف الحلقات المتداخلة لإنشاء الشبكات الثنائية، الجداول الرياضية، ورسم الأشكال الهندسية.
تشريح الحلقة الفردية: كيف تتحرك في الذاكرة؟
كود بسيط يطبع الأرقام 1 2 3 لملاحظة دورة حياة المتغير i:
single_loop_anatomy.cpp 

  

    🧠 المنطق البرمجي
    💾 الذاكرة
    ⚙️ مسار التحكم
  

  ترويسة الحلقة الفردية:
  
• int i = 1: خطوة التهيئة، تُحجز خانة في الذاكرة لمتغير صحيح اسمه i وتُسند له القيمة 1 (تُنفذ مرة واحدة فقط عند البداية).
  
• i <= 3: شرط الاستمرار، يُفحص قبل الدخول لجسم الحلقة؛ طالما أن القيمة ≤ 3 يُسمح بالتنفيذ.
  
• i++: خطوة التحديث، تزيد قيمة i بمقدار 1 بعد اكتمال تنفيذ جسم الحلقة كاملاً ثم يُعاد فحص الشرط.

for (int i = 1; i <= 3; i++) {



  

    🧠 عملية الإخراج
  

  يقوم مجرى الإخراج cout بقراءة القيمة اللحظية للمتغير i من الذاكرة وإرسالها إلى شاشة العرض متبوعة بمسافة. لا يتم النزول لسطر جديد هنا، فتظهر الأرقام بجوار بعضها.

    cout << i << " ";



  

    🔒 حدود النطاق (Scope)
    ⚙️ القفز التلقائي
  

  قوس الإغلاق يعلن نهاية دورة واحدة؛ يقفز المعالج فوراً إلى خطوة التحديث i++ بالأعلى، ثم يفحص الشرط من جديد حتى يصبح i = 4 فيفشل الشرط وتتوقف الحلقة تماماً.

}
👈 اسحب الجدول أفقياً لتصفح المقارنة الفنية الكاملة 👉
المفهوم التقنيالشفرة البرمجية والتشبيه الذهنيآلية وسلوك التنفيذ البرمجي الدقيق
تشبيه عقارب الساعة
(Clock Metaphor)		 Outer = عقرب الساعات (بطيء)
Inner = عقرب الدقائق (سريع) 		عقرب الساعات لا ينتقل من الساعة 1 إلى الساعة 2 إلا بعد أن يكمل عقرب الدقائق دورة كاملة (60 دقيقة). بالمثل، لا ينتقل اللوب الخارجي للسطر التالي إلا بعد اكتمال جميع دورات اللوب الداخلي بالكامل.
إعادة ضبط العداد الداخلي
(Inner Loop Reset)		 col resets to initial value في كل مرة ينتهي فيها السطر وتزيد دورة اللوب الخارجي، يُعاد استدعاء سطر بداية اللوب الداخلي، فيبدأ عداد الأعمدة من قيمته الابتدائية (مثلاً col = 1) كأنه يبدأ لأول مرة.

الجزء 2: الأنماط الأساسية وجداول التتبع المنظم (Trace Tables)

مثال 1: طباعة مستطيل النجوم (3 صفوف × 4 أعمدة)
ثلاث دورات خارجية × أربع دورات داخلية = 12 نجمة إجمالاً:
stars_rectangle.cpp 

  

    🧠 الحلقة الخارجية (Outer Loop)
    💾 مسؤول الصفوف
  

  الهدف: إنشاء وإدارة الصفوف.
  
• يبدأ العداد row = 1 ويمثل رقم السطر الأول.
  
• الشرط row <= 3 يضمن أن الشبكة ستتكون من 3 صفوف بالضبط.
  
• في كل دورة لهذا اللوب، يثبت المتغير row بينما يقوم اللوب الداخلي برسم كامل أعمدة هذا السطر.

for (int row = 1; row <= 3; row++) {



  

    🧠 الحلقة الداخلية (Inner Loop)
    💾 مسؤول الأعمدة
  

  الهدف: رسم محتويات السطر المفتوح حالياً.
  
• يبدأ العداد col = 1 ويعاد ضبطه إلى 1 مع كل صف جديد.
  
• الشرط col <= 4 يجبر هذه الحلقة على الدوران 4 مرات متتالية داخل نفس الصف لطباعة 4 أعمدة.

    for (int col = 1; col <= 4; col++) {



  

    🧠 الطباعة الأفقية
  

  طباعة نجمة ومسافة على شاشة المخرجات دون نزول سطر جديد. هذا الأمر سيتكرر 4 مرات متجاورة في كل سطر.

        cout << "* ";



  

    🔒 نهاية اللوب الداخلي
  

  عند اكتمال العمود الرابع (col = 5 يفشل الشرط)، تنتهي الحلقة الداخلية وينتقل التحكم إلى السطر التالي مباشرة خارجها.

    }



  

    🧠 النزول لسطر جديد
    ⚠️ موقع حرج
  

  الموقع الحاسم: هذا السطر كُتب خارج اللوب الداخلي ولكن داخل اللوب الخارجي. معناه: بعد أن تنتهي من طباعة جميع الأعمدة الأربعة للسطر الحالي، انزل إلى سطر جديد في الشاشة قبل أن تبدأ الصف التالي.

    cout << endl;



  

    ⚙️ نهاية اللوب الخارجي
  

  يقفز المعالج إلى row++ ليزيد رقم الصف (يصبح 2)، ويعود لفحص الشرط row <= 3 لتبدأ دورة صف جديدة بالكامل.

}

مثال 2: جدول الضرب التنسيقي 5 × 5 (باستخدام \t)
الحلقة الخارجية تختار المضروب الأول؛ والحلقة الداخلية تضربه في الأرقام من 1 إلى 5:
multiplication_table.cpp 

  

    🧠 المضروب الأساسي (الصف)
    💾 المتغير i
  

  تحديد جدول الرقم: المتغير i يمثل الرقم الأساسي الذي نريد طباعة جدول مضاعفاته (1 ثم 2 ثم 3 ثم 4 ثم 5). يظل ثابتاً طوال الصف الواحد.

for (int i = 1; i <= 5; i++) {



  

    🧠 المضاعف الدوري (العمود)
    💾 المتغير j
  

  توليد المضاعفات: المتغير j يبدأ من 1 ويصل إلى 5، ليمثل المعامل الذي نضرب فيه الرقم i داخل هذا السطر.

    for (int j = 1; j <= 5; j++) {



  

    🧠 الحساب والجدولة
  

  العملية والتنسيق: يُحسب ناتج العملية الحسابية i * j فورياً في المعالج، ثم يُطبع متبوعاً بمحرف الجدولة "\t". فائدة \t هي ترك مسافة تبويب أفقية ثابتة تجعل الأعداد ذات الخانة الواحدة والخانethnic متطابقة رأسياً فوق بعضها كالأعمدة المحترفة.

        cout << i * j << "\t";



  

    🔒 انتهاء مضاعفات الرقم الحالي
  

  نهاية حلقة المضاعفات بعد طباعة 5 نواتج في السطر نفسه.

    }



  

    ⚙️ فصل جداول الضرب بسطر
  

  النزول إلى سطر جديد لبدء جدول الرقم التالي في سطر مستقل ونظيف.

    cout << endl;



  

    ⚙️ الانتقال للمضروب التالي
  

  تزيد قيمة i بمقدار 1 لتبدأ مضاعفات الرقم التالي.

}

مثال 3: تتبع المتغيرات المتغيرة (طباعة العدادين ij)
تتبع كلا العدادين لمعرفة أيهما يتغير بسرعة وأيهما يتغير ببطء:
print_ij.cpp 

  

    🧠 العداد البطيء
    💾 i = 1, 2, 3
  

  العداد الخارجي i يدور 3 مرات فقط. يمثل منزلة العشرات في المخرجات الرقمية لأنه يظل ثابتاً لفترة أطول.

for (int i = 1; i <= 3; i++) {



  

    🧠 العداد السريع
    💾 j = 1, 2
  

  العداد الداخلي j يدور مرتين في كل دورة للمتغير i. يمثل منزلة الآحاد لأنه يدور بسرعة ويعاد ضبطه إلى 1 فوراً عند كل زيادة في i.

    for (int j = 1; j <= 2; j++) {



  

    🧠 الدمج البصري للعدادين
  

  طباعة قيمة i متبوعة مباشرة بقيمة j دون أي علامة جمع رياضية، مما يؤدي لظهور الرقمين مدمجين كعدد ثنائي الخانات مثل 11 ثم 12، متبوعين بمسافة.

        cout << i << j << " ";



  

    🔒 انتهاء دورة j الحالية
  

  إغلاق حلقة j بعد المرور على 1 و 2.

    }



  

    ⚙️ انتقال i للدورة التالية
  

  نهاية دورة i دون أمر endl؛ مما يجعل النتائج كلها تطبع على سطر واحد أفقي متصل.

}
مسار التتبع اليدوي وقيم العدادات:
• عندما i = 1: العداد j يأخذ 1 ثم 2 → ينطبع 11 12
• عندما i = 2: يُعاد ضبط j إلى 1 ثم 2 → ينطبع 21 22
• عندما i = 3: يُعاد ضبط j إلى 1 ثم 2 → ينطبع 31 32
المخرجات النهائية الكاملة على سطر واحد:
11 12 21 22 31 32
مثال 4: بناء المثلث بالحد التابع (الشرط التابع: col <= row)
الحد الأقصى لعداد الحلقة الداخلية يعتمد على قيمة عداد الحلقة الخارجية:
triangle.cpp 

  

    🧠 السطر المتحكم بالارتفاع
    💾 row = 1 to 5
  

  الحلقة الخارجية تتحكم في ارتفاع المثلث (عدد الصفوف من 1 إلى 5). القيمة الحالية لـ row ستكون هي نفسها الحد الأقصى لعدد النجوم التي ستُطبع في هذا السطر.

for (int row = 1; row <= 5; row++) {



  

    🧠 سر النمط المثلثي (الحد التابع)
    ⚠️ col <= row
  

  المنطق الجوهري للمثلث: شرط التوقف هنا ليس عدداً ثابتاً مثل 5، بل هو col <= row!
  
• في السطر الأول (row=1): تدور الحلقة الداخلية حتى col <= 1 (نجمة واحدة).
  
• في السطر الخامس (row=5): تدور الحلقة الداخلية حتى col <= 5 (خمس نجوم).

    for (int col = 1; col <= row; col++) {



  

    🧠 طباعة نجمة واحدة
  

  طباعة النجمة المكونة لضلع أو جسد المثلث في العمود الحالي.

        cout << "* ";



  

    🔒 انتهاء نجوم السطر الحالي
  

  إغلاق اللوب الداخلي بعد طباعة عدد نجوم مساوٍ تماماً لرقم السطر الحالي.

    }



  

    ⚙️ الانتقال لطباعة سطر مثلثي أوسع
  

  النزول لسطر جديد لإعطاء الشكل الهندسي المدرج للمثلث القائم.

    cout << endl;



  

    ⚙️ زيادة رقم الصف
  

  تزيد row فيتسع سقف الحلقة الداخلية في الدورة القادمة بنجمة إضافية.

}
المخرجات وآلية العمل:
* * * * * * * * * * * * * * *
• السطر 1 يطبع نجمة واحدة؛ والسطر 5 يطبع 5 نجوم.
• المستطيل (col <= 4): نفس عدد الأعمدة في كل سطر.
• المثلث (col <= row): عدد الأعمدة يتزايد ديناميكياً كلما زادت قيمة السطر row.

الجزء 3: الحسابات الرياضية للتكرارات — الحلقات المستقلة مقابل التابعة

🔢 القواعد الحسابية لعدد مرات تنفيذ جسم اللوب الداخلي

  • الحلقات المستقلة (Independent Loops): نضرب عدد دورات الخارجية في عدد دورات الداخلية:
    $$\text{Total Executions} = \text{Outer Count} \times \text{Inner Count}$$
  • الحلقات التابعة (Dependent Loops): نجمع عدد مرات التكرار سطراً بسطر وفق متسلسلة غاوس:
    $$\text{Total Executions} = 1 + 2 + 3 + \dots + N = \frac{N(N+1)}{2}$$
تتبع عدد تكرارات الحلقات التابعة سطراً بسطر مع الشرح التحليلي 

  

    🧠 العداد الخارجي (N = 4)
  

  حلقة تدور 4 دورات تمثل عدد الأسطر الإجمالي (1، 2، 3، 4).

for (int i = 1; i <= 4; i++) {



  

    🧠 عدد دورات ديناميكي
    💾 j <= i
  

  العداد الداخلي يدور عدداً من المرات مساوياً لقيمة i الحالية في كل سطر.

    for (int j = 1; j <= i; j++) {



  

    🧠 طباعة رقم العمود
  

  طباعة قيمة j متبوعة بمسافة؛ سينتج في كل سطر متوالية تبدأ دائماً من الرقم 1.

        cout << j << " ";



  

    🔒 اكتمال دورات السطر
  

  انتهاء التكرار الداخلي للسطر الحالي.

    }



  

    ⚙️ كسر السطر
  

  النزول إلى سطر جديد لطباعة السلسلة الرقمية التالية.

    cout << endl;



  

    ⚙️ إكمال الدورة الخارجية
  

  نهاية دورة الصف والانتقال للصف التالي.

}
• السطر 1 (i=1): يطبع 1 → مرة واحدة
• السطر 2 (i=2): يطبع 1 2 → مرتان
• السطر 3 (i=3): يطبع 1 2 3 → 3 مرات
• السطر 4 (i=4): يطبع 1 2 3 4 → 4 مرات
الإجمالي = 1 + 2 + 3 + 4 = 10 مرات طباعة

الجزء 4: الأخطاء الشائعة وجلسة تنقيح الأخطاء (Debug It)

نوع الخطأالكود الخاطئ أو السلوكالنتيجة والحل النموذجي
تعديل العداد الخاطئ
(Wrong Variable)		 for (int col=1; col<=4; row++) كارثة برمجية: يؤدي إلى حلقة لا نهائية (Infinite Loop) لأن col لا يزداد أبداً ويظل 1 للأبد.
التصحيح: استخدام col++ في ترويسة اللوب الداخلي.
نسيان الأقواس المعقوفة
(Missing Braces)		 for(...) cout << "*"; cout << endl; بدون الأقواس { }، تعتبر لغة C++ جملة الطباعة الأولى فقط تابعة للحلقة، وتُنفذ جملة السطر الجديد مرة واحدة في النهاية فقط.
نسيان النزول لسطر جديد
(No Newline)		 نسيان كتابة cout << endl; تتلاصق جميع العناصر في سطر أفقي واحد طويل جداً وتفقد التنسيق الشبكي.
أخطاء حدود الزيادة
(Off-by-One Limits)		 i < 5 مقابل i <= 5 الأولى تدور 4 مرات فقط (من 1 إلى 4)؛ بينما الثانية تدور 5 مرات كاملة (من 1 إلى 5).
Debug It: تشريح الخطأ الكارثي في ترويسة اللوب الداخلي (Slide 15)
اكتشف الخطأ البرمجي الدقيق وسبب حدوث اللوب اللانهائي: 

  

    🧠 حلقة الصفوف السليمة
  

  هذه الحلقة الخارجية سليمة برمجياً وتنتظر انتهاء الحلقة الداخلية للمرور على الصفوف الثلاثة.

for (int row = 1; row <= 3; row++) {



  

    ⚠️ الخطأ القاتل هنا!
    🧠 تحليل العطل البرمجي
  

  موطن الكارثة البرمجية: تم كتابة row++ بدلاً من col++ في خطوة التحديث!
  
• المتغير المفحوص في الشرط هو col <= 4.
  
• لكن المتغير الذي يزداد في الذاكرة هو row!
  
• النتيجة: المتغير col يظل ثابتاً عند 1 طوال الوقت، والشرط 1 <= 4 يظل صائباً (True) إلى الأبد، فيعلق المعالج في طباعة نجوم مستمرة وتنهار استجابة البرنامج!

    for (int col = 1; col <= 4; row++) {



  

    🧠 الطباعة المستمرة للأبد
  

  تظل هذه الجملة تطبع نجوماً بدون توقف ولا يستطيع المعالج الخروج من هذا اللوب أبداً.

        cout << "* ";



  

    ⚙️ كود ميت لا يُصل إليه
  

  هذا القوس يعيد التنفيذ لنفس اللوب الداخلي للأبد.

    }



  

    ⚙️ سطر معزول
  

  لن يصل التنفيذ إلى أمر endl إطلاقاً بسبب دوران اللوب الداخلي للأبد.

    cout << endl;



  

    ⚙️ نهاية لن تتحقق
  

  نهاية اللوب الخارجي.

}

• المشكلة: تم وضع row++ في خطوة التحديث داخل الحلقة الداخلية بدلاً من col++، مما يترك الشرط col <= 4 صائباً للأبد.

القاعدة 2: الحلقات التابعة لنمط المثلث (متسلسلة غاوس الحسابية)

إذا كان شرط الداخلية مقيداً بعداد الخارجية (j <= i) من 1 إلى N، تُحسب التكرارات بقانون مجموع المتسلسلة:

$$\text{Total Executions} = 1 + 2 + 3 + \dots + N = \frac{N(N + 1)}{2}$$

القاعدة 3: فخ جملتي break و continue في الحلقات المتداخلة
