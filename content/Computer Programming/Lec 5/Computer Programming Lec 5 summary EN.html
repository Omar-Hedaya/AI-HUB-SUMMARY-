    ⚙️ Control Flow

• int i = 1: Initialization step. Allocates 4 bytes in stack memory for integer i and assigns initial value 1. Executes exactly once at loop entry.

    🔒 Scope Boundary
    ⚙️ Branching Jump
  

  Closing brace signals the end of one iteration. Control jumps back to the update step i++, then tests i <= 3 again. When i hits 4, condition evaluates to false, terminating the loop.

}

stars_rectangle.cpp

    💾 row = 1 to 3
  

  Purpose: Manages the row progression.
  
• Initializes row = 1 in stack memory.
  
• Condition row <= 3 guarantees that exactly 3 rows are produced.
  
• During each outer cycle, row remains fixed while the inner loop generates all columns for that row.

for (int row = 1; row <= 3; row++) {



  

    🧠 Inner Loop (Column Worker)
    💾 col = 1 to 4
  

  Purpose: Fills columns in the currently active row.
  
• Resets col = 1 at the start of every new row.
  
• Condition col <= 4 forces 4 consecutive prints horizontally before yielding control back to the outer loop.

    for (int col = 1; col <= 4; col++) {

  Outputs a star followed by a space without advancing the terminal cursor down. Repeats 4 times per row.

        cout << "* ";



  

    🔒 Inner Loop Termination
  

  After column 4 finishes (col = 5 fails condition), inner loop exits and control proceeds to the next statement.

    }



  

    🧠 Row Terminator
    ⚠️ Critical Placement
  

  Critical placement: Positioned outside the inner loop, but inside the outer loop. Once all 4 columns are printed, flushes buffer and drops cursor to a fresh line for the next row.

    cout << endl;



  

    ⚙️ Outer Loop Cycle Repeat
  

  CPU jumps to row++ (incrementing row to 2), then evaluates row <= 3 to begin row 2.

}

Part 3: Calculating Iterations — Independent vs Dependent Loops

🔢 Arithmetic Rules for Inner Body Executions

  • Independent Loops: Multiply the iteration counts:
    $$\text{Total Executions} = \text{Outer Count} \times \text{Inner Count}$$
  • Dependent Loops: Count row-by-row and sum the arithmetic series:
    $$\text{Total Executions} = 1 + 2 + 3 + \dots + N = \frac{N(N+1)}{2}$$
Counting Dependent Iterations Row-by-Row 

  

    🧠 Outer Loop (N = 4 Rows)
  

  Outer loop controls 4 lines (i = 1, 2, 3, 4).

for (int i = 1; i <= 4; i++) {



  

    🧠 Dependent Limit (j <= i)
  

  Inner loop executes i times in each row, producing a variable execution count per line.

    for (int j = 1; j <= i; j++) {



  

    🧠 Stream Sequence
  

  Prints j followed by space, producing an incremental sequence starting from 1 on every line.

        cout << j << " ";



  

    🔒 Row Items Finished
  

  Inner loop finishes for the current row.

    }



  

    ⚙️ Line Feed
  

  Advances cursor to start the next numbered series on a new line.

    cout << endl;



  

    ⚙️ Outer Cycle Repeat
  

  Outer iteration completes, advancing to row i + 1.

}
• Row 1 (i=1): prints 1 → 1 print
• Row 2 (i=2): prints 1 2 → 2 prints
• Row 3 (i=3): prints 1 2 3 → 3 prints
• Row 4 (i=4): prints 1 2 3 4 → 4 prints
Total = 1 + 2 + 3 + 4 = 10 prints

Part 4: Common Mistakes & The Debugging Guide

Mistake TypeErroneous Code ExampleConsequence & How to Fix
Wrong Variable Update for (int col=1; col<=4; row++) Deadly Bug: Creates an Infinite Loop because col never increments and remains 1 forever.
Fix: Update col++ inside the inner loop header.
Missing Braces for(...) cout << "*"; cout << endl; Without braces { }, only the very first statement belongs to the loop. The newline executes only once at the end.
No Newline Omitting cout << endl; All row items concatenate into a single gigantic horizontal line without 2D shape.
Off-by-One Limits i < 5 vs i <= 5 The first executes 4 times (1 to 4); the second executes 5 full times (1 to 5).
Debug It: Dissecting the Infinite Loop Trap (Slide 15)
Identify the bug in the following C++ code snippet before looking at the fix: 

  

    🧠 Outer Loop OK
  

  Outer loop is structured properly to handle 3 rows.

for (int row = 1; row <= 3; row++) {



  

    ⚠️ Fatal Bug Here!
    🧠 Bug Mechanics
  

  Catastrophic defect: The post-expression updates row++ instead of col++!
  
• The continuation test checks col <= 4.
  
• However, col is never incremented in RAM; it remains 1 forever!
  
• The test 1 <= 4 evaluates to true indefinitely, locking the CPU in an infinite print cycle.

    for (int col = 1; col <= 4; row++) {



  

    🧠 Unstoppable Stream
  

  Executes without end due to the broken loop condition.

        cout << "* ";



  

    ⚙️ Dead Code Barrier
  

  Control is trapped within the inner loop scope and never escapes.

    }



  

    ⚙️ Unreachable Statement
  

  This newline statement is never reached due to the infinite loop above.

    cout << endl;



  

    ⚙️ Outer Closure
  

  Outer scope never completes cleanly.

}
Root Cause & Solution:
• Problem: The update expression in the inner loop increments row++ instead of col++. The condition col <= 4 remains true indefinitely.
• Correction: Replace with col++.

📌 Rapid Revision Guide Before Entering Your Exam

Key summary of essential rules tested in multiple-choice (MCQ) and code tracing exam questions.

Rule 1: Independent Loop Executions (Multiplication Principle)

When the inner loop termination condition is constant and independent of the outer loop variable, multiply the two limits:

$$\text{Total Executions} = \text{Outer} \times \text{Inner} = N \times M$$
Quick Trace with Deep Explanation:

  

    🧠 Outer Loop (4 Iterations)
  

  Outer counter i runs 4 times for values 0, 1, 2, 3.

for (int i = 0; i < 4; i++) {



  

    🧠 Inner Loop (5 Iterations)
  

  Inner counter j runs a static 5 times (1, 2, 3, 4, 5) per pass of i.

    for (int j = 1; j <= 5; j++) {



  

    💾 Print Execution Count
  

  Body executes 4 × 5 = 20 total times.

        cout << "*";
    }
}
Result: 4 × 5 = 20 stars
Rule 2: Dependent Triangular Loops (Gauss Summation)

If the inner condition is bounded by the outer counter (j <= i) from 1 to N, executions follow the triangular number formula:

$$\text{Total Executions} = 1 + 2 + 3 + \dots + N = \frac{N(N + 1)}{2}$$
Example for N = 5:
Calculation: 5 × 6 / 2 = 15 total iterations
Rule 3: The break & continue Trap in Nested Loops

⚠️ Golden Exam Rule: A break; statement exits only the innermost loop enclosing it. It never terminates the outer loop!

Tricky Trace Question with Deep Analysis:

  

    🧠 Outer Loop Continues
  

  Outer loop executes 3 passes (i = 1, 2, 3) and is immune to the inner break.

for (int i = 1; i <= 3; i++) {



  

    🧠 Inner Loop Target
  

  Inner counter j starts at 1.

    for (int j = 1; j <= 4; j++) {



  

    ⚠️ Break Trap
  

  Break Behavior: When j == 2, break aborts the inner loop only! Loops passes for j=2, 3, 4 are skipped, and control returns directly to the outer loop to start the next i.

        if (j == 2) break;



  

    🧠 Execution Condition
  

  Only runs when j = 1 in each outer loop pass.

        cout << i << j << " ";
    }
}
Output: 11 21 31 (The outer loop still executes for i=1, 2, and 3).
Rule 4: Proper Placement of cout << endl;
  • The correct place for cout << endl; is at the bottom of the outer loop body (after all columns of that row have printed).
  • Placing endl inside the inner loop forces a newline after every single character, collapsing your 2D grid into a single vertical column.
Rule 5: Printing i vs Printing j
Print StatementOutput FormUnderlying Mechanic

3 3 3		 Constant across each row: Variable i does not change while the inner loop is running.

Rule 6: Accidental Infinite Loop via Wrong Update Variable

The most frequent syntax mistake in exams is writing row++ in the inner loop header. This leaves col forever stuck at 1, keeping the termination condition permanently satisfied.
