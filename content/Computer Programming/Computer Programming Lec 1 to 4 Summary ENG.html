1.1 Anatomy of a C++ Program

Every standard C++ program is built from specific foundational components:

  • Preprocessor Directives: Lines starting with #, such as #include <iostream>, instructing the preprocessor to attach headers for input/output facilities.
  • Main Function main(): The designated execution entry point where program control starts. It must return an integer (int).
  • Return Statement return 0;: Exits the function and signals normal program termination back to the operating system.
  • Semicolon ;: Required punctuation mark terminating every executable statement.
SAMPLE CODE // FIRST PROGRAM
welcome.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Welcome to C++!\n";
    return 0;
}

1.2 Comments in C++

Comments are non-executable text statements ignored by the compiler, used strictly for documentation:

  • Single-Line Comment: Begins with // and ignores the remainder of that line.
  • Multiple-Line (Block) Comment: Starts with /* and ends with */, spanning across multiple lines.

1.3 Variables, Identifiers & Constants

Variable: A named memory location dedicated to holding data that can change during runtime.

Identifier Naming Rules:

  1. Can only contain letters (uppercase and lowercase), digits, and the underscore character _.
  2. Must begin with a letter or an underscore (never a digit).
  3. Cannot contain spaces or special punctuation symbols (#, -, !, $, %).
  4. Cannot be any of the reserved language keywords (int, class, cin, return).

Defining Constants:

  • Using Preprocessor: #define PI 3.14 (no semicolon).
  • Using Keyword: const float PI = 3.14; (initialization mandatory).

2.1 Arithmetic Operators & Precedence

Standard arithmetic operators: Addition (+), Subtraction (-), Multiplication (*), Division (/), and Modulo (%):

Operator Precedence Hierarchy:

  1. Parentheses (): Evaluated first from innermost to outermost.
  2. Multiplicative (*, /, %): Evaluated next, left-to-right.
  3. Additive (+, -): Evaluated last, left-to-right.

2.2 Increment & Decrement Operators

Compound assignment abbreviations: c += 3 is equivalent to c = c + 3.

Prefix vs Postfix Evaluation:

  • Pre-increment (++x): Increments the variable first, then yields the updated value for the rest of the expression.
  • Post-increment (x++): Supplies the current value to the expression first, then increments the variable afterwards.
  • When standing alone as a single statement (e.g., ++c; vs c++;), both produce the exact same final result.
TRACE EXAMPLE // PRE VS POST
inc_trace.cpp 
#include <iostream>
using namespace std;

int main() {
    int c = 5;
    cout << ++c << endl; // Prints 6 (incremented immediately)
    cout << c++ << endl; // Prints 6 (evaluates current value, then c becomes 7)
    cout << c << endl;   // Prints 7
    return 0;
}

2.3 Relational & Logical Operators

Relational operators yield boolean results: true (1) or false (0):

  • Comparison: >, <, >=, <=, ==, !=.
  • Logical: && (AND), || (OR), ! (NOT).

Short-Circuit Evaluation:

C++ optimizes boolean evaluation by stopping early once the outcome is definitively guaranteed:

  • In &&: If the left operand is false, the right operand is never evaluated (result is false).
  • In ||: If the left operand is true, the right operand is never evaluated (result is true).

2.4 Confusing Equality (==) and Assignment (=)

CRITICAL LOGICAL BUG:
Writing if (payCode = 4) instead of if (payCode == 4) assigns 4 to payCode. Because 4 is non-zero, it evaluates as True in C++, executing the conditional branch unconditionally without any compiler warning!

2.5 Lvalues vs Rvalues

  • Lvalues (Left Values): Expressions that can appear on the left-hand side of an assignment equation. They identify persistent, addressable memory locations whose contents can be modified (e.g. variable names like x = 4;).
  • Rvalues (Right Values): Expressions that can only appear on the right-hand side of an assignment equation. They represent temporary values, calculations, or literal constants (e.g. you cannot write 4 = x;).
  • Cardinal Rule: Lvalues can be used as Rvalues, but Rvalues cannot be used as Lvalues.

In C++, any non-zero value is treated as True, and zero alone is treated as False.

Compound Statements & Braces:
When an if or else clause controls multiple statements, they must be wrapped inside curly braces { }. Without braces, only the first statement is conditioned.

3.3 Complete Classification of Programming Errors

Error Category Detection Timing Consequence / Behavior Examples
Syntax Errors Compilation Time Caught by compiler; program fails to compile into an executable binary. Missing semicolons ;, misspelled keywords (cot), unmatched braces {.
Non-fatal Logic Errors Runtime (Execution) The program runs and completes normally, but produces incorrect or unintended output. Using = instead of ==, wrong precedence in averages a+b/2 instead of (a+b)/2.

3.4 The switch Multiple-Selection Structure

Replaces lengthy chained else if statements when comparing one integral expression against distinct constant values:

COMPLETE EXAMPLE // DAYS IN MONTH WITH LEAP YEAR
days_in_month.cpp 
#include <iostream>
using namespace std;

int main() {
    int month, year;
    cout << "Enter month number (1-12): ";
    cin >> month;

    switch (month) {
        case 1: case 3: case 5: case 7:
        case 8: case 10: case 12:
            cout << "31 days" << endl;
            break;
        case 4: case 6: case 9: case 11:
            cout << "30 days" << endl;
            break;
        case 2:
            cout << "Enter year: ";
            cin >> year;
            if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))
                cout << "29 days (Leap year)" << endl;
            else
                cout << "28 days (Normal year)" << endl;
            break;
        default:
            cout << "Invalid month number!" << endl;
    }
    return 0;
}

4. Control Structures (Iteration / Loops)

Repetition constructs: for, while, do/while, break vs continue statements, and nested loop patterns.

# 3 Constructs # For Loop # While Loop # Do/While Loop # Break vs Continue # Nested Patterns
EXAM PITFALL // Loops Edition: 1. Misplaced Semicolon: Writing for(int i=0; i<5; i++); { cout << i; } creates an empty loop body! The loop runs 5 times doing nothing, and the braces execute once afterwards with i=5.
2. Do/While Semicolon: Unlike while and for, the do { ... } while(cond); strictly requires a trailing semicolon.
3. Continue in While: In a while loop, executing continue jumps directly to the test condition, skipping any increment step placed at the end of the body, often causing an infinite loop!

4.1 The Three C++ Iterative Constructs

Loops allow repeated execution of code while a continuation test expression remains true:

  • for statement: Counter-controlled repetition, best suited when the exact number of iterations is known before loop execution begins.
  • while statement: Condition-controlled repetition that pre-tests the condition before each iteration (may execute 0 times).
  • do/while statement: Post-tested repetition that tests the continuation condition after executing the body, guaranteeing at least one execution.

4.2 The for Repetition Structure

The standard syntax brings initialization, condition testing, and incrementation together into a single line:

for ( ForInit ; LoopContinuationTest ; PostExpression ) {
    ActionStatements;
}

Execution Order in a for Loop:

  1. Initialization (ForInit): Evaluated exactly once at the very start of loop execution.
  2. Condition (ForExpr): Evaluated before each iteration. If true, the body executes. If false, the loop terminates.
  3. Action Body: Executes when the condition is true.
  4. Post-Expression (PostExpr): Evaluated after the body completes (usually incrementing/decrementing the loop counter).
  5. Flow loops back to Step 2.
Comma Operator in for Loops:
Multiple initializations and post-expressions can be chained using commas:
for (int i = 0, j = 0; j + i <= 10; j++, i++)
SAMPLE CODE // FOR LOOP SUMMATIONS
for_examples.cpp 
#include <iostream>
using namespace std;

int main() {
    // 1. Sum even numbers from 0 to 100
    int evenSum = 0;
    for (int i = 0; i <= 100; i += 2) {
        evenSum += i;
    }
    cout << "Even Sum = " << evenSum << endl; // 2550

    // 2. Print user character N times
    char ch = '*';
    int n = 5;
    for (int i = 0; i < n; i++) {
        cout << ch;
    }
    cout << endl;
    return 0;
}

4.3 The while Repetition Structure

A while loop executes repeatedly as long as the continuation expression evaluates to true. If initially false, the loop body never runs (0 executions).

SAMPLE CODE // WHILE LOOP FACTORIAL & ACCUMULATOR
factorial.cpp 
#include <iostream>
using namespace std;

int main() {
    int n, fact = 1;
    cout << "Enter a positive integer: ";
    cin >> n;

    int temp = n;
    while (temp > 0) {
        fact = fact * temp;
        temp--;
    }
    cout << "Factorial of " << n << " is " << fact << endl;
    return 0;
}
Rewriting a for loop as a while loop:
for (init; cond; inc) { body; } translates identically to:
init; while (cond) { body; inc; }

4.4 The do/while Repetition Structure

The do/while loop tests its condition after executing the body statement(s). Therefore, it is guaranteed to execute at least once.

do {
    statement(s);
} while ( condition ); // Note the required trailing semicolon!
SAMPLE CODE // DO-WHILE COUNTER
dowhile_counter.cpp 
#include <iostream>
using namespace std;

int main() {
    int counter = 1;
    do {
        cout << counter << " ";
    } while (++counter <= 10);
    cout << endl;
    return 0;
}

4.5 The break and continue Statements

The break Statement

Causes an immediate exit from a while, for, do/while, or switch block. Control transfers to the first statement immediately following the enclosing structure.

The continue Statement

Skips the remaining statements in the current iteration of the loop body and proceeds with the next iteration.

Difference in continue Execution:

  • In for loops: continue triggers the increment/post-expression step first, then evaluates the continuation test.
  • In while & do/while loops: continue jumps directly to the continuation test condition without updating statements located lower in the loop body.
SAMPLE CODE // BREAK AND CONTINUE IN ACTION
jump_statements.cpp 
#include <iostream>
using namespace std;

int main() {
    // 1. break: early exit when user enters 0
    int sum = 0, val;
    for (int i = 0; i < 5; i++) {
        cin >> val;
        if (val == 0) break; // exits loop early
        sum += val;
    }

    // 2. continue: skip numbers divisible by 4
    for (int count = 0; count <= 12; ++count) {
        if (count % 4 == 0) continue; // skips multiples of 4
        cout << count << " ";         // prints 1 2 3 5 6 7 9 10 11
    }
    cout << endl;
    return 0;
}

6. Programming Errors & Value Rules Summary

  • Syntax Errors: Caught at compile-time (missing semicolons, misspelled keywords).
  • Non-Fatal Logic Errors: Occur at runtime; program runs but produces wrong output (e.g. if(a=4)).
  • Fatal Logic Errors: Occur at runtime; program crashes immediately (e.g. dividing by zero).
  • Lvalue vs Rvalue: Lvalues reside in persistent memory and can be assigned to (left of =). Rvalues are temporary values/constants (right of =). Lvalues can act as Rvalues, but not vice versa!
