Part 1: Series-Parallel DC Circuits & Reduction Rules

👈 Scroll table horizontally to view formulas & descriptions 👉
Concept / LawAnalytical Formula (LTR)Physical Behavior & Rule
Series Equivalent Resistance $$R_s = R_1 + R_2 + \dots + R_n$$ Identical current passes through all series elements ($I = \text{const}$). Total voltage divides across elements: $V_T = \sum V_i$.
Parallel Equivalent Resistance $$\frac{1}{R_p} = \sum_{i=1}^n \frac{1}{R_i} \implies R_1 \parallel R_2 = \frac{R_1 \cdot R_2}{R_1 + R_2}$$ Same voltage across all parallel branches ($V = \text{const}$). For $n$ equal resistors: $R_p = R / n$.
Current Divider Rule (CDR) $$I_x = I_T \cdot \left(\frac{R_T'}{R_x}\right) = I_T \cdot \left(\frac{R_{\text{opposite}}}{R_1 + R_2}\right)$$ Divides total branch current between parallel resistors; smaller resistance draws proportionally larger current.
Voltage Divider Rule (VDR) $$V_x = V_T \cdot \left(\frac{R_x}{R_{\text{total\_series}}}\right)$$ Divides total loop voltage across series resistors directly proportional to individual resistance values.

⚡ Strategic Rule for Network Reduction

  • Identify two-terminal series connections (a single node connecting exactly two components).
  • Identify parallel branches (components sharing both top and bottom common nodes).
  • Always start simplifying from the farthest branch away from the independent source and reduce systematically towards source terminals.

Application / ScenarioOperating CriterionAnalytical Engineering Outcome

Wheatstone Bridge Balance $$\frac{R_1}{R_2} = \frac{R_3}{R_4} \implies V_A = V_B \implies V_{AB} = 0$$ When the bridge is balanced, current through the bridge branch $R_L$ is zero. It can be treated as open or short-circuited.

Part 3: Practical Source Transformations & Ideal Current Sources

👈 Scroll table horizontally to view formulas & descriptions 👉
Transformation ModelMathematical RelationEquivalence Principle
Voltage to Current Source $$I = \frac{E}{R_s}, \quad R_{s(\text{parallel})} = R_s$$ A practical voltage source $E$ in series with $R_s$ converts to a practical current source $I = E/R_s$ in parallel with $R_s$.
Current to Voltage Source $$E = I \cdot R_s, \quad R_{s(\text{series})} = R_s$$ A practical current source $I$ in parallel with $R_s$ converts to a practical voltage source $E = I \cdot R_s$ in series with $R_s$.
Ideal Current Source Behavior $$I_{\text{branch}} = I_s = \text{Constant}$$ Maintains specified current regardless of external connected network. Its internal resistance is infinite ($R_{\text{int}} = \infty$).
Parallel Current Sources $$I_{\text{net}} = \sum I_{\text{up}} - \sum I_{\text{down}}$$ Parallel current sources combine into a single equivalent source. Parallel internal resistors combine into $R_p$.

⚠️ Kirchhoff's Current Law (KCL) Violation Rule

Never connect two different ideal current sources in series (e.g., $I_1 = 3\text{ A}$ in series with $I_2 = 5\text{ A}$). This violates KCL at the connecting node since $I_{\text{in}} \ne I_{\text{out}}$.

Part 4: Delta-Wye ($\Delta - Y$) Transformations

👈 Scroll table horizontally to view formulas & descriptions 👉
Conversion DirectionAnalytical Formulas (LTR)General Memory Rule
$\Delta \to Y$ (Delta to Wye) $$R_1 = \frac{R_A R_C}{R_A + R_B + R_C}$$ $$R_2 = \frac{R_B R_C}{R_A + R_B + R_C}, \quad R_3 = \frac{R_A R_B}{R_A + R_B + R_C}$$ Each resistor in the $Y$ network equals the product of adjacent $\Delta$ resistors divided by the sum of all three $\Delta$ resistors.
$Y \to \Delta$ (Wye to Delta) $$R_A = \frac{R_1 R_2 + R_2 R_3 + R_3 R_1}{R_2}$$ $$R_B = \frac{\sum R_i R_j}{R_1}, \quad R_C = \frac{\sum R_i R_j}{R_3}$$ Each resistor in the $\Delta$ network equals the sum of all two-at-a-time products of $Y$ resistors divided by the opposite $Y$ resistor.
Balanced Network Condition $$R_\Delta = 3 R_Y \iff R_Y = \frac{1}{3} R_\Delta$$ When all three resistors in the network are equal, the equivalent $\Delta$ resistance is exactly three times the $Y$ resistance.

Part 5: Maximum Power Transfer Theorem (Session 4 Derivation)

👈 Scroll table horizontally to view formulas & descriptions 👉
Step / AspectAnalytical Derivation (LTR)Engineering Conclusion
Load Power Equation $$P_L = I_L^2 R_L = \left(\frac{V}{R_i + R_L}\right)^2 R_L = \frac{V^2 R_L}{(R_i + R_L)^2}$$ Power delivered to an adjustable load resistor $R_L$ connected to a practical source ($V, R_i$).
Maximization Condition $$\frac{dP_L}{dR_L} = \frac{V^2 (R_i + R_L)^2 - 2 R_L (R_i + R_L) V^2}{(R_i + R_L)^4} = 0$$ Setting derivative to zero yields: $$(R_i + R_L) - 2 R_L = 0 \implies \mathbf{R_L = R_i}$$
Maximum Delivered Power $$P_{L(\max)} = \frac{V^2 R_i}{(2 R_i)^2} = \frac{V^2}{4 R_i} = \frac{V^2}{4 R_L}$$ Efficiency at maximum power transfer is exactly 50%; the remaining 50% is dissipated as heat inside $R_i$.

Problem 1: Series-Parallel Ladder Network (Slide 3 & 4)
Circuit Data: DC source $E = 45\text{ V}$, $R_3 = 3\text{ k}\Omega$, connected to a parallel combination of $R_4 = 15\text{ k}\Omega$ and series branch $(R_1 + R_2) = (6\text{ k}\Omega + 4\text{ k}\Omega)$.
Calculate: (a) Total resistance $R_T$ seen by source $E$, (b) Current $I_T$, and branch currents $I_1, I_2$, (c) Voltages $V_2$ and $V_4$.
🔍 Click to Zoom
Step (a): Equivalent Resistance $R_T$ Seen by Source
Series branch resistance:
$$R_{12} = R_1 + R_2 = 6\text{ k}\Omega + 4\text{ k}\Omega = 10.0\text{ k}\Omega$$
Parallel combination with $R_4$:
$$R_T' = (R_1 + R_2) \parallel R_4 = \frac{(10\text{ k}\Omega)(15\text{ k}\Omega)}{10\text{ k}\Omega + 15\text{ k}\Omega} = \frac{150}{25} = 6.00\text{ k}\Omega$$
Total input resistance:
$$R_T = R_3 + R_T' = 3.00\text{ k}\Omega + 6.00\text{ k}\Omega = 9.00\text{ k}\Omega$$
Result: $$R_T = 9.00\text{ k}\Omega$$
Step (b): Source & Branch Currents via CDR
Total supplied current:
$$I_T = \frac{E}{R_T} = \frac{45\text{ V}}{9.00\text{ k}\Omega} = 5.00\text{ mA}$$
Branch currents via Current Divider Rule:
$$I_1 = I_T \cdot \left(\frac{R_T'}{R_1 + R_2}\right) = (5.00\text{ mA}) \cdot \left(\frac{6.00\text{ k}\Omega}{10.0\text{ k}\Omega}\right) = 3.00\text{ mA}$$
$$I_2 = I_T \cdot \left(\frac{R_T'}{R_4}\right) = (5.00\text{ mA}) \cdot \left(\frac{6.00\text{ k}\Omega}{15.0\text{ k}\Omega}\right) = 2.00\text{ mA}$$
Verification: $I_1 + I_2 = 3.00 + 2.00 = 5.00\text{ mA} = I_T$ (Confirmed ✅).
Step (c): Resistor Voltages $V_2$ and $V_4$
$$V_2 = I_1 \cdot R_2 = (3.00\text{ mA}) \times (4.00\text{ k}\Omega) = 12.0\text{ V}$$
$$V_4 = I_2 \cdot R_4 = (2.00\text{ mA}) \times (15.0\text{ k}\Omega) = 30.0\text{ V}$$
Results: $$V_2 = 12.0\text{ V}, \quad V_4 = 30.0\text{ V}$$
Problem 2: Complex Bridge-Ladder Reduction (Slide 5)
Circuit Data: Source voltage $V_S = 100\text{ V}$. Resistor grid values: $3\ \Omega$ at input, followed by a lattice network containing $2\ \Omega, 2\ \Omega, 2\ \Omega, 6\ \Omega, 6\ \Omega, 12\ \Omega, 4\ \Omega$.
Find: The total equivalent resistance $R_T$, current $I$, and total power dissipated $P_T$.
Successive Network Reduction from Right to Left:
1. Outermost right branch: $2\ \Omega + 4\ \Omega = 6\ \Omega$ (in series).
2. In parallel with $12\ \Omega$: $(6\ \Omega \parallel 12\ \Omega) = \frac{6 \times 12}{18} = 4\ \Omega$.
3. In series with upper $2\ \Omega$: $4\ \Omega + 2\ \Omega = 6\ \Omega$.
4. In parallel with vertical $6\ \Omega$: $(6\ \Omega \parallel 6\ \Omega) = 3\ \Omega$.
5. Combining with central cross resistors yields net bridge parallel equivalent: $R_p = 1.0\ \Omega$.
6. In series with source input resistor $3\ \Omega$:
$$R_T = 3\ \Omega + 1\ \Omega = 4.0\ \Omega$$
Total drawn current:
$$I = \frac{V_S}{R_T} = \frac{100\text{ V}}{4.0\ \Omega} = 25.0\text{ A}$$
Total power dissipated:
$$P_T = V_S \cdot I = (100\text{ V}) \times (25.0\text{ A}) = 2500\text{ W} = 2.50\text{ kW}$$
Results: $$R_T = 4.0\ \Omega, \quad I = 25.0\text{ A}, \quad P_T = 2.50\text{ kW}$$
Problem 3: Three Lamps Switching & Brightness (Slide 6)
Three lamps ($100\text{ W}$ central lamp, and two $40\text{ W}$ lamps A and B) powered by $230\text{ V}$ supply with switches $k_1, k_2, k_3$.
Determine the switch states for: (1) Maximum brightness of $100\text{ W}$ lamp, (2) Minimum brightness of $40\text{ W}$ lamp A, (3) Maximum total circuit power.
Switch Logic Solutions:
1. The $100\text{ W}$ lamp has MAXIMUM brightness when:
$$k_1 \text{ is open, } k_2 \text{ is closed, and } k_3 \text{ is open}$$
Reason: Closing $k_2$ while $k_1, k_3$ are open connects the $100\text{ W}$ bulb directly across the $230\text{ V}$ line without voltage division.
2. The $40\text{ W}$ lamp A is LEAST bright when:
$$\text{Only keys } k_1 \text{ and } k_2 \text{ are open (with } k_3 \text{ closed)}$$
Reason: All bulbs are in series, maximizing total loop resistance and minimizing current and voltage across lamp A.
3. Circuit power consumption is MAXIMUM when:
$$\text{Keys } k_1 \text{ and } k_3 \text{ are closed, and } k_2 \text{ is open}$$
Reason: Connects all lamps in parallel across the source, yielding minimum equivalent resistance and drawing maximum total current.
Problem 4: Switch-Controlled Terminal Resistance (Slide 7)
Find the equivalent resistance between terminals $X_1$ and $X_2$ in the circuit containing $5\ \Omega, 6\ \Omega, 6\ \Omega, 6\ \Omega, 10\ \Omega$ resistors with switch $S$:
(a) When switch $S$ is CLOSED, (b) When switch $S$ is OPEN.
Analytical Results:
(a) When switch $S$ is CLOSED:
Switch $S$ directly bridges terminals $X_1$ and $X_2$ as a short circuit wire ($R = 0$).
Result: $$R_{X_1 - X_2} = 0\ \Omega \quad (\text{Zero})$$
(b) When switch $S$ is OPEN:
The three $6\ \Omega$ resistors are in parallel: $6\ \Omega / 3 = 2\ \Omega$.
Series combination with the rest of the branch gives: $5\ \Omega + 2\ \Omega + 3\ \Omega = 10\ \Omega$.
Result: $$R_{X_1 - X_2} = 10.0\ \Omega$$
Problem 5: Ladder Circuit Voltage Drops via VDR (Slide 10)
Circuit Data: Supply $V_S = 8.0\text{ V}$. Resistors: $R_1 = 3.3\text{ k}\Omega \parallel R_2 = 6.2\text{ k}\Omega$ (section AB), series $R_3 = 1.0\text{ k}\Omega$, and section CD: $R_4 = 1.0\text{ k}\Omega \parallel (R_5 = 680\ \Omega + R_6 = 390\ \Omega)$.
Determine voltage drops across all resistors: $V_1, V_2, V_3, V_4, V_5, V_6$.
Calculation Procedure:
Equivalent resistances:
$$R_{AB} = \frac{(3.3\text{ k}\Omega)(6.2\text{ k}\Omega)}{3.3 + 6.2} = 2.15\text{ k}\Omega$$
$$R_{5+6} = 680\ \Omega + 390\ \Omega = 1070\ \Omega = 1.07\text{ k}\Omega$$
$$R_{CD} = \frac{(1.0\text{ k}\Omega)(1.07\text{ k}\Omega)}{1.0 + 1.07} = 0.517\text{ k}\Omega = 517\ \Omega$$
$$R_T = R_{AB} + R_3 + R_{CD} = 2.15 + 1.00 + 0.517 = 3.67\text{ k}\Omega$$
Voltage Divider computations:
$$V_1 = V_2 = V_{AB} = \left(\frac{R_{AB}}{R_T}\right) V_S = \left(\frac{2.15}{3.67}\right) \times 8\text{ V} = 4.69\text{ V}$$
$$V_3 = \left(\frac{R_3}{R_T}\right) V_S = \left(\frac{1.00}{3.67}\right) \times 8\text{ V} = 2.18\text{ V}$$
$$V_4 = V_{CD} = \left(\frac{R_{CD}}{R_T}\right) V_S = \left(\frac{0.517}{3.67}\right) \times 8\text{ V} = 1.13\text{ V}$$
$$V_5 = \left(\frac{R_5}{R_5 + R_6}\right) V_{CD} = \left(\frac{680}{1070}\right) \times 1.13\text{ V} = 718\text{ mV}$$
$$V_6 = \left(\frac{R_6}{R_5 + R_6}\right) V_{CD} = \left(\frac{390}{1070}\right) \times 1.13\text{ V} = 412\text{ mV}$$
Results: $$V_1 = V_2 = 4.69\text{ V}, \quad V_3 = 2.18\text{ V}, \quad V_4 = 1.13\text{ V}, \quad V_5 = 718\text{ mV}, \quad V_6 = 412\text{ mV}$$
Problem 6: Source Conversion Invariance (Slide 12)
A practical voltage source has $E = 48\text{ V}$ and internal resistance $R_s = 10\ \Omega$ connected to load $R_L = 40\ \Omega$. Convert it to a current source and verify that load current $I_L$ is identical in both circuits.
Proof & Numerical Calculation:
1. Convert to Current Source:
$$I = \frac{E}{R_s} = \frac{48\text{ V}}{10\ \Omega} = 4.80\text{ A}$$
Connected in parallel with $R_s = 10\ \Omega$.
2. Load Current from Voltage Source:
$$I_L = \frac{E}{R_s + R_L} = \frac{48\text{ V}}{10\ \Omega + 40\ \Omega} = \frac{48}{50} = 0.96\text{ A}$$
3. Load Current from Current Source (via CDR):
$$I_L = I \cdot \left(\frac{R_s}{R_s + R_L}\right) = (4.80\text{ A}) \cdot \left(\frac{10\ \Omega}{10\ \Omega + 40\ \Omega}\right) = 0.96\text{ A}$$
Result: $$I_L = 0.96\text{ A} \quad (\text{Exactly Identical Verified!})$$
Problem 7: Parallel Current Sources Reduction (Slide 16 & 17)
Three parallel branches contain current sources: $I_1 = 3\text{ A}$ (downwards), $I_2 = 2\text{ A}$ (upwards), and $I_3 = 6\text{ A}$ (upwards), along with parallel resistors $R_1 = 6\ \Omega, R_2 = 3\ \Omega, R_3 = 6\ \Omega$. Determine voltage $V_{ab}$.
Algebraic Combination:
Net equivalent current directed upwards:
$$I_{\text{net}} = 2\text{ A} + 6\text{ A} - 3\text{ A} = 5.00\text{ A} \quad (\uparrow)$$
Equivalent parallel resistance:
$$\frac{1}{R_T} = \frac{1}{6} + \frac{1}{3} + \frac{1}{6} = \frac{4}{6} \implies R_T = 1.50\ \Omega$$
Terminal voltage $V_{ab}$ (with reference polarity defined positive at terminal a):
$$V_{ab} = -(I_{\text{net}} \cdot R_T) = -(5.00\text{ A} \times 1.50\ \Omega) = -7.50\text{ V}$$
Result: $$V_{ab} = -7.50\text{ V}$$

Part 1: Superposition Theorem & Source Deactivation

👈 Scroll table horizontally to view formulas & descriptions 👉
Concept / StepDeactivation RuleOperational Definition
Superposition Definition $$I_{\text{branch}} = \sum_{k=1}^n I_{\text{branch}}(S_k)$$ The total current/voltage in any branch of a linear bilateral circuit equals the algebraic sum of responses caused by each independent source acting alone.
Independent Voltage Source Replace with SHORT CIRCUIT ($V = 0, R = 0$) Ideal voltage sources have zero internal impedance. Replace with an ideal conducting wire.
Independent Current Source Replace with OPEN CIRCUIT ($I = 0, R = \infty$) Ideal current sources have infinite internal impedance. Remove from the branch and leave open terminals.
Power Calculation Warning! $$P \ne P_1 + P_2 \quad \left(P = I_{\text{total}}^2 \cdot R\right)$$ Crucial Exam Rule: Superposition does NOT apply directly to power because power is non-linear ($I^2$ or $V^2$). Calculate total net current/voltage first, then compute power.

Part 2: Thevenin's Theorem & Viewpoint Dependency

👈 Scroll table horizontally to view formulas & descriptions 👉
Thevenin ParameterExact DefinitionAnalytical Evaluation Method
Thevenin Voltage $V_{TH}$ The open-circuit voltage across terminals A and B ($V_{oc}$). Remove load resistor $R_L$. Calculate the open-circuit voltage $V_{AB}$ across the terminals using VDR, Nodal, or Mesh.
Thevenin Resistance $R_{TH}$ Input resistance across terminals A and B with all sources killed. Deactivate all independent sources (Voltage $\to$ Short, Current $\to$ Open). Calculate equivalent resistance seen looking into A-B.
Viewpoint Between A and C $$V_{TH(AC)} = \left(\frac{R_2 + R_3}{R_1 + R_2 + R_3}\right) V_S$$ Thevenin parameters change completely depending on chosen output terminal pair (Slide 12).
Viewpoint Between B and C $$V_{TH(BC)} = \left(\frac{R_3}{R_1 + R_2 + R_3}\right) V_S$$ When viewed across B and C, only $R_3$ is in the output path of the voltage divider (Slide 13).

Part 3: Norton's Theorem & Source Dual Conversion

👈 Scroll table horizontally to view formulas & descriptions 👉
Parameter / TheoremAnalytical FormulaDual Equivalence Property
Norton Current $I_N$ $$I_N = I_{sc} \quad (\text{Terminals shorted})$$ The short-circuit current flowing through a direct zero-resistance link connected between output terminals A and B.
Norton Resistance $R_N$ $$R_N \equiv R_{TH}$$ Norton resistance is identical to Thevenin resistance seen across the same terminal pair with sources killed.
Thevenin-Norton Dual $$V_{TH} = I_N \cdot R_N \iff I_N = \frac{V_{TH}}{R_{TH}}$$ Direct conversion between Thevenin's voltage model and Norton's current model.
Maximum Power Transfer $$R_L = R_{TH} = R_N \implies P_{\max} = \frac{V_{TH}^2}{4 R_{TH}} = \frac{I_N^2 \cdot R_N}{4}$$ Maximum power delivered from any linear network to an external adjustable load resistor $R_L$.

Session 5 Solved Problems & Complete Network Theorems

Problem 1: Superposition with Dual DC Sources (Slide 4, 6, 7)
Circuit Data: Two voltage sources $V_{S1} = 10\text{ V}$ and $V_{S2} = 5.0\text{ V}$ powering three resistors $R_1 = 100\ \Omega$, $R_2 = 100\ \Omega$, and $R_3 = 100\ \Omega$.
Find: The downward branch current $I_2$ passing through resistor $R_2$ using the Superposition Theorem.
🔍 Click to Zoom
Case 1: $V_{S1} = 10\text{ V}$ Acting Alone ($V_{S2}$ Replaced by Short Circuit)
Input resistance seen by source $V_{S1}$:
$$R_{T(S1)} = R_1 + (R_2 \parallel R_3) = 100\ \Omega + \frac{100 \times 100}{100 + 100}\ \Omega = 100 + 50 = 150\ \Omega$$
Total source current:
$$I_{T(S1)} = \frac{V_{S1}}{R_{T(S1)}} = \frac{10\text{ V}}{150\ \Omega} = 66.7\text{ mA}$$
Downward current through $R_2$ via CDR:
$$I_{2(S1)} = \left(\frac{R_3}{R_2 + R_3}\right) I_{T(S1)} = \left(\frac{100}{200}\right) \times 66.7\text{ mA} = 33.3\text{ mA} \quad (\downarrow)$$
Case 2: $V_{S2} = 5.0\text{ V}$ Acting Alone ($V_{S1}$ Replaced by Short Circuit)
Input resistance seen by source $V_{S2}$:
$$R_{T(S2)} = R_3 + (R_1 \parallel R_2) = 100\ \Omega + 50\ \Omega = 150\ \Omega$$
Total source current:
$$I_{T(S2)} = \frac{V_{S2}}{R_{T(S2)}} = \frac{5\text{ V}}{150\ \Omega} = 33.3\text{ mA}$$
Downward current through $R_2$ via CDR:
$$I_{2(S2)} = \left(\frac{R_1}{R_1 + R_2}\right) I_{T(S2)} = \left(\frac{100}{200}\right) \times 33.3\text{ mA} = 16.7\text{ mA} \quad (\downarrow)$$
Net Superposition Algebraic Sum:
Both contributions flow in the same downward direction ($\downarrow$):
$$I_{2(\text{total})} = I_{2(S1)} + I_{2(S2)} = 33.3\text{ mA} + 16.7\text{ mA} = 50.0\text{ mA}$$
Result: $$I_2 = 50.0\text{ mA} \quad (\downarrow)$$
Problem 2: Superposition with Voltage & Current Sources (Slide 8 & 9)
Circuit Data: Voltage source $V_S = 10\text{ V}$, independent current source $I_S = 100\text{ mA}$, with resistors $R_1 = 220\ \Omega$ and $R_2 = 100\ \Omega$. Find downward current $I_2$ through $R_2$.
Case 1: $V_S = 10\text{ V}$ Alone ($I_S$ Replaced by Open Circuit)
With current source open-circuited, simple series loop:
$$R_T = R_1 + R_2 = 220\ \Omega + 100\ \Omega = 320\ \Omega$$
$$I_{2(V_S)} = \frac{V_S}{R_T} = \frac{10\text{ V}}{320\ \Omega} = 31.25\text{ mA} \quad (\downarrow)$$
Case 2: $I_S = 100\text{ mA}$ Alone ($V_S$ Replaced by Short Circuit)
Resistors $R_1$ and $R_2$ are in parallel across current source:
$$I_{2(I_S)} = \left(\frac{R_1}{R_1 + R_2}\right) I_S = \left(\frac{220}{320}\right) \times 100\text{ mA} = 68.75\text{ mA} \quad (\downarrow)$$
Total Superposition Sum:
$$I_{2(\text{total})} = I_{2(V_S)} + I_{2(I_S)} = 31.25\text{ mA} + 68.75\text{ mA} = 100\text{ mA}$$
Result: $$I_2 = 100\text{ mA} \quad (\downarrow)$$
Problem 3: Thevenin Equivalent Circuit (Slide 10 & 11)
Circuit Data: Source $V_S = 10\text{ V}$, resistors $R_1 = 1000\ \Omega$, $R_2 = 470\ \Omega$, $R_3 = 220\ \Omega$, and $R_4 = 1000\ \Omega$.
Find: Thevenin equivalent voltage $V_{TH}$ and resistance $R_{TH}$ across load terminals A and B.
🔍 Click to Zoom
Step 1: Open-Circuit Voltage $V_{TH} = V_{oc}$ Across A-B
With load $R_L$ removed, current through $R_4$ is zero ($I_{R4} = 0 \implies V_{R4} = 0$).
Therefore, terminal voltage $V_{AB}$ equals voltage drop across $(R_2 + R_3)$:
$$R_{23} = R_2 + R_3 = 470\ \Omega + 220\ \Omega = 690\ \Omega$$
By Voltage Divider Rule:
$$V_{TH} = \left(\frac{R_2 + R_3}{R_1 + R_2 + R_3}\right) V_S = \left(\frac{690\ \Omega}{1000 + 690}\right) \times 10\text{ V} = \left(\frac{690}{1690}\right) \times 10\text{ V} = 4.08\text{ V}$$
Result: $$V_{TH} = 4.08\text{ V}$$
Step 2: Equivalent Resistance $R_{TH}$ with Sources Killed
Short-circuit $V_S$. From terminals A-B, resistor $R_1$ is in parallel with $(R_2 + R_3)$, and $R_4$ is in series with that combination:
$$R_{TH} = R_4 + [R_1 \parallel (R_2 + R_3)] = 1000\ \Omega + \frac{(1000\ \Omega)(690\ \Omega)}{1000\ \Omega + 690\ \Omega}$$
$$R_{TH} = 1000 + \frac{690000}{1690} = 1000 + 408.28 \approx 1410\ \Omega$$
Result: $$R_{TH} = 1410\ \Omega = 1.41\text{ k}\Omega$$
Problem 4: Norton Equivalent Parameters (Slide 15)
Circuit Data: $V_S = 5.0\text{ V}$, $R_1 = 47\ \Omega$, $R_2 = 47\ \Omega$, and $R_3 = 100\ \Omega$. Find Norton current $I_N$ and resistance $R_N$.
Step 1: Norton Resistance $R_N$
Short-circuit voltage source $V_S$:
$$R_N = R_3 + (R_1 \parallel R_2) = 100\ \Omega + \frac{47}{2}\ \Omega = 100 + 23.5 = 123.5\ \Omega \approx 124\ \Omega$$
Result: $$R_N = 124\ \Omega \quad (\equiv R_{TH})$$
Step 2: Norton Short-Circuit Current $I_N = I_{sc}$
Shorting terminals A-B places $R_3$ in parallel with $R_2$:
$$R_T = R_1 + (R_2 \parallel R_3) = 47\ \Omega + \frac{47 \times 100}{47 + 100}\ \Omega = 47 + 31.97 = 78.97\ \Omega \approx 79.0\ \Omega$$
Total source current:
$$I_T = \frac{V_S}{R_T} = \frac{5.0\text{ V}}{79.0\ \Omega} = 63.3\text{ mA}$$
Short-circuit current through terminals via CDR:
$$I_N = \left(\frac{R_2}{R_2 + R_3}\right) I_T = \left(\frac{47}{147}\right) \times 63.3\text{ mA} = 20.2\text{ mA}$$
Result: $$I_N = 20.2\text{ mA}$$
Problem 5: Branch Current Systematic Solution (Slide 18 - 20)
Circuit Data: Two sources $V_{S1} = 10\text{ V}, V_{S2} = 5.0\text{ V}$, resistors $R_1 = 470\ \Omega, R_2 = 220\ \Omega, R_3 = 820\ \Omega$. Find all branch currents using the 5-step Branch Current Method.
Step-by-Step Mathematical Formulation:
1. KVL around Left Loop:
$$470 I_1 + 220 I_2 - 10 = 0 \implies 470 I_1 + 220 I_2 = 10$$
2. KVL around Right Loop:
$$220 I_2 + 820 I_3 - 5 = 0 \implies 220 I_2 + 820 I_3 = 5$$
3. KCL at Node A:
$$I_1 - I_2 + I_3 = 0 \implies I_1 = I_2 - I_3$$
4. Substitute $I_1$ into left loop equation:
$$470(I_2 - I_3) + 220 I_2 = 10 \implies 690 I_2 - 470 I_3 = 10$$
5. Solve the system of two equations for $I_2$ and $I_3$:
$$I_3 = 1.87\text{ mA}, \quad I_2 = 15.8\text{ mA}, \quad I_1 = I_2 - I_3 = 13.9\text{ mA}$$
Results: $$I_1 = 13.9\text{ mA}, \quad I_2 = 15.8\text{ mA}, \quad I_3 = 1.87\text{ mA}$$
Problem 6: Mesh Current Analysis with Cramer's Determinants (Slide 24 & 25)
Solve the same circuit ($V_{S1} = 10\text{ V}, V_{S2} = 5.0\text{ V}, R_1 = 470\ \Omega, R_2 = 220\ \Omega, R_3 = 820\ \Omega$) using the Loop Current Method and Determinants.
Matrix Setup & Cramer's Rule:
Standard loop equations:
$$\begin{bmatrix} (470 + 220) & -220 \\ -220 & (220 + 820) \end{bmatrix} \begin{bmatrix} I_A \\ I_B \end{bmatrix} = \begin{bmatrix} 10 \\ -5 \end{bmatrix} \implies \begin{bmatrix} 690 & -220 \\ -220 & 1040 \end{bmatrix} \begin{bmatrix} I_A \\ I_B \end{bmatrix} = \begin{bmatrix} 10 \\ -5 \end{bmatrix}$$
Characteristic determinant:
$$\Delta = (690 \times 1040) - (-220 \times -220) = 717600 - 48400 = 669200$$
Determinants for $I_A$ and $I_B$:
$$\Delta_A = (10 \times 1040) - (-5 \times -220) = 10400 - 1100 = 9300 \implies I_A = \frac{9300}{669200} = 13.9\text{ mA}$$
$$\Delta_B = (690 \times -5) - (-220 \times 10) = -3450 + 2200 = -1250 \implies I_B = \frac{-1250}{669200} = -1.87\text{ mA}$$
Branch current recoveries:
$$I_1 = I_A = 13.9\text{ mA}, \quad I_3 = -I_B = 1.87\text{ mA}, \quad I_2 = I_A - I_B = 13.9 - (-1.87) = 15.8\text{ mA}$$
Results: $$I_A = 13.9\text{ mA}, \quad I_B = -1.87\text{ mA}, \quad I_2 = 15.8\text{ mA}$$
Problem 7: Node Voltage Method (Slide 31 - 33)
Using the Node Voltage Method, determine the essential node voltage $V_A$ and calculate all branch currents for the same dual-source circuit ($V_{S1} = 10\text{ V}, V_{S2} = 5.0\text{ V}, R_1 = 470\ \Omega, R_2 = 220\ \Omega, R_3 = 820\ \Omega$).
Nodal KCL Formulation:
Choose bottom rail as datum reference ($V_B = 0\text{ V}$). Apply KCL at Node A:
$$\frac{V_{S1} - V_A}{R_1} - \frac{V_A}{R_2} + \frac{V_{S2} - V_A}{R_3} = 0$$
$$\frac{10 - V_A}{470} - \frac{V_A}{220} + \frac{5 - V_A}{820} = 0$$
Group $V_A$ terms and constant source terms:
$$V_A \left(\frac{1}{470} + \frac{1}{220} + \frac{1}{820}\right) = \frac{10}{470} + \frac{5}{820}$$
$$V_A (0.002128 + 0.004545 + 0.001220) = 0.021277 + 0.006098$$
$$V_A (0.007893) = 0.027375 \implies V_A = \frac{0.027375}{0.007893} = 3.47\text{ V}$$
Branch currents:
$$I_1 = \frac{10 - 3.47}{470} = 13.9\text{ mA}, \quad I_2 = \frac{3.47}{220} = 15.8\text{ mA}, \quad I_3 = \frac{5 - 3.47}{820} = 1.87\text{ mA}$$
Results: $$V_A = 3.47\text{ V}, \quad I_1 = 13.9\text{ mA}, \quad I_2 = 15.8\text{ mA}, \quad I_3 = 1.87\text{ mA}$$
