⚡ Sheet 4 Cheat Sheet: Line Integrals $\int_C P\,dx + Q\,dy$
1. Direct Parametrization (Along a curve $y = g(x)$)
$$\int_C P(x,y)\,dx + Q(x,y)\,dy = \int_{x_1}^{x_2} \left[ P(x, g(x)) + Q(x, g(x))\cdot g'(x) \right] dx$$
• نستبدل $y$ بـ $g(x)$ و $dy$ بـ $g'(x)dx$ ليصبح التكامل في متغير واحد $x$.
2. Independence of Path & Exact Differential (Conservative)
$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} \iff \int_C P\,dx + Q\,dy \text{ is independent of path (Conservative)}$$
$$P\,dx + Q\,dy = d\phi \implies \int_{(x_1, y_1)}^{(x_2, y_2)} P\,dx + Q\,dy = \phi(x_2, y_2) - \phi(x_1, y_1)$$
• إذا تحقق شرط التساوي، التكامل لا يعتمد على المسار وقيمته تساوي فرق دالة الجهد $\phi$ بين نقطتي البداية والنهاية.
3. Polar Parametrization for Circles ($x^2+y^2=R^2$)
$$x = R\cos\theta \implies dx = -R\sin\theta\,d\theta, \quad y = R\sin\theta \implies dy = R\cos\theta\,d\theta$$
📌 Q1: Evaluate $\int_{(0,0)}^{(1,1)} (x+y)\,dx + (2x-3y)\,dy$ along curves
Evaluate $\int_{(0,0)}^{(1,1)} (x+y)\,dx + (2x-3y)\,dy$ along:
(a) $y=x$  |  (b) $x^2=y$  |  (c) $x=y^2$  |  (d) $y=x^3$
(a) Along $y = x \implies dy = dx$
$$I = \int_0^1 (x+x)\,dx + (2x-3x)\,dx = \int_0^1 (2x - x)\,dx = \int_0^1 x\,dx = \left[\frac{x^2}{2}\right]_0^1 = \frac{1}{2}$$
Answer (a): $1/2$
(b) Along $y = x^2 \implies dy = 2x\,dx$
$$I = \int_0^1 (x+x^2)\,dx + (2x-3x^2)(2x\,dx) = \int_0^1 (x + x^2 + 4x^2 - 6x^3)\,dx = \int_0^1 (x + 5x^2 - 6x^3)\,dx$$ $$= \left[\frac{x^2}{2} + \frac{5x^3}{3} - \frac{6x^4}{4}\right]_0^1 = \frac{1}{2} + \frac{5}{3} - \frac{3}{2} = \frac{5}{3} - 1 = \frac{2}{3}$$
Answer (b): $2/3$
(c) Along $x = y^2 \implies dx = 2y\,dy$, with $y$ from $0$ to $1$
$$I = \int_0^1 (y^2+y)(2y\,dy) + (2y^2-3y)\,dy = \int_0^1 (2y^3 + 2y^2 + 2y^2 - 3y)\,dy = \int_0^1 (2y^3 + 4y^2 - 3y)\,dy$$ $$= \left[\frac{2y^4}{4} + \frac{4y^3}{3} - \frac{3y^2}{2}\right]_0^1 = \frac{1}{2} + \frac{4}{3} - \frac{3}{2} = \frac{4}{3} - 1 = \frac{1}{3}$$
Answer (c): $1/3$
(d) Along $y = x^3 \implies dy = 3x^2\,dx$
$$I = \int_0^1 (x+x^3)\,dx + (2x-3x^3)(3x^2\,dx) = \int_0^1 (x + x^3 + 6x^3 - 9x^5)\,dx = \int_0^1 (x + 7x^3 - 9x^5)\,dx$$ $$= \left[\frac{x^2}{2} + \frac{7x^4}{4} - \frac{9x^6}{6}\right]_0^1 = \frac{1}{2} + \frac{7}{4} - \frac{3}{2} = \frac{7}{4} - 1 = \frac{3}{4}$$
Answer (d): $3/4$
📌 Q2: Evaluate $\int_{(0,0)}^{(1,1)} (x+2y)\,dx + (2x-y)\,dy$ along curves
Evaluate $\int_{(0,0)}^{(1,1)} (x+2y)\,dx + (2x-y)\,dy$ along:
(a) $y=x$  |  (b) $x^2=y$  |  (c) $x=y^2$  |  (d) $y=x^3$
Path Independence Check (Exactness Test)
$$P = x + 2y \implies \frac{\partial P}{\partial y} = 2, \qquad Q = 2x - y \implies \frac{\partial Q}{\partial x} = 2$$
Since $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x} = 2$, the vector field is conservative and independent of path!
$$d\phi = (x+2y)dx + (2x-y)dy \implies \phi(x,y) = \frac{x^2}{2} + 2xy - \frac{y^2}{2}$$ $$I = \phi(1,1) - \phi(0,0) = \left(\frac{1}{2} + 2 - \frac{1}{2}\right) - 0 = 2$$
Value is 2 along ALL paths (a, b, c, d)
📌 Q3: $\int_{(0,1)}^{(1,0)} (x+e^y)\,dx + (2y+xe^y)\,dy$ along circle $x^2+y^2=1$
Find $\int_{(0,1)}^{(1,0)} (x+e^y)\,dx + (2y+xe^y)\,dy$ along the unit circle $x^2+y^2=1$.
Test for Exact Differential
$$P = x + e^y \implies P_y = e^y, \qquad Q = 2y + xe^y \implies Q_x = e^y$$
Since $P_y = Q_x$, the field is conservative. Finding potential function $\phi(x,y)$:
$$\phi(x,y) = \int (x+e^y)dx = \frac{x^2}{2} + xe^y + g(y)$$ $$\frac{\partial\phi}{\partial y} = xe^y + g'(y) = 2y + xe^y \implies g'(y) = 2y \implies g(y) = y^2$$ $$\phi(x,y) = \frac{x^2}{2} + xe^y + y^2$$
Evaluate between limits from $(0,1)$ to $(1,0)$:
$$I = \phi(1,0) - \phi(0,1) = \left(\frac{1}{2} + 1(e^0) + 0\right) - \left(0 + 0 + 1^2\right) = \left(\frac{1}{2} + 1\right) - 1 = \frac{1}{2}$$
Answer: $1/2$
📌 Q4 & Q5: Line Integrals along Circles from $(-R,0)$ to $(R,0)$
(4) $\int_{(-1,0)}^{(1,0)} (2x+y)\,dx + (x+3y)\,dy$ along $x^2+y^2=1$
(5) $\int_{(-3,0)}^{(3,0)} (2x-y)\,dx + (x+3y)\,dy$ along $x^2+y^2=9$
Solution for Question 4: $P_y = 1, Q_x = 1$ (Conservative!)
$$P = 2x+y \implies P_y = 1, \qquad Q = x+3y \implies Q_x = 1 \implies \text{Exact}$$ $$\phi(x,y) = x^2 + xy + \frac{3}{2}y^2$$ $$I = \phi(1,0) - \phi(-1,0) = (1^2 + 0 + 0) - ((-1)^2 + 0 + 0) = 1 - 1 = 0$$
Answer (Q4): $0$
Solution for Question 5: $P_y = -1, Q_x = 1$ (Not Conservative)
Parametrize upper semi-circle from $\theta = \pi$ to $\theta = 0$: $x = 3\cos\theta, y = 3\sin\theta$
$$dx = -3\sin\theta\,d\theta, \quad dy = 3\cos\theta\,d\theta$$ $$(2x-y)dx + (x+3y)dy = (6\cos\theta - 3\sin\theta)(-3\sin\theta) + (3\cos\theta + 9\sin\theta)(3\cos\theta)$$ $$= -18\sin\theta\cos\theta + 9\sin^2\theta + 9\cos^2\theta + 27\sin\theta\cos\theta = 9(\sin^2\theta+\cos^2\theta) + 9\sin\theta\cos\theta = 9 + \frac{9}{2}\sin 2\theta$$
$$I = \int_{\pi}^0 \left(9 + \frac{9}{2}\sin 2\theta\right) d\theta = \left[9\theta - \frac{9}{4}\cos 2\theta\right]_{\pi}^0 = \left(0 - \frac{9}{4}\right) - \left(9\pi - \frac{9}{4}\right) = -9\pi$$
Answer (Q5): $-9\pi$ (or $9\pi$ if lower path)
📌 Q6: $\int_{(0,0)}^{(2,0)} (x+2y)\,dx + (2x+3y)\,dy$ along circle $x^2+y^2-2x=0$
Find the integral $\int_{(0,0)}^{(2,0)} (x+2y)\,dx + (2x+3y)\,dy$ along circle $x^2+y^2-2x=0$.
Independence of Path Evaluation
$$P = x + 2y \implies P_y = 2, \qquad Q = 2x + 3y \implies Q_x = 2$$
The field is conservative! Determining the potential function:
$$\phi(x,y) = \frac{x^2}{2} + 2xy + \frac{3}{2}y^2$$ $$I = \phi(2,0) - \phi(0,0) = \left(\frac{2^2}{2} + 0 + 0\right) - 0 = 2$$
Answer: $2$
📌 Q7 & Q8: Line vs Circle Paths
(7) $\int_{(0,1)}^{(1,0)} (x-y)\,dx + (2x+3y)\,dy$ through: (a) $x+y=1$  |  (b) $x^2+y^2=1$
(8) $\int_{(0,2)}^{(2,0)} (x+y^2)\,dx + (2xy+1)\,dy$ through: (a) $x+y=2$  |  (b) $x^2+y^2=4$
Solution for Question 7 (Not Conservative: $P_y = -1 \neq Q_x = 2$)
Path (a): Straight line $y = 1-x \implies dy = -dx$, $x$ from $0$ to $1$:
$$I_a = \int_0^1 [x - (1-x)]dx + [2x + 3(1-x)](-dx) = \int_0^1 (2x-1 - 3 + x)dx = \int_0^1 (3x-4)dx = \left[\frac{3x^2}{2} - 4x\right]_0^1 = -\frac{5}{2}$$
Path (b): Circle $x=\cos\theta, y=\sin\theta$, from $\theta=\pi/2$ to $\theta=0$:
$$I_b = \int_{\pi/2}^0 (\cos\theta-\sin\theta)(-\sin\theta)d\theta + (2\cos\theta+3\sin\theta)(\cos\theta)d\theta$$ $$= \int_{\pi/2}^0 (-\sin\theta\cos\theta + \sin^2\theta + 2\cos^2\theta + 3\sin\theta\cos\theta)d\theta = \int_{\pi/2}^0 (1 + \cos^2\theta + 2\sin\theta\cos\theta)d\theta$$ $$= \left[\theta + \frac{\theta}{2} + \frac{\sin 2\theta}{4} + \sin^2\theta\right]_{\pi/2}^0 = (0) - \left(\frac{3\pi}{4} + 1\right) = -1 - \frac{3\pi}{4}$$
Q7: (a) $-5/2$  |  (b) $-1 - 3\pi/4$
Solution for Question 8 (Conservative: $P_y = 2y = Q_x$)
Notice that $P_y = 2y$ and $Q_x = 2y$. The field is EXACT!
$$\phi(x,y) = \frac{x^2}{2} + xy^2 + y$$ $$I = \phi(2,0) - \phi(0,2) = \left(\frac{2^2}{2} + 0 + 0\right) - (0 + 0 + 2) = 2 - 2 = 0$$
Q8: Result is $0$ for BOTH paths (a) and (b)
⚡ Sheet 5 Cheat Sheet: Green's Theorem $\oint_C P\,dx + Q\,dy$
1. Green's Theorem in the Plane
$$\oint_C P\,dx + Q\,dy = \iint_D \left( \frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right) dA$$
• المسار $C$ يجب أن يكون مغلقاً بالاتجاه الموجب (عكس عقارب الساعة Counter-Clockwise).
2. Closed Integral of Exact/Conservative Field
$$\text{If } \frac{\partial Q}{\partial x} = \frac{\partial P}{\partial y} \implies \oint_C P\,dx + Q\,dy = \iint_D (0)\,dA = 0$$
• أي تكامل على مسار مغلق لمجال محافظ يساوي صفراً مباشرة دون حسابات مطولة.
3. Double Integrals in Polar & Elliptic Coordinates
$$\text{Circle: } x = r\cos\theta, y = r\sin\theta, \quad dA = r\,dr\,d\theta$$ $$\text{Ellipse } \frac{x^2}{a^2} + \frac{y^2}{b^2} \le 1: \quad x = ar\cos\theta, y = br\sin\theta, \quad dA = ab\,r\,dr\,d\theta, \quad \text{Area} = \pi ab$$
📌 Q1: $\oint_C (xy)\,dx + (x+y)\,dy$
Find $\oint_C (xy)\,dx + (x+y)\,dy$ along:
(a) $x^2 = y$ and $x = y^2$  |  (b) $x^2+y^2=4$
Using Green's Theorem: $\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} = 1 - x$
$$P = xy \implies P_y = x, \qquad Q = x+y \implies Q_x = 1 \implies Q_x - P_y = 1 - x$$
Part (a): Region bounded by $y=x^2$ and $y=\sqrt{x}$ from $x=0$ to $1$:
$$I = \int_0^1 \int_{x^2}^{\sqrt{x}} (1-x)\,dy\,dx = \int_0^1 (1-x)(\sqrt{x} - x^2)dx = \int_0^1 (x^{1/2} - x^2 - x^{3/2} + x^3)dx$$ $$= \left[\frac{2}{3}x^{3/2} - \frac{x^3}{3} - \frac{2}{5}x^{5/2} + \frac{x^4}{4}\right]_0^1 = \frac{2}{3} - \frac{1}{3} - \frac{2}{5} + \frac{1}{4} = \frac{1}{3} - \frac{2}{5} + \frac{1}{4} = \frac{11}{60}$$
Part (b): Region $x^2+y^2 \le 4$ (Radius $R=2$):
$$I = \iint_D (1-x)dA = \iint_D 1\,dA - \iint_D x\,dA = \text{Area}(D) - 0 = \pi(2)^2 = 4\pi$$
(a) $11/60$  |  (b) $4\pi$
📌 Q2: $\oint_C (x+2y)\,dx + (x^2-y)\,dy$ for triangle (0,0), (2,0), (2,2)
Evaluate $\oint_C (x+2y)\,dx + (x^2-y)\,dy$ along triangle with vertices $(0,0), (2,0), (2,2)$.
Application of Green's Theorem
$$P = x+2y \implies P_y = 2, \qquad Q = x^2-y \implies Q_x = 2x$$ $$Q_x - P_y = 2x - 2$$
Region limits: $x$ goes from $0$ to $2$, and $y$ goes from $0$ to the hypotenuse line $y = x$:
$$I = \int_0^2 \int_0^x (2x-2)\,dy\,dx = \int_0^2 (2x-2)x\,dx = \int_0^2 (2x^2 - 2x)dx = \left[\frac{2x^3}{3} - x^2\right]_0^2 = \frac{16}{3} - 4 = \frac{4}{3}$$
Answer: $4/3$
📌 Q3: $\oint_C (2xy)\,dx + (x^2+y^3)\,dy$
Evaluate $\oint_C (2xy)\,dx + (x^2+y^3)\,dy$ along:
(a) $y=x, y=x^2$  |  (b) $x^2+y^2=5$
Exact Differential Check
$$P = 2xy \implies P_y = 2x, \qquad Q = x^2+y^3 \implies Q_x = 2x$$ $$Q_x - P_y = 2x - 2x = 0$$
By Green's Theorem, since the integrand of the double integral is zero:
$$I = \iint_D 0\,dA = 0$$
Answer: $0$ for both (a) and (b)
📌 Q4: $\oint_C (3x^2y)\,dx + (x^3-2y)\,dy$ for triangle (0,0), (2,0), (0,2)
Evaluate $\oint_C (3x^2y)\,dx + (x^3-2y)\,dy$ for triangle with vertices $(0,0), (2,0), (0,2)$.
Exact Field Test
$$P = 3x^2y \implies P_y = 3x^2, \qquad Q = x^3-2y \implies Q_x = 3x^2$$ $$Q_x - P_y = 3x^2 - 3x^2 = 0$$
$$I = \iint_D 0\,dA = 0$$
Answer: $0$
📌 Q5: $\int_A^B \bar{U}\cdot d\bar{r}$ where $\bar{U} = (x+y^2)i + (xy)j$
Find $\int_A^B \bar{U}\cdot d\bar{r}$ with $\bar{U} = (x+y^2)i + (xy)j$ from $A(0,0)$ to $B(1,1)$ along:
(a) $y=x^2$  |  (b) $y^2=x$  |  (c) $y=x$
(a) Along $y=x^2 \implies dy=2x\,dx$
$$I = \int_0^1 (x+x^4)dx + x(x^2)(2x\,dx) = \int_0^1 (x + x^4 + 2x^4)dx = \int_0^1 (x + 3x^4)dx = \left[\frac{x^2}{2} + \frac{3x^5}{5}\right]_0^1 = \frac{1}{2} + \frac{3}{5} = \frac{11}{10}$$
Answer (a): $11/10$
(b) Along $x=y^2 \implies dx=2y\,dy$, $y$ from $0$ to $1$
$$I = \int_0^1 (y^2+y^2)(2y\,dy) + (y^2\cdot y)dy = \int_0^1 (4y^3 + y^3)dy = \int_0^1 5y^3\,dy = \left[\frac{5y^4}{4}\right]_0^1 = \frac{5}{4}$$
Answer (b): $5/4$
(c) Along $y=x \implies dy=dx$
$$I = \int_0^1 (x+x^2)dx + (x^2)dx = \int_0^1 (x + 2x^2)dx = \left[\frac{x^2}{2} + \frac{2x^3}{3}\right]_0^1 = \frac{1}{2} + \frac{2}{3} = \frac{7}{6}$$
Answer (c): $7/6$
📌 Q6: Verify Green's Theorem for $\oint_C (xy)\,dx + (x+y)\,dy$
Verify Green's Theorem for $\oint_C (xy)\,dx + (x+y)\,dy$ where $C$ is:
(a) $y=x, y=x^2$  |  (b) $x^2+y^2=5$  |  (c) $4x^2+9y^2=36$
General Integrand for Double Integral Side
$$Q_x - P_y = \frac{\partial}{\partial x}(x+y) - \frac{\partial}{\partial y}(xy) = 1 - x$$
(a) Region between $y=x^2$ and $y=x$
1. Line Integral side: $C = C_1 (\text{along } y=x^2 \text{ from } 0 \to 1) - C_2 (\text{along } y=x \text{ from } 1 \to 0)$:
$$\int_{C_1} = \int_0^1 x(x^2)dx + (x+x^2)(2x\,dx) = \int_0^1 (x^3 + 2x^2 + 2x^3)dx = \left[\frac{3x^4}{4} + \frac{2x^3}{3}\right]_0^1 = \frac{17}{12}$$ $$\int_{C_2} = \int_1^0 x(x)dx + (x+x)dx = \int_1^0 (x^2+2x)dx = \left[\frac{x^3}{3} + x^2\right]_1^0 = -\frac{4}{3} = -\frac{16}{12}$$ $$\oint_C = \frac{17}{12} - \frac{16}{12} = \frac{1}{12}$$
2. Double Integral side:
$$\iint_D (1-x)dA = \int_0^1 \int_{x^2}^x (1-x)dy\,dx = \int_0^1 (1-x)(x-x^2)dx = \int_0^1 (x - 2x^2 + x^3)dx = \frac{1}{2} - \frac{2}{3} + \frac{1}{4} = \frac{1}{12}$$
Green's Theorem Verified for (a): Both Sides = $1/12$
(b) Circle $x^2+y^2=5$ (Radius $R=\sqrt{5}$)
Double Integral: $\iint_D (1-x)dA = \text{Area} - \iint_D x\,dA = \pi(\sqrt{5})^2 - 0 = 5\pi$
Line Integral: $x=\sqrt{5}\cos\theta, y=\sqrt{5}\sin\theta$ integrates directly to $5\pi$.
Verified for (b): Both Sides = $5\pi$
(c) Ellipse $4x^2+9y^2=36 \implies \frac{x^2}{9} + \frac{y^2}{4} = 1$ ($a=3, b=2$)
Double Integral: $\iint_D (1-x)dA = \text{Area} - 0 = \pi a b = \pi(3)(2) = 6\pi$
Verified for (c): Both Sides = $6\pi$
📌 Q7: Verify Green's Theorem for $\oint_C (2xy)\,dx + (x^2+\sin y)\,dy$
Verify Green's Theorem for $\oint_C (2xy)\,dx + (x^2+\sin y)\,dy$ where $C$ is:
(a) $y=x, y=x^2$  |  (b) $x^2+y^2=5$  |  (c) $4x^2+9y^2=36$
Double Integral Side Calculation
$$P = 2xy \implies P_y = 2x, \qquad Q = x^2+\sin y \implies Q_x = 2x$$ $$Q_x - P_y = 2x - 2x = 0$$
Double integral is identically zero: $\iint_D 0\,dA = 0$ for all regions (a), (b), and (c).
Line Integral Side (Conservative Field)
Since $P\,dx + Q\,dy = d(x^2y - \cos y)$, the integral over ANY closed loop is strictly:
$$\oint_C (2xy)\,dx + (x^2+\sin y)\,dy = 0$$
Verified: Both Sides = 0 for (a), (b), and (c)
